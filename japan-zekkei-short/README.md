# 死ぬまでに見たい 日本の絶景TOP10（ショート動画）

- 完成動画: `out/japan_zekkei_top10.mp4`（1080×1920 / 30fps / 約60秒）
- サムネイル: `out/thumbnail.jpg`
- ナレーション: VOICEVOX:青山龍星（冒頭・ため・締め＝熱血、各スポット＝ノーマル）
- 映像: `scenes.py` で描いたオリジナルのイラスト（写真なし版）
- BGM: `bgm.py` で合成した和風シネマティック曲（オリジナル・著作権フリー）。効果音なし
  - 琴の分散和音、尺八風の笛、ストリングス、和太鼓。ニ長調ペンタトニックで、Bm-G-D-A の感動系進行（88BPM）
  - 構成: 導入（静かに琴と太鼓）→ 本編（笛のメロディ）→ ため（ストリングスのクレッシェンド）→ 第1位（全楽器）
  - 別の曲を使いたい場合は `bgm/` に mp3 や wav を置くと、自動でそちらが使われます（DOVA-SYNDROME などのフリーBGMを想定）

## 構成と演出

| 時間 | 内容 | 演出 |
|---|---|---|
| 0〜6秒 | フック「死ぬまでに見たい日本の絶景TOP10」 | 10景を0.45秒ずつ見せる、タイトルの段階登場、「第1位は最後に発表！」で離脱防止 |
| 6〜51秒 | 第10位→第2位のカウントダウン | 順位のポップイン、ゆっくりズーム、0.3秒のクロスフェード切り替え、上部の進捗バー |
| 51〜54秒 | 「そして、第1位は…」 | BGMのリズムを抜いて「ため」を作る、ぼかした背景と「？」 |
| 54〜60秒 | 第1位 新倉山浅間公園 | BGMが戻り、紙吹雪 |
| 最後 | 10景を一覧表示し「行きたいのは何位？」 | コメント・保存を促してエンゲージメントを上げる |

ナレーション中はBGMの音量を自動で下げています（ダッキング）。音量は-14 LUFS前後に正規化しています。

## （任意）写真版を作る場合

現在の完成版はイラストのみで、写真は使っていません。写真版を作りたくなったときは以下を使えます。

### フリー写真の自動取得

```bash
python3 fetch_photos.py   # Wikimedia Commons から CC0 / パブリックドメイン / CC BY の写真を取得
python3 build.py          # 写真入りで再ビルド
```

- ネットワークで `commons.wikimedia.org` と `upload.wikimedia.org` へのアクセスが必要です
- 作者・ライセンスは `photos/credits.json` と `photos/CREDITS.md` に記録され、動画の左下にも「Photo: 作者 / ライセンス」と表示されます
- CC BY の写真は、投稿の説明欄にも `CREDITS.md` の内容を記載してください
- 検索で自動選択するため、その場所の写真か必ず目で確認してください（違う場合は `photos/` の該当ファイルを差し替え）

### 写真の手動差し替え

実際の写真を `photos/` に次のファイル名で置き、再ビルドすると自動で差し替わります（縦長写真推奨、自動で中央をトリミング）。

| 順位 | ファイル名 |
|---|---|
| 10 | `10_tsunoshima.jpg` |
| 9 | `09_takachiho.jpg` |
| 8 | `08_biei.jpg` |
| 7 | `07_takeda.jpg` |
| 6 | `06_yakushima.jpg` |
| 5 | `05_miyako.jpg` |
| 4 | `04_shirakawago.jpg` |
| 3 | `03_kamikochi.jpg` |
| 2 | `02_yukinootani.jpg` |
| 1 | `01_fuji.jpg` |

写真は、自分で撮影したもの、商用利用可能なフリー素材（Unsplash、Pexels、写真AC など）、または各自治体・観光協会の利用規約に沿った素材を使ってください。クレジット表記が必要な素材は、投稿の説明欄に記載します。

## ビルド方法

```bash
docker run -d -p 50021:50021 voicevox/voicevox_engine:cpu-latest
pip install pillow numpy   # ffmpeg も必要
python3 build.py
```

台本・字幕・見頃は `script.py` で編集できます。読み間違い対策として、ナレーション文は一部をひらがなにしています。
