# 死ぬまでに見たい 日本の絶景TOP10（ショート動画）

- 完成動画: `out/japan_zekkei_top10.mp4`（1080×1920 / 30fps / 約60秒）
- サムネイル: `out/thumbnail.jpg`
- ナレーション: VOICEVOX:青山龍星（冒頭・ため・締め＝熱血、各スポット＝ノーマル）
- BGM・効果音: `build.py` 内で合成したオリジナル（著作権フリー）

## 構成と演出

| 時間 | 内容 | 演出 |
|---|---|---|
| 0〜6秒 | フック「死ぬまでに見たい日本の絶景TOP10」 | 10景を0.3秒ずつ高速カット、タイトルの段階登場・揺れ、「第1位は最後に発表！」で離脱防止 |
| 6〜51秒 | 第10位→第2位のカウントダウン | 順位のポップイン、ホワイトフラッシュとズーム、衝撃音・風切り音、上部の進捗バー |
| 51〜54秒 | 「そして、第1位は…」 | BGMを止めてドラムロールとライザー、ぼかした背景と「？」 |
| 54〜60秒 | 第1位 新倉山浅間公園 | 大きな衝撃音とチャイム、紙吹雪 |
| 最後 | 10景を一覧表示し「行きたいのは何位？」 | コメント・保存を促してエンゲージメントを上げる |

ナレーション中はBGMの音量を自動で下げています（ダッキング）。音量は-14 LUFS前後に正規化しています。

## ビルド方法

```bash
docker run -d -p 50021:50021 voicevox/voicevox_engine:cpu-latest
pip install pillow numpy   # ffmpeg も必要
python3 build.py
```

台本・字幕・見頃は `script.py` で編集できます。読み間違い対策として、ナレーション文は一部をひらがなにしています。
