# 毎日の未解決事件 — YouTubeショート・シリーズ

毎日21時に1本、未解決事件を1分で紹介する縦型ショート(1080×1920 / 30fps / 58秒)。
ナレーションは VOICEVOX:四国めたん、BGM・映像はすべて自作(権利フリー)。

## シリーズの方向性

**FILE No.002 以降は「不気味系」フォーマットが基準。**
事実そのものが不気味な事件を選び、「①不気味な違和感 → ②事件 → ③もっと不気味な事実 → ④未解決」の
4段構成で、ささやきナレーション・狂ったオルゴールBGM・VHS質感で聴かせる。
詳細は `ep002-hinterkaifeck/README.md` を参照。

## 制作パイプライン(各エピソード共通)

1. `script.md` … 台本(読み上げ原稿/字幕/シーン構成/事実関係)
2. `render.html` … Canvas 2D の決定論的レンダラ(`render(t)`)。ブラウザで開くとプレビュー
3. `node capture.js` … Playwright で1フレームずつ撮影 → 無音mp4
4. `python3 narrate.py` … VOICEVOX合成(尺に自動フィット)+自作BGMをダッキングしてミックス
5. `./export_upload.sh` … -14 LUFS 正規化して `upload/` に一式(mp4/SRT/サムネ/metadata.md)

## 題材選定の倫理ガイドライン

- 遺族への影響が小さい、古い事件・時効成立事件を優先
- 残酷な直接描写はしない(メタファーで表現)
- 実在個人の特定につながる推測はしない。数値は「概数」として扱う
- VOICEVOX 利用規約に従い「VOICEVOX:四国めたん」クレジットを動画内+概要欄に必ず表記
