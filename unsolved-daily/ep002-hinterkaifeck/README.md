## 再生成の方法

```bash
cd unsolved-daily/ep002-hinterkaifeck
node capture.js            # output/unsolved_002_silent.mp4(無音版)
python3 narrate.py         # めたん3スタイル合成+BGMダッキング → narrated.mp4
python3 bgm.py 58 output/bgm.wav  # BGMのみ
./export_upload.sh         # upload/ に -14 LUFS 正規化済み一式
```

VOICEVOX のセットアップは `../ep001-300million/README.md` と同じ。
**ささやき(style 36)/ヒソヒソ(style 37)は 0.vvm には入っていない**ため、
`voicevox_vvm` リリース(tag 0.17.1)の **0.vvm〜8.vvm** を `VOICEVOX_VVMS` のディレクトリに置くこと
(narrate.py が必要スタイルの有無を起動時に検証する)。

音声を公開する場合は「VOICEVOX:四国めたん」のクレジット表記が必須
(動画末尾カードと `upload/metadata.md` に記載済み)。

## 題材選定の方針(不気味系)

- 「事実そのものが不気味」な事件を選ぶ(演出で盛るのではなく、事実の提示順で怖がらせる)
- 100年単位で古い事件・遺族への影響が小さい事件を優先。残酷な直接描写はしない
- 1件1分で「①不気味な違和感 → ②事件 → ③もっと不気味な事実 → ④未解決」の4段構成
