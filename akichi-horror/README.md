# 近所の謎の空き地 — ホラーショート動画

近所にある「謎の空き地」をテーマにした縦型ホラーショート(1080×1920 / 30fps / 約62秒)です。
映像・効果音はすべてコードで生成しており、外部の素材は使っていません。ナレーションは VOICEVOX(青山龍星「しっとり」「囁き」)です。

- **完成動画: `upload/akichi_horror_final.mp4`**(字幕焼き込み・ナレーション・効果音入り、-14 LUFS)
- 字幕: `upload/subtitles_ja.srt` / サムネイル: `upload/thumbnail.jpg` / タイトル・説明文・タグ: `upload/metadata.md`

## ストーリー

| シーン | 内容 |
|---|---|
| タイトル | 「近所の謎の空き地」 |
| 空き地 | うちの近所に、ずっと空き地がある。 |
| 看板 | 看板には「売地」の文字。でも電話番号だけが、黒く塗りつぶされている。 |
| 地面 | 草が一本も生えていない。真夏でも。(中央へ向かう足跡) |
| 時計 | そして毎晩、午前2時。 |
| 人影 | 空き地の真ん中に、誰かが立っている。 |
| 近所の人 | 「あの空き地、前は何があったんですか」→「空き地? そんなもの、どこにあるの?」(映像が一瞬、家に置き換わる) |
| 接近 | 昨日の夜、ついに近づいてみた。その人影は……私と同じ服を着ていた。 |
| 窓 | 振り返ると、私の部屋の窓から、誰かがこっちを見ていた。 |
| ジャンプスケア | 約1秒(白フラッシュは1回のみ) |
| エンド | 今夜2時。窓の外は、見ないでください。 |

## 再生成の方法

```bash
cd akichi-horror
python3 narrate.py   # ナレーション合成 → output/narration.wav, timeline.js/json(シーン尺), subtitles_ja.srt
python3 sound.py     # 環境音・効果音を合成してナレーションとミックス → output/mix.wav
node capture.js      # render.html を1フレームずつ撮影 → output/video_silent.mp4
./export.sh          # 映像と音声を合成し -14 LUFS に正規化 → upload/
```

- `narrate.py` … 原稿は `SCRIPT` にあります。読み上げの長さからシーンの尺を自動で決めるので、原稿を書き換えても映像・効果音のタイミングが追従します
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)。録画風オーバーレイ、グレイン、走査線、グリッチ
- `sound.py` … 低音ドローン、風、虫の声、時計の秒針、心音、足音、衝撃音、ジャンプスケア音を numpy だけで合成。発話中は環境音を自動で下げます
- 必要なもの: Node.js + `playwright`(Chromium)、`ffmpeg`、IPA明朝/IPAゴシック、Python 3 + `numpy` + `pyopenjtalk` + `voicevox_core`(セットアップは `../pacific-war-analysis/README.md` と同じ。音声モデルは `15.vvm`)

VOICEVOX の音声を公開する場合は「VOICEVOX:青山龍星」のクレジット表記が必要です(エンドカードと説明文に記載済み)。
