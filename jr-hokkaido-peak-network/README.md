# JR北海道 最盛期の路線網 — ショート動画

1987年4月の発足直後、JR北海道がもっとも多くの路線を持っていた頃の路線網と、その後の廃止の流れを
地図アニメーションで解説する縦型ショート動画(1080×1920 / 30fps / 約73秒)です。

- **完成動画: `output/jr_hokkaido_peak_network.mp4`**(H.264 + AAC ステレオ・-14 LUFS)
- 字幕: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.jpg`
- ナレーションのみ: `output/narration.wav`(VOICEVOX:四国めたん ノーマル)
- BGMのみ: `output/bgm.wav`(numpy で合成した自作曲・権利フリー)
- 投稿用タイトル・説明文: `metadata.md`

## 構成と演出

| 時間 | シーン | 内容 | 演出 |
|---|---|---|---|
| 0:00 | フック | 「昔は今の1.5倍!?」→ 最盛期の路線網 | ズームアウトから全路線が光った状態で開始。インパクト音と弾む大見出し |
| 0:07 | 発足 | 1987.4.1、21線区・3,176.6km | 札幌から外へ路線が描かれていき、線区数と営業キロがカウントアップ |
| 0:16 | 幹線 | 函館本線・室蘭本線・千歳線・根室本線 | 読み上げに合わせて金色にハイライトし、路線名がポップ |
| 0:22 | 道北・道東 | 宗谷本線(稚内)・石北本線(網走) | 北東へカメラ移動、終点にピン |
| 0:27 | 消えた路線 | 名寄本線・天北線・池北線・深名線・標津線 | ピンクで強調、BGMはドラムを抜いてノスタルジックに。「網の目」で全路線が一斉に光る |
| 0:37 | 青函トンネル | 1988年 海峡線開業 | 津軽海峡へズームし緑の線が海底を伸びる。ライザーで溜めて「本州」でビートが戻る |
| 0:43 | 縮小 | 1987〜2016年の廃止・移管 | 背景が赤く変化。廃止ごとに線が赤く光って × 印→点線に、年号・路線名・営業キロが更新、100km超の廃止は画面が揺れ低音インパクト |
| 0:52 | さらに廃止 | 2016〜2026年(留萌本線 全線廃止まで) | 同上 |
| 1:00 | 比較 | 21線区→12線区、3,176.6km→2,091.7km | 棒グラフ比較、「約3分の1」でドン(−34%) |
| 1:06 | 締め | 乗ってみたかった路線は? | 廃止路線名が次々表示、コメント吹き出しで参加を促す。クレジット表示 |

ほかに全編を通して、列車の光点が路線上を走る・雪が舞う・字幕のキーワードを黄色で強調・上部に進行バー・シーン頭の白フラッシュとズームパンチを入れています。

## 使用データ

| 項目 | 値 | 出典 |
|---|---|---|
| 発足時(1987年4月1日)の路線 | 21線区・3,176.6km | 国会提出資料、各種報道 |
| 現在(2026年4月1日)の路線 | 在来線12線区・2,091.7km(新幹線148.8kmを含め計2,240.5km) | JR北海道「線区別営業キロ」 |
| 廃止・移管(年月・km) | 幌内線 1987.7 20.8 / 松前線 1988.2 50.8 / 歌志内線 1988.4 14.5 / 標津線 1989.4 116.9 / 天北線 1989.5 148.9 / 名寄本線 1989.5 143.0 / 池北線 1989.6 140.0(第三セクターへ転換) / 上砂川支線 1994.5 7.3 / 深名線 1995.9 121.8 / 江差線 木古内〜江差 2014.5 42.1 / 江差線 五稜郭〜木古内 2016.3 37.8(道南いさりび鉄道へ移管) / 留萌本線 留萌〜増毛 2016.12 16.7 / 石勝線 夕張支線 2019.4 16.1 / 札沼線 北海道医療大学〜新十津川 2020.5 47.6 / 日高本線 鵡川〜様似 2021.4 116.0 / 留萌本線 石狩沼田〜留萌 2023.4 35.7 / 根室本線 富良野〜新得 2024.4 81.7 / 留萌本線 深川〜石狩沼田 2026.4 14.4 | 各種資料 |
| 開業 | 海峡線 中小国〜木古内 1988.3.13 87.8km | 同上 |

補足:

- 「今の約1.5倍」は 3,176.6km ÷ 2,091.7km(在来線どうし)= 約1.52倍。「約3分の1が消えた」は (3,176.6 − 2,091.7) ÷ 3,176.6 = 約34%。
- 厳密には、1988年3〜4月(海峡線開業後、歌志内線廃止前)が営業キロの最大で、計算上は約3,193kmです。動画では区切りのよい発足時の数字を「最盛期」として使っています。
- 縮小シーンの営業キロのカウンターは、上表の増減を時系列に積み上げ、終点が公式値 2,091.7km に一致するよう比例配分しています(線路の付け替えなどで生じる約3kmの差を吸収するため。途中の数値は目安)。
- 路線図は主要駅の位置を結んだ模式図で、正確な線形ではありません(動画内にも明記)。海岸線は [dataofjapan/land](https://github.com/dataofjapan/land) の都道府県 GeoJSON を簡略化したものです。

## 再生成

```bash
cd jr-hokkaido-peak-network
./build.sh
```

| ファイル | 役割 |
|---|---|
| `narrate.py` | 原稿(`SCRIPT`)を VOICEVOX:四国めたん(style 2)で合成し、ナレーションの長さからシーンの開始時刻を決めて `timings.js`・`output/narration.wav`・字幕SRT を出力 |
| `render.html` | Canvas 2D で `render(t)` が時刻 t のフレームを描画(ブラウザで開くとプレビュー再生)。`lines.js`(駅座標・路線・廃止イベント)、`coast.js`(海岸線)、`timings.js` を読む |
| `capture.js` | Playwright で1フレームずつ撮影し ffmpeg で mp4 化。BGM 同期用に `output/sync.json`(廃止イベント等の時刻)も書き出す。`--stills 1,10` で確認用の静止画 |
| `bgm.py` | `sync.json` に合わせて124BPMのBGMを合成(展開・インパクト音が映像と同期) |
| `mix.py` | ナレーション中にBGMを自動で下げて(ダッキング)ミックスし、-14 LUFS に正規化して最終mp4を作成 |
| `prep_geo.py` | `data/japan.geojson` から北海道・青森の海岸線を抜き出して `coast.js` を作る(通常は再実行不要) |

必要なもの: Node.js + `playwright`(Chromium)、ffmpeg、Python 3 + numpy + `pyopenjtalk`(辞書用)+ `voicevox_core`。

### VOICEVOX のセットアップ

| 必要なもの | 取得元 | 環境変数 |
|---|---|---|
| `voicevox_core-0.17.1-cp310-abi3-manylinux_2_34_x86_64.whl` | VOICEVOX/voicevox_core releases → `pip install` | — |
| `voicevox_onnxruntime-linux-x64-1.17.3.tgz` | VOICEVOX/onnxruntime-builder releases | `VOICEVOX_ORT`(`lib/libvoicevox_onnxruntime.so`) |
| `0.vvm`(四国めたん・ずんだもん等) | VOICEVOX/voicevox_vvm releases | `VOICEVOX_VVMS`(置いたディレクトリ) |

VOICEVOX の音声を公開する際は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画の最後と説明文に記載済み)。
