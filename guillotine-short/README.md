# ギロチンの歴史 — ショート動画

「人道的な処刑」のために生まれたギロチンの誕生から廃止までを追う縦型ショート動画(1080×1920 / 30fps / 約73秒)。
ナレーションは **VOICEVOX:四国めたん(ノーマル)**、BGM はプログラムで合成した自作曲(権利フリー)です。

- 完成動画: `output/guillotine_short.mp4`(-14 LUFS 正規化済み・ステレオ AAC)
- 字幕: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.png`

## 構成

| シーン | 内容 |
|---|---|
| タイトル | 「人道的」な処刑機械の物語(刃が落ちる演出+効果音) |
| 以前の死刑 | 貴族は剣で斬首、庶民は絞首刑・車裂き — 身分で方法が違った |
| 1789年 | 医師ギヨタンの提案:身分に関係なく・同じ方法で・苦痛なく |
| 構造 | 設計 アントワーヌ・ルイ / 製作 トビアス・シュミット、斜めの刃、1792.4.25 最初の執行 |
| 恐怖政治 | 1793–94年、全土で約1万7千人に死刑判決 |
| 処刑された人々 | ルイ16世 / マリー・アントワネット / ロベスピエール |
| 見世物 | 公開処刑に群衆、おもちゃのギロチンも売られた |
| 終わり | 1939 最後の公開処刑 → 1977 最後の執行 → 1981 死刑廃止 |
| トリビア | ギヨタン本人はギロチンで処刑されていない(1814年に病死) |
| クレジット | VOICEVOX:四国めたん / BGM 自作 |

人数・寸法(高さ約4m、刃と重り約40kg)などは資料により幅があるため概数です。残酷な描写は避け、機械は簡略化した線画のみで表現しています。

## 再生成

```bash
python3 narrate.py   # ナレーション合成 → 実尺からシーン割り timings.js を生成、BGM・効果音をミックス(output/mix.wav)
node capture.js      # render.html を1フレームずつ撮影 → output/guillotine_video.mp4
./mux.sh             # 映像+音声を合成し -14 LUFS に正規化 → output/guillotine_short.mp4
```

- 原稿は `narrate.py` の `SCRIPT`(読み上げ用/字幕用の2表記)。書き換えて上の3コマンドを再実行すれば、尺も自動で合います。
- VOICEVOX CORE 0.17.1 + `0.vvm`(四国めたん等)+ Open JTalk 辞書が必要。セットアップは `../pacific-war-analysis/README.md` と同じで、モデルだけ `0.vvm` を使います。スタイルは `VOICEVOX_STYLE`(2=ノーマル, 0=あまあま, 6=ツンツン, 4=セクシー)。
- 公開時は VOICEVOX 利用規約に従い「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文に記載してください)。
