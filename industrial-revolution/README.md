# 産業革命 — 世界を変えた100年 — ショート動画

18世紀後半のイギリスで始まった産業革命を、数字でたどる縦型ショート動画です(1080×1920 / 30fps / 約67秒)。ナレーションは VOICEVOX:四国めたん(ノーマル)で、BGM と字幕が付いています。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)
- 完成動画(ナレーション+BGM): `output/industrial_revolution_narrated.mp4`
- 無音版: `output/industrial_revolution.mp4` / ナレーションのみ: `output/narration.wav` / BGMのみ: `output/bgm.wav`

## 再生成の方法

```bash
cd industrial-revolution
node capture.js              # output/industrial_revolution.mp4 (無音版)
python3 narrate.py           # 四国めたんのナレーション + BGM ダッキングミックス → output/industrial_revolution_narrated.mp4
python3 bgm.py 67.5 bgm.wav  # BGM のみ
./export_upload.sh           # upload/ にアップロード用一式(-14 LUFS 正規化・ステレオAAC・SRT・JPG)
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画する(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright でフレームごとに撮影し、ffmpeg で mp4 にする
- `bgm.py` … 「機械の時代」風のBGM。Aマイナー、96BPM。ピチカート風のオスティナート、パッド、ベース、時計のようなチクタク音、ピストン風のキックと蒸気音を numpy だけで合成する。外部音源を使わないため権利表記は不要
- `narrate.py` … シーンごとの原稿を VOICEVOX(四国めたん ノーマル, style 2)で合成し、シーンの長さに収まるよう話速を自動で調整する。BGM はナレーション中に自動で音量を下げてミックスする。`VOICEVOX_STYLE=0`(あまあま)/`6`(ツンツン)/`4`(セクシー)でスタイルを変えられる
- VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じ手順。音声モデルは `0.vvm`(四国めたん・ずんだもんほか)を使う

VOICEVOX の音声を公開する場合は、利用規約に従い「VOICEVOX:四国めたん」のクレジット表記が必要です(動画の最後のカードと説明文に記載済み)。

色は「以前・世界平均・手作業」が青 `#5E9FD6`、「イギリス・機械・産業革命後」が銅色 `#E5793B` です。
