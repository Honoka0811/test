# 七つ目 — 学校の七不思議 × コックリさん ホラーショート

「うちの学校の七不思議には、七つ目がありません。」
放課後、七つ目をコックリさんに聞いた3人。十円玉が示したのは「い・れ・て」だった——。
「午前2時のノック」(`../horror-knock/`)の核にある「ノック=入っていいか聞くもの」を、
コックリさんの「おいでください」(=自分たちから招く儀式)と組み合わせて再構築した、オリジナルの短編ホラーです。
ナレーションは四国めたん(VOICEVOX)、縦型 1080×1920 / 30fps / 約75秒。

- **完成動画: `output/nanatsume.mp4`**(ナレーション・効果音・字幕焼き込み済み)
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt` / タイムライン: `output/timeline.json`

> ⚠ 終盤(約 1:08)に大きな音と顔が出るジャンプスケアがあります。

## 構成

| 時間 | シーン | 内容 |
|---|---|---|
| 0:00 | 夜の廊下 | 壊れかけのチャイム。「うちの学校の七不思議には、七つ目がありません。」 奥の非常口の緑の光の中に、かすかな人影 |
| 0:04 | タイトル | 学校の七不思議 / 七つ目 |
| 0:06 | 黒板 | 誰もいないのに、一〜六がチョークで書かれていく。「七、」の下線を引いている途中でチョークが折れる |
| 0:12 | コックリさん(夕方) | 「コックリさん、コックリさん。七つ目を教えてください」(3人の声)。十円玉が「い」「れ」「て」 |
| 0:27 | 教室の引き戸 | すりガラスの向こうの人影が戸を3回叩き、ガラスに手を押しつける。壁の時計は4時44分 |
| 0:32 | コックリさん(夕闇) | 「お帰りください」→ 十円玉は「いいえ」。誰かが指を離す(=儀式の禁忌) |
| 0:38 | 自分の部屋の窓 | その夜から毎晩、窓が叩かれる。カーテン越しに手の影が増えていく |
| 0:45 | 時計 | 4:43 → 4:44。ノックが、来ない |
| 0:50 | 暗い寝室 | 「ノックって、入っていいかたずねるためのもの」。ドアがいつの間にか開き、指が縁をつかむ |
| 0:59 | 回想(セピア) | あの日、最初に唱えた言葉——「コックリさん、コックリさん、おいでください」。十円玉は「はい」へ |
| 1:04 | 暗転 | 耳元で「だから、来たよ」 |
| 1:07 | ジャンプスケア | |
| 1:09 | 黒板(アウトロ) | 空欄だった七つ目に、赤いチョークで「いれて」。「七つ目、知ってしまいましたね。」→ 3回のノック |

伏線: 七不思議の四つ目「四時四十四分の鏡」/ 教室の時計とノックが来ない時刻の 4:44。
アウトロで視聴者も「七つ目を知った人」になる(=冒頭の「知った人はいなくなる」につながる)。

## 声と音

- ナレーションはすべて **VOICEVOX:四国めたん**
  - 語り = ノーマル / 「七つ目、知ってしまいましたね」= ヒソヒソ
  - コックリさんを唱える3人 = 四国めたんのヒソヒソ×2(声の高さを変えて)+ささやきを、左右に振って少しずつずらして重ねた合唱。回想では帯域を狭め、テープの揺れと長い残響で「記憶の声」に
  - 「だから、来たよ」= ささやきを約3半音下げ、逆残響で吸い込むように始まり、右耳のすぐ後ろに定位(イヤホン推奨)
- 効果音はすべて numpy/scipy で合成(外部音源なし): テープが伸びたように揺れて下がっていく学校のチャイム(ウェストミンスターの鐘の旋律=パブリックドメイン)、チョークの筆記音と折れる音、遠くのカラス、紙の上を十円玉がすべる音(動く速さに合わせて強弱)、教室の引き戸のノック(木+ガラスのびびり)、心音、緊張音、スケアの衝撃音
- 音量: 全体 約 -16 LUFS / トゥルーピーク -1.2 dBTP。スケアだけがナレーションより約 +7.5dB 大きい

## 再生成

```bash
cd horror-kokkuri
./setup.sh      # VOICEVOX CORE 0.17.1・ONNX Runtime・音声モデル(0.vvm, 5.vvm)・Noto Serif JP
./build.sh      # 音声 → 映像 → サムネイル → 合成 → output/nanatsume.mp4
```

- `audio.py` の `TIMELINE` が台本。十円玉の動き(`coin` の `path`)、黒板の書き込み(`chalk`)、ノックの時刻も台本に書いてあり、映像と音が同じ時刻を使う
- `render.html` … 全シーンを Canvas 2D でコード描画(コックリさんの紙・十円玉・指・黒板・廊下・引き戸など)
- `capture.js` … `--stills 1.0,30.5` で確認用の静止画、`--thumb` でサムネイル
