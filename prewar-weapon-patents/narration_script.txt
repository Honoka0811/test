# ナレーション原稿(VOICEVOX:四国めたん ノーマル などに貼り付け用)
# 形式: 開始秒 / シーン長 / 原稿。各行を1つの音声として書き出し、開始秒+0.45秒の位置に配置する。

[  0.0s /  8.5s] 戦前の日本では、兵器にかかわる発明が、特許としてどう扱われていたのでしょうか。今回はその歴史を、数字でたどります。
[  8.5s / 13.5s] 日本の特許制度は、千八百八十五年の専売特許条例から始まりました。特許第一号は、ほったずいしょう(堀田瑞松)のさび止め塗料。鉄の船底を守るこの発明は、海軍の軍艦にも採用されました。
[ 22.0s / 17.5s] 軍事上秘密とされた発明を公開しない、秘密特許という制度もありました。指定するのは陸軍大臣と海軍大臣。審査官のおよそ二割は、陸海軍の技術将校でした。件数は明治に二十四件、大正に百十六件、昭和には千四百三十二件へ急増します。
[ 39.5s / 16.5s] 一方、主力兵器の多くは海外の特許に頼っていました。零戦の二十ミリ機銃は、スイス・エリコン社のライセンス。三式戦闘機のエンジンはドイツのダイムラー・ベンツ製で、陸軍系の川崎と海軍系の愛知が、別々にライセンスを取得しました。
[ 56.0s / 18.5s] 逆に、日本発の発明が生かされなかった例もあります。やぎひでつぐ(八木秀次)と宇田新太郎のアンテナは、千九百二十六年に特許となりましたが、日本軍は重視しませんでした。千九百四十二年、シンガポールで押収した英軍のレーダー資料に「ヤギ」の名があった、という逸話が残っています。
[ 74.5s / 15.0s] 材料の特許も、兵器を支えました。千九百三十五年、海軍の要請で住友金属の五十嵐勇が開発したちょうちょうジュラルミン(超々ジュラルミン)は、一年以内に特許出願され、零戦の主翼の桁に使われて、機体を軽くしました。
[ 89.5s / 15.5s] 戦時には、敵国の特許そのものが標的になりました。千九百十七年の工業所有権戦時法で、敵国民の特許は効力を失い、ドイツ発の医薬品などが国内で作られます。この法律は、千九百四十二年に再び発動されました。
[105.0s / 11.5s] 秘密特許と戦時法は、千九百四十八年、戦争放棄をうたう新憲法のもとで廃止されました。発明を守る制度は、戦争とともに、形を変えてきたのです。
