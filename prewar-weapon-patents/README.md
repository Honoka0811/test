# 戦前の兵器と特許 — ショート動画

明治の専売特許条例(1885年)から秘密特許制度の廃止(1948年)まで、戦前の日本で兵器にかかわる発明が
特許としてどう扱われたかをたどる縦型ショート動画(1080×1920 / 30fps / 約117秒)です。
ナレーションは VOICEVOX の **四国めたん**(ノーマル)、BGM は numpy で合成した自作曲(権利フリー)です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)
- 完成動画(ナレーション+BGM): `output/prewar_weapon_patents_narrated.mp4`
- 完成動画(無音・字幕なし): `output/prewar_weapon_patents.mp4`
- ナレーション音声のみ: `output/narration.wav`
- サムネイル: `output/thumbnail.png`
- ナレーション原稿: `narration_script.txt`

## 再生成の方法

```bash
cd prewar-weapon-patents
node capture.js            # output/prewar_weapon_patents.mp4 (無音版) を生成
python3 narrate.py         # ナレーション合成 + BGM ミックスで output/prewar_weapon_patents_narrated.mp4 を生成
node thumb.js 4.5          # output/thumbnail.png (タイトル画面) を書き出す
./export_upload.sh         # upload/ にアップロード用一式を書き出す(-14 LUFS 正規化・ステレオAAC・SRT・JPG)
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright(Chromium)で 1 フレームずつ撮影し、ffmpeg(libx264)にパイプして mp4 化
- `thumb.js` … 任意の時刻のフレームを PNG で書き出す
- `bgm.py` … ドキュメンタリー風BGM(Dマイナー、72BPM。低音ドローン+倍音パッド+和太鼓風の打音+まばらなアルペジオ)を numpy だけで合成
- `narrate.py` … シーンごとの原稿を VOICEVOX(四国めたん ノーマル, style 2)で合成し、各シーンの長さに収まるよう話速を自動調整(基準 1.2)。BGM はナレーション中に自動で音量を下げてミックス。`voicevox_core` が無い環境では Open JTalk にフォールバック
- 固有名詞の読みは VOICEVOX が誤読するため、読み上げ用原稿のみ「ほったずいしょう」「やぎひでつぐ」「ちょうちょうジュラルミン」とかなで書いています(字幕は漢字表記)
- 必要なもの: Node.js, `playwright`(Chromium), `ffmpeg`, 日本語フォント(IPAゴシック), Python 3 + `numpy`

### VOICEVOX のセットアップ(ナレーション用)

| 必要なもの | 取得元 | 環境変数 |
|---|---|---|
| Python ラッパー `voicevox_core-0.17.1-cp310-abi3-manylinux_2_34_x86_64.whl` | VOICEVOX/voicevox_core releases → `pip install` | — |
| ONNX Runtime `voicevox_onnxruntime-linux-x64-1.17.3.tgz` | VOICEVOX/onnxruntime-builder releases | `VOICEVOX_ORT`(展開後の `lib/libvoicevox_onnxruntime.so`) |
| 音声モデル `0.vvm`(四国めたん・ずんだもん ほか) | VOICEVOX/voicevox_vvm releases | `VOICEVOX_VVMS`(置いたディレクトリ) |
| Open JTalk 辞書 `open_jtalk_dic_utf_8-1.11` | open-jtalk (SourceForge) | `VOICEVOX_DICT` |

スタイルを変える場合は `VOICEVOX_STYLE=0 python3 narrate.py`(0 = あまあま、6 = ツンツン、4 = セクシー)のようにします。
VOICEVOX の音声を公開する場合は、利用規約に従い「VOICEVOX:四国めたん」のクレジット表記が必要です(動画の最後のカードと `upload/metadata.md` に記載済み)。
