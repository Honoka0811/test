# 満洲国の主要都市 人口ランキング＋鉄道網 — ショート動画

満洲国(1932〜1945年)の主要都市を地図上に示しながら、人口ランキング(5位→1位、番外編の大連)と
鉄道網を紹介する縦型ショート動画です(1080×1920 / 30fps / 約110秒)。

- **完成動画: `output/manchukuo_cities_final.mp4`**(ナレーション・BGM・効果音入り、-14 LUFS、ステレオ AAC)
- 映像のみ(無音): `output/manchukuo_cities.mp4`
- 字幕: `output/subtitles_ja.srt`(画面にも焼き込み済み)
- サムネイル: `output/thumbnail.jpg`
- 音声素材: `output/narration.wav` / `output/bgm.wav` / `output/sfx.wav` / `output/mix.wav`(mix.wav は git 管理外)

- 人口は 1940年の臨時人口調査(『康徳七年 臨時人口調査報告』)系の数値を、二次資料(日本語版 Wikipedia「満洲国」「新京特別市」の表、研究論文)から引用しました。集計機関や市域の取り方で値が異なるため、動画内でも「概数」と明記しています。
- 統計上の「日本人」には朝鮮人・台湾人を含む場合があります。
- 満洲国の面積(約115万km²、日本の約3倍)、人口(1940年 約4,300万人)、特急「あじあ」(1934年運行開始、大連〜新京 約701km を 8時間30分)は一般的な概説書の値です。
- 鉄道の路線は主要駅を直線で結んだ概略です。国境線は Natural Earth の現在の中国国境の東北部分に、熱河省・興安省の西端を手で近似した線を継ぎ足しています。

## 再生成の方法

```bash
cd manchukuo-cities
python3 geo.py <Natural Earth geojson のディレクトリ>   # geo.js(地図データ)を作る。リポジトリには生成済みの geo.js を同梱
python3 tts.py               # ナレーション合成 → timing.js(シーン尺・字幕)、output/narration.wav、output/subtitles_ja.srt
node capture.js output/manchukuo_cities.mp4   # 映像(無音)を書き出す
python3 mix.py               # BGM・効果音を合成してミックスし、output/manchukuo_cities_final.mp4 を書き出す
node snap.js 5 40 60         # 確認用: 指定秒のフレームを output/snaps/ に PNG で保存
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)。地図は経度方向を cos(44°) で補正した正距円筒図法で、カメラ(中心・ズーム)をキーフレームで補間
- `tts.py` … VOICEVOX(青山龍星 ノーマル、style 13)でシーンごとにナレーションを合成し、その長さからシーン尺を決める。原稿は読み上げ用(一部かな書き)と字幕用の2本立て
- `music.py` … BGM(Dマイナー・90BPM のミステリアスなドキュメンタリー調、Dm–B♭–Gm–A。低音ピアノの反復フレーズ+ストリングス風パッド+低いドローン+心音のようなキック+時計の刻み+まばらなオルゴール。順位が上がるほど弦の対旋律などが加わり、1位の発表は低い弦の一撃)と効果音(丸い「ポン」、グロッケンの「シャラン」、柔らかいウーッシュ、タムロール、汽笛)を numpy/scipy だけで合成。効果音は高域を 8kHz 以下に抑え、ナレーションより約11dB小さくミックス。外部音源を使わないため権利表記は不要
- `mix.py` … ナレーション中は BGM を自動で下げて(ダッキング)ミックスし、-14 LUFS に正規化
- 必要なもの: Node.js + `playwright`(Chromium)、`ffmpeg`、日本語フォント(IPAゴシック)、Python 3 + `numpy` + `scipy` + `voicevox_core`

VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じです(voicevox_core 0.17.1、ONNX Runtime 1.17.3、`15.vvm`、Open JTalk 辞書)。
VOICEVOX の音声を公開する場合は、利用規約に従い「VOICEVOX:青山龍星」のクレジット表記が必要です(動画の最後に表示、説明文にも記載してください)。
