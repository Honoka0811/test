# 日本の絶景5選 — 旅行ショート動画

「海外行く前に見て。日本の"世界レベル"絶景5選」をテーマにした縦型ショート動画です(1080×1920 / 30fps / 約59秒)。
ナレーションは **VOICEVOX:四国めたん**(ノーマル)。BGM・効果音・映像はすべてコードで合成したオリジナルなので、外部素材の権利処理は不要です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグ/固定コメント/チェックリストの `metadata.md`)
- サムネイル(PNG): `output/thumbnail.png`
- シーンのタイミング: `output/timeline.json`(ナレーションの実測から自動生成)

## 構成(約59秒)

| 時間 | シーン | ナレーション | 演出 |
|---|---|---|---|
| 0:00–0:06 | フック | 海外、行かなくてよくない? 日本の世界レベル絶景、5つ、いくよ | 画面揺れ+パンチイン、5スポットの0.3秒ティザーカット、「5選」バースト |
| 0:06–0:15 | 5位 角島大橋(山口) | 全長1,780m、通行無料 | 橋の上を走る車、全長カウンター、BGMドロップ |
| 0:15–0:23 | 4位 与那覇前浜(宮古島) | 7kmの白い砂浜、東洋一のビーチ | 揺れるヤシの木、波打ち際、7kmカウンター |
| 0:23–0:32 | 3位 竹田城跡(兵庫) | 雲海に浮かぶ天空の城、狙い目は夜明け前 | 流れる雲海、昇る朝日、雲海シーズンの表示 |
| 0:32–0:41 | 2位 青ヶ島(東京) | 二重カルデラの島、人口約170人、船かヘリだけ | 空撮風の島、ヘリと船、170人カウンター。最後にBGMを抜いて溜める |
| 0:41–0:51 | 1位 父母ヶ浜(香川) | 干潮と夕暮れが重なる瞬間、浜が鏡になる | 夕日+鏡面反射が完成する瞬間にきらめき音、BGM再ドロップ |
| 0:51–0:59 | CTA | 次の休み、どこ行く? コメントで教えてね | 順位のおさらい、コメント/保存/いいねボタン、クレジット |

全編を通して、上部に進捗バーと順位マーカー、下部に話している言葉だけを大きく出す字幕(数字は黄色)、シーン切替のフラッシュとウーッシュ音を入れています。

## BGM

`bgm.py` がトロピカルハウス風の曲(Fメジャー / 122BPM / F–C–Dm–B♭)を numpy だけで合成します。
4つ打ちキック、クラップ、ハイハット、サイドチェインの効いたベースとパッド、スチールパン風のリフ、裏打ちのコードスタブ、ライザーとクラッシュで構成しています。
5位の開始と1位の開始に「ドロップ」を置き、1位の直前はドラムを抜いて溜めを作ります。
ナレーション中はBGMを自動で下げます(ダッキング)。

## 再生成の方法

```bash
cd travel-shorts
python3 narrate.py         # ナレーション合成 → output/narration.wav, timeline.json, subtitles_ja.srt
node capture.js            # 映像を撮影 → output/video_silent.mp4
python3 mix.py             # BGM + 効果音 + ナレーションをミックス → output/video_narrated.mp4
./export_upload.sh         # upload/ に書き出し(-14 LUFS・リミッター・ステレオAAC・SRT・サムネイル)
```

- `narrate.py` … 原稿は `SCENES` にあります。字幕用の表記と読み上げ用のかなを組で持ち、読点ごとの発話時刻を VOICEVOX の音素長から求めて字幕と演出を同期させます
- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画します。`python3 -m http.server` で配信してブラウザで開くとプレビュー再生します
- `capture.js` … Playwright(Chromium)で1フレームずつ撮影し、ffmpeg(libx264)でエンコードします。`--frame 12.5 out.png` で1枚だけ、`--thumb out.png` でサムネイルを書き出せます
- `bgm.py` / `sfx.py` … BGM と効果音(ウーッシュ、ポップ、カウンターの刻み、ディン、きらめき、低音のブーム)
- `mix.py` … ダッキングしながらミックスし、映像と多重化します
- 必要なもの: Node.js + `playwright`(Chromium)、`ffmpeg`、日本語フォント(IPA Pゴシック)、数字用フォント(Inter Display)、Python 3 + `numpy` + `pyopenjtalk`(辞書用) + `voicevox_core`

### VOICEVOX のセットアップ

| 必要なもの | 取得元 | 環境変数 |
|---|---|---|
| `voicevox_core-0.17.1-cp310-abi3-manylinux_2_34_x86_64.whl` | VOICEVOX/voicevox_core releases → `pip install` | — |
| `voicevox_onnxruntime-linux-x64-1.17.3.tgz` | VOICEVOX/onnxruntime-builder releases | `VOICEVOX_ORT`(展開後の `lib/libvoicevox_onnxruntime.so`) |
| 音声モデル `0.vvm`(四国めたん・ずんだもん等) | VOICEVOX/voicevox_vvm | `VOICEVOX_VVMS`(置いたディレクトリ) |

スタイルは `VOICEVOX_STYLE` で変えられます(2 = 四国めたん ノーマル、0 = あまあま、6 = ツンツン)。話速は `VOICEVOX_SPEED`(既定 1.25)です。
四国めたんの音声を公開する場合は「VOICEVOX:四国めたん」のクレジット表記が必要です。動画の最後と説明文の両方に入れています。

## 内容の出典メモ

- 角島大橋: 全長1,780m、2000年開通、通行無料(山口県下関市)
- 与那覇前浜: 約7kmの白砂のビーチ。「東洋一」と呼ばれる(沖縄県宮古島市)
- 竹田城跡: 雲海に浮かぶ姿から「天空の城」。雲海はおおむね9月下旬〜12月上旬の早朝、前日との寒暖差が大きく晴れた日に出やすい(兵庫県朝来市)
- 青ヶ島: 外輪山の中に内輪山(丸山)がある二重カルデラ。人口は約170人(2020年国勢調査で169人)。八丈島から船またはヘリコプターで渡る(東京都青ヶ島村)
- 父母ヶ浜: 干潮と日没が重なり風が弱い日に、潮だまりが鏡のように空を映す。「日本のウユニ塩湖」と呼ばれる(香川県三豊市)

イラストはすべて Canvas で描いた抽象的なイメージで、実際の景観を正確に再現したものではありません。
