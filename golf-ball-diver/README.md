# ゴルフボールダイバー紹介 — ショート動画

ゴルフ場の池に潜ってロストボールを回収する「ゴルフボールダイバー」を紹介する縦型ショート動画(1080×1920 / 30fps / 53秒)。

- 完成動画: `output/golf_ball_diver.mp4`(ナレーション+BGM+字幕焼き込み、-14 LUFS)
- 字幕: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.png`
- ナレーション: VOICEVOX:四国めたん(ノーマル)  ※公開時はクレジット表記が必要(動画末尾に記載済み)
- BGM: `bgm.py` で numpy 合成した自作曲(Cメジャー/112BPM、マリンバ風)。権利フリー

## 構成

| 時間 | シーン | ナレーション(要旨) |
|---|---|---|
| 0:00–0:06 | タイトル | 池の底に潜る仕事、ゴルフボールダイバーをご存知かしら? |
| 0:06–0:14 | 失われるボール | 米国だけで年間約3億個(推計)、多くが池の底へ |
| 0:14–0:22 | 仕事内容 | ゴルフ場と契約し、閉場後の池で手探り回収 |
| 0:22–0:31 | 過酷さ | 視界ゼロ・冷水・米国南部ではワニやヘビ |
| 0:31–0:39 | 稼ぎ | 1日数千個、腕利きは年収1,000万円超も |
| 0:39–0:47 | その後 | 洗浄→選別→ロストボールとして再販売 |
| 0:47–0:53 | まとめ | 池ポチャのボールにも第二の人生 |

数値は海外報道などで広く引用される概数・推計です(動画内にも明記)。

## 再生成

```bash
python3 narrate.py   # ナレーション合成 → output/cues.json, subtitles_ja.srt, mix.wav(BGMダッキング込み)
node capture.js      # render.html を撮影し mix.wav と合成 → output/golf_ball_diver.mp4
```
VOICEVOX CORE(0.16.1 wheel)、voicevox_onnxruntime 1.17.3、`0.vvm`(四国めたん)が必要。パスは `VOICEVOX_ORT` / `VOICEVOX_VVMS` で指定。
原稿は `narrate.py` の `SCRIPT`(読み上げ用と字幕用の2列)。
