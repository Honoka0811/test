# 戦前の日本 都道府県 人口ランキング TOP10 — ショート動画

1940年(昭和15年)国勢調査の都道府県別人口を、10位から1位までカウントダウンで紹介する
縦型ショート動画(1080×1920 / 30fps / 約67秒)です。

- **完成動画: `output/prewar_population_top10.mp4`**(ナレーション・BGM・効果音入り、-14 LUFS、H.264 + AAC ステレオ)
- 字幕: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.jpg`
- ナレーションのみ: `output/narration.wav`(VOICEVOX:四国めたん ノーマル)/ BGMのみ: `output/bgm.wav`(自作・権利フリー)
- 投稿用のタイトル・説明文・タグ: `metadata.md`

## 構成と演出

| 時間 | シーン | 演出 |
|---|---|---|
| 0:00–0:05 | フック | 「戦前の日本」「人口ランキング」が飛び出し、TOP10 の判子を叩きつけ(ビート開始)。「約85年前、いちばん人が多かったのはどこ？」と問いかけ |
| 0:05–0:41 | 10位→4位 | 順位メダルの叩きつけ(シュッ+ドン・画面揺れ)、地図が該当県へズーム&赤く発光、人口カウンターが回る、人口バー、「現在◯位 ▲▼」バッジ |
| 0:41–1:01 | TOP3 | リズムが止まりドラムロール+ライザー、画面が暗転、地図上をルーレットが走り「？？？」がスクランブル → 発表の瞬間にフラッシュ・クラッシュ・紙吹雪。1位発表後はBGMにブラス風スタブを足して最高潮に |
| 1:01–1:07 | まとめ | 1940年と現在の順位比較表、「今5位の埼玉県は当時15位」の小ネタ、コメント誘導 |

全編で古いフィルム風の粒子・ちらつき・傷・周辺減光をかけ、昭和ポスター風の配色(墨・金・朱)にしています。

  府県別の値は [都道府県市区町村 1940年の都道府県人口](https://uub.jp/pjn/pb19401001.html) / [2020年](https://uub.jp/pjn/pb20201001.html) の一覧(国勢調査値)から取得。
- 「戦前」は太平洋戦争開戦前の最後の国勢調査である1940年を採用。当時の全国人口は 73,114,308 人。
- 東京都の成立は1943年のため、1940年時点の名称は「東京府」。
- 地図: [dataofjapan/land](https://github.com/dataofjapan/land) の `japan.geojson` を `make_map.py` で簡略化(沖縄県・遠隔離島は省略)。

## 再生成の方法

```bash
cd prewar-population-ranking
npm install                     # フォント(Dela Gothic One / Noto Sans JP / Shippori Mincho B1)
python3 narrate.py              # VOICEVOX でナレーション合成 → timeline.js・字幕を生成(尺はナレーションで決まる)
node capture.js                 # render.html を1フレームずつ撮影 → output/video_silent.mp4
python3 mix.py                  # BGM・効果音を合成してナレーションとミックス → output/prewar_population_top10.mp4
node capture.js --still 59 output   # 任意の時刻の静止画(サムネイル用)
```

VOICEVOX は `voicevox_core` 0.16 の Python バインディング、`voicevox_onnxruntime` 1.17.3、
`0.vvm`(四国めたん)を使用。パスは環境変数 `VOICEVOX_ORT` / `VOICEVOX_VVMS` で変更できます。
`mix.py` は numpy / scipy が必要です。
