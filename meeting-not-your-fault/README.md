# 伝わらないのは、あなただけのせいじゃない — ショート動画

会議で「何が言いたいの？」「何がしたいの？」と責められて、自分だけが悪いと感じてしまう人へ。
「伝わらない原因は聞く側にあることもある」を伝える縦型ショート(1080×1920 / 30fps / 約66秒)。

- **完成動画: `output/tsutawaranai_anatadake_janai.mp4`**(ナレーション＋BGM＋字幕焼き込み、-14 LUFS)
- 字幕ファイル: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.jpg`

## 構成

| 時間 | シーン | 内容 |
|---|---|---|
| 0:00–0:08 | つかみ | 「何が言いたいの？」「で、何がしたいの？」の吹き出し |
| 0:08–0:14 | 自責 | 雨雲「自分が悪いんだ…」 |
| 0:14–0:19 | 問いかけ | 本当に「あなただけ」のせい？ |
| 0:19–0:27 | 共同作業 | 話す人と聞く人、原因は両側にありうる |
| 0:27–0:44 | 3つのサイン | 遮る／責めるだけで質問しない／目的を共有していない |
| 0:44–0:54 | 返し方 | 「どの部分が分かりにくかったですか？」と聞き返す |
| 0:54–1:00 | 抱え込まない | 「伝え方」と「聞き方」を半分ずつ |
| 1:00–1:06 | まとめ | 伝わらないのは、あなただけのせいじゃない。 |

## 素材とクレジット

- ナレーション: **VOICEVOX:四国めたん**(ノーマル、最後の一言のみ「あまあま」)。公開時はこのクレジット表記が必要(動画のエンドカードに記載済み。概要欄にも書くのがおすすめ)
- BGM: `bgm.py` で numpy から合成したオリジナルのLo-fi風曲(Fメジャー/82BPM、19秒以降にビート)。権利表記不要
- フォント: M PLUS Rounded 1c(SIL Open Font License)。`build.sh` が取得

## 再生成

```bash
./build.sh
```

- `narrate.py` … 原稿(`LINES`)を VOICEVOX で合成し、セリフの長さからシーン尺を決めて `timeline.js` と SRT を書き出す。原稿を変えれば尺も自動で追従
- `render.html` … Canvas で `render(t)` がフレームを描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright で全フレームを撮影し ffmpeg で mp4 化
- `mix.py` … BGM を発話中だけ下げて(ダッキング)ミックスし、-14 LUFS に正規化して合成
- VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じ(音声モデルは四国めたんを含む `0.vvm`)。パスは環境変数 `VOICEVOX_ORT` / `VOICEVOX_VVMS` / `VOICEVOX_DICT` で指定
