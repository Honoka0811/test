# 祖母の家の決まり — ホラーショート動画(7本目)

縦型ショート動画(1080×1920 / 30fps / 約58秒)。アプリ画面を使わない、昔ながらの怪談です(オリジナル)。

- 完成動画: `output/sobo_no_kimari.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、障子の向こうの声=ささやき、祖母=ノーマルを低くゆっくり、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(都節音階の琴風の旋律、低いドローン、鈴虫、風鈴、太鼓、小鳥、布団のこすれる音、心音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。障子に映る影絵と、真上から見た和室の2種類の絵で進む |
| フォント | しっぽり明朝(OFL-1.1) |

## 演出

- 障子に老婆の影が映った瞬間、鈴虫の声と琴が止まる
- 夜の場面は布団が2組、朝の場面は1組。絵だけでオチが分かる
- 最後は、障子の明かりを背にした影として「隣の布団」がゆっくり起き上がる(手や顔は描かず、影だけで見せる)

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
