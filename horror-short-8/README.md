# もういいよ — ホラーショート動画(8本目)

縦型ショート動画(1080×1920 / 30fps / 約56秒)。夕暮れの神社のかくれんぼを題材にした、オリジナルの怪談です。アプリ画面は使いません。

- 完成動画: `output/mou_ii_yo.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、子どもの声=あまあま・ツンツン・ノーマルを高めに、4人目の返事=ささやき、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(遠くのスピーカーから流れる夕方のチャイム風の旋律、ひぐらし、カラス、風、砂利を踏む足音、太鼓、心音)。旋律は自作。外部音源なし |
| 映像 | `render.html` の Canvas 描画。影絵の神社(奥行きごとの層を重ねて視差をつける)と、夕日でのびた影が歩く帰り道 |
| フォント | しっぽり明朝(OFL-1.1) |

## 演出

- 「もういいよ」の返事は、それぞれの隠れ場所の近くに文字で出る
- 奥から声がした瞬間、チャイムもひぐらしも風も止まる
- 帰り道は影だけを映す。4人の影は歩いて揺れるが、5つ目は揺れずについてくる
- みんなが立ち止まったあとも、ひとりぶんの足音だけが近づいてくる

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
