# 犬派 VS 猫派 対決! — ショート動画

犬キャラと猫キャラが4ラウンド+サドンデスで対決する縦型ショート動画(1080×1920 / 30fps / 約55秒)。
ナレーションは VOICEVOX:四国めたん(ノーマル)、BGM・効果音は numpy で合成したオリジナル(権利フリー)。
仕組みは `../morning-vs-night/` と共通(シーン構成とキャラ・BGMの曲を変更)。

- 完成動画: `output/dog_vs_cat.mp4` / 字幕: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.png`

## 構成

| シーン | 内容 |
|---|---|
| タイトル | 犬派 VS 猫派 どっちが上!? |
| 選手入場 | 赤コーナー 犬派(しっぽフリフリ)/ 青コーナー 猫派(気まぐれクール) |
| ROUND 1 癒やし | 猫派の勝ち(ゴロゴロ音) |
| ROUND 2 なつき度 | 犬派の勝ち(呼べば来る) |
| ROUND 3 お世話のラクさ | 猫派の勝ち(散歩不要・留守番OK) |
| FINAL ROUND 健康 | 犬派の勝ち(散歩で飼い主も運動) |
| SUDDEN DEATH かわいさ | 判定不能 → 両者優勝 |
| エンディング | あなたは犬派?猫派? コメントで教えてね |

## 再生成

```bash
./build.sh
```

BGM は Fメジャー・112BPM のスウィング(跳ねる)リズム。必要な VOICEVOX 一式と環境変数は `../morning-vs-night/README.md` を参照。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画のエンディングにも記載済み)。
