## 1000万再生を狙うための設計メモ

| 要素 | この動画での仕掛け |
|---|---|
| 冒頭2秒で止める | 「1秒に1円ずつ数えてみます」+ 実際に毎秒増えるカウンター。ルールが一瞬で分かる |
| 答えを知りたくさせる | 3秒目で「1兆円まで何年かかる?」と質問。答えは32秒目まで引っ張る |
| 離脱させない構造 | 1万→100万→1億→10億→1兆と桁が4つずつ上がる階段。次の答えを予測しながら見るので飛ばしにくい |
| 感情のピーク | 国家予算 / 国の借金で「人類誕生前から数えている」という驚き → 最後に自分の年収(53日)で落差を作る |
| コメントを誘発 | 「あなたの年収は何日?」で自分の数字を計算して書きたくなる。固定コメントで計算式を置く |
| シェアされやすさ | 数字と図だけで意味が伝わるため、言語に依存しにくい。英語字幕を同梱 |
| 再視聴性 | 情報密度が高く、67秒で9つの数字。見返しや一時停止が起きやすい |
| 横展開 | 「1秒に1円」シリーズ化が可能: 世界の富豪、企業の時価総額、宝くじ、スマホ代、ガチャ、世界のGDP など |
