# 1秒に1円ずつ数えたら、1兆円は何年かかる? — ショート動画

「1秒 = 1円」というルールで、1万円から国の借金1,323兆円まで数えるのに何年かかるかを数字と図で見せる
縦型ショート動画(1080×1920 / 30fps / 67秒)です。ナレーション付き、日本語・英語字幕付き。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT(日/英)・サムネイルJPG・タイトル/説明文/タグ/戦略メモの `metadata.md`)
- 完成動画(ナレーション付き): `output/yen_per_second_narrated.mp4`
- 完成動画(無音・映像のみ): `output/yen_per_second.mp4`
- ナレーション音声のみ: `output/narration.wav` / BGMのみ: `output/bgm.wav`(自作・権利フリー)
- サムネイル: `output/thumbnail.png`

## 使用データと計算

| 項目 | 値 | 秒数 | 換算 | 出典 |
|---|---|---|---|---|
| 1万円 | 10,000 | 10,000秒 | 2時間46分40秒 | — |
| 100万円 | 1,000,000 | 10^6秒 | 11.574日 = 11日13時間46分40秒 | — |
| 1億円 | 10^8 | 10^8秒 | 1,157.4日 = 3.17年 ≈ 3年2ヶ月 | — |
| 10億円 | 10^9 | 10^9秒 | 11,574日 = 31.69年 ≈ 31年8ヶ月 | — |
| 1兆円 | 10^12 | 10^12秒 | 31,688年 | — |
| 国家予算(2025年度一般会計) | 約115.2兆円 | 1.152×10^14秒 | 約365万年 | 財務省 令和7年度予算 |
| 国の借金(2025年3月末) | 約1,323兆円 | 1.323×10^15秒 | 約4,193万年 | 財務省「国債及び借入金並びに政府保証債務現在高」 |
| 平均給与(令和5年分) | 460万円 | 4.6×10^6秒 | 53.24日 = 53日5時間46分 | 国税庁 民間給与実態統計調査 |

1年 = 365.25日 = 31,557,600秒。年代(縄文時代の開始 約1.6万年前、最古の石器 約260万年前、ホモ・サピエンス 約30万年前、恐竜絶滅 約6,600万年前、最古の人類 約700万年前)は概説書で一般的な概数です。

## 再生成の方法

```bash
cd yen-per-second
node capture.js                       # output/yen_per_second.mp4 (無音版) を生成
node capture.js --thumb               # output/thumbnail.png を生成
node capture.js --preview 3,10,20     # 指定秒の静止画を output/preview/ に書き出し(確認用)
python3 narrate.py                    # ナレーション合成 + BGM ミックス → output/yen_per_second_narrated.mp4 と字幕SRT(日/英)
python3 bgm.py 67 output/bgm.wav      # BGM だけを書き出す場合
./export_upload.sh                    # upload/ にアップロード用一式を書き出す(-14 LUFS 正規化・ステレオAAC)
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)。`thumbnail()` でサムネイル
- `capture.js` … Playwright(Chromium)で 1 フレームずつ撮影し、ffmpeg(libx264)にパイプして mp4 化
- `bgm.py` … Aマイナー / 120BPM。毎秒ちょうどに鳴る時計のチック音(画面の「1秒=1円」の点滅と同期)、パッド、低音パルス、アルペジオ、数字が出る瞬間の「ドン」、場面転換前のライザーを numpy だけで合成。外部音源を使わないため権利表記は不要
- `narrate.py` … シーンごとの原稿を合成し、各シーンの長さに収まるよう話速を自動調整。BGM はナレーション中に自動で音量を下げてミックス。VOICEVOX(`voicevox_core`)があればそれを使い、無ければ Open JTalk(`pyopenjtalk`)にフォールバック
- 必要なもの: Node.js, `playwright`(Chromium), `ffmpeg`, 日本語フォント(IPAゴシック)と Inter(数字用), Python 3 + `numpy` + `pyopenjtalk`

### ナレーションの声を VOICEVOX にする

同梱の完成版は Open JTalk で合成しています(この環境では VOICEVOX を導入できなかったため)。
`../pacific-war-analysis/README.md` の手順で VOICEVOX CORE・ONNX Runtime・音声モデル(`15.vvm` 青山龍星 など)を用意し、
環境変数 `VOICEVOX_ORT` / `VOICEVOX_VVMS` を渡して `python3 narrate.py` を再実行すると、同じ原稿を VOICEVOX の声で差し替えられます。
その場合は動画の説明文のクレジットを「VOICEVOX:青山龍星」に変更してください(VOICEVOX 利用規約)。

配色は金額=金 `#F5C451`、時間/日=緑 `#55D6A6`、年=青 `#4C9BF0`、万年=赤 `#F0575A` の4段階で、桁が上がるごとに色が「熱く」なる設計です。
