# 妹からのメッセージ — ホラーショート動画(2本目)

縦型ショート動画(1080×1920 / 30fps / 約57秒)。チャット画面形式のオリジナル「意味が分かると怖い話」です。

- 完成動画: `output/imouto_message.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(地の文=ノーマル、妹のメッセージ=ささやき、ドア越しの声=あまあま、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(ドローン、低いピアノ、不協和ストリングス、心音、送受信音、ノック、バイブ)。外部音源なし |
| 映像 | `render.html` の Canvas 描画を Playwright で 1 フレームずつ撮影 |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

## 視聴維持のための仕掛け

- 冒頭で「最後の一通で意味が変わる」と予告し、最後まで見る理由を作る
- 妹のメッセージが届く直前に、毎回こもった「送信音」が右寄りで小さく鳴っている(オチの伏線。見返し・コメント誘導)
- ドアの前にいたのは誰か、をあえて説明しない(考察コメント誘導)

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです(VOICEVOX CORE 0.17.1、`0.vvm` と `5.vvm`、`pyopenjtalk`)。
台本は `script.py` を編集してください。公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
