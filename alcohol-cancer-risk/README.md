# 毎日の飲酒量とがんリスクの関係 — ショート動画

「毎日のお酒は、がんのリスクをどれだけ上げるのか」を、WHO/IARC・国立がん研究センター(多目的コホート研究)・厚生労働省ガイドライン(2024年)の数字でたどる縦型ショート動画(1080×1920 / 30fps / 約77秒)です。字幕付きの無音版と、ナレーション+BGM付き版があります。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグ/チェックリストの `metadata.md`)
- 完成動画(ナレーション付き): `output/alcohol_cancer_risk_narrated.mp4`
- 完成動画(無音・字幕なし、画面テキストのみ): `output/alcohol_cancer_risk.mp4`
- ナレーション音声のみ: `output/narration.wav` / 字幕: `output/subtitles_ja.srt`
- サムネイル: `output/thumbnail.png`

補足:
- 相対リスクはいずれも「基準群に対して何倍か」で、絶対リスク(実際に何%の人ががんになるか)ではありません。
- JPHC研究のがん全体の解析(2005年)では、リスク上昇は主に喫煙者で見られ、非喫煙者では明確な上昇が見られていません。動画では尺の都合で省いているため、説明文等で補足するのが望ましいです。
- 日本酒1合(180ml, 15%)は純アルコール約22gで、研究によって「1合 = 23g」として扱われます。
- 数値はすべて公表資料に基づく概数で、動画内でも「推計」「目安」と明記しています。医療上の判断は医師にご相談ください。

## 再生成の方法

```bash
cd alcohol-cancer-risk
node capture.js             # output/alcohol_cancer_risk.mp4 (無音版) を生成
node capture.js --stills 4.5 /tmp/thumb && cp /tmp/thumb/t4_5.png output/thumbnail.png   # サムネイル
python3 narrate.py          # ナレーション合成 + BGM ミックスで output/alcohol_cancer_risk_narrated.mp4 を生成
python3 bgm.py 76.5 bgm.wav # BGM だけを書き出す場合
./export_upload.sh          # upload/ にアップロード用一式を書き出す(-14 LUFS 正規化・ステレオAAC・SRT・JPG)
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright(Chromium)で 1 フレームずつ撮影し、ffmpeg(libx264)にパイプして mp4 化。`--stills` で確認用の静止画を書き出せる
- `bgm.py` … 解説系BGM(Aマイナー、76BPM。柔らかいパッド+低音ドローン+控えめな打音+電子ピアノ風アルペジオ+簡易リバーブ)を numpy だけで合成。外部音源を使わないため権利表記は不要
- `narrate.py` … シーンごとの原稿を合成し、各シーンの長さに収まるよう話速を自動調整。BGM はナレーション中に自動で音量を下げて(ダッキング)ミックスし、動画に合成
- 必要なもの: Node.js, `playwright`(Chromium), `ffmpeg`, 日本語フォント(IPAゴシック), Python 3 + `numpy` + `pyopenjtalk`

### ナレーション音声について

`narrate.py` は VOICEVOX(青山龍星, style 13)を優先し、`voicevox_core` が無い環境では **Open JTalk**(`pyopenjtalk`)にフォールバックします。
現在 `output/` に入っているナレーション付き版は **Open JTalk 版**です(本リポジトリの `pacific-war-analysis` と同じ VOICEVOX の声に差し替える場合は、下記をセットアップして `python3 narrate.py` を再実行してください)。

| 必要なもの | 取得元 | 環境変数 |
|---|---|---|
| Python ラッパー `voicevox_core-0.17.1-cp310-abi3-manylinux_2_34_x86_64.whl` | VOICEVOX/voicevox_core releases → `pip install` | — |
| ONNX Runtime `voicevox_onnxruntime-linux-x64-1.17.3.tgz` | VOICEVOX/onnxruntime-builder releases | `VOICEVOX_ORT`(展開後の `lib/libvoicevox_onnxruntime.so`) |
| 音声モデル `15.vvm`(青山龍星) | VOICEVOX/voicevox_vvm releases | `VOICEVOX_VVMS`(置いたディレクトリ) |
| Open JTalk 辞書 | `pyopenjtalk` 同梱のものを自動使用 | `VOICEVOX_DICT`(任意) |

VOICEVOX の音声を公開する場合は、利用規約に従い「VOICEVOX:青山龍星」のクレジット表記が必要です(`render.html` のまとめカードと `upload/metadata.md` の説明文にクレジット行を追加してください)。

色はアンバー `#F5B942`(お酒・数値)、赤 `#E8524F`(高リスク)、ティール `#3FB8A8`(行動の提案)の3系統です。
