# ハーバー・ボッシュ法がすごすぎる — ショート動画

「空気からパンを作った」と言われるハーバー・ボッシュ法を、約70秒で紹介する縦型ショート動画(1080×1920 / 30fps)です。
ナレーションは **VOICEVOX:四国めたん(ノーマル)**、BGM は numpy で合成した自作曲(権利フリー)。字幕は映像に焼き込み済みです。

- **完成動画: `upload/haber_bosch_short.mp4`**(H.264 + AAC ステレオ、-14 LUFS)
- 字幕ファイル: `upload/subtitles_ja.srt` / サムネイル: `upload/thumbnail.jpg`
- タイトル・説明文・タグ案: `upload/metadata.md`
- 素材: `output/narration.wav`(ナレーションのみ)、`output/bgm.wav`(BGMのみ)

|---|---|---|

| 0:36–0:48 | 世界人口 | 16億 → 82億人、人類の約半分を支える(推計) |
| 0:48–0:56 | あなたの体にも | 体内窒素の約半分、アンモニア年約1.8億t、世界エネルギーの1〜2% |
| 0:56–1:04 | 影の面 | 火薬、毒ガス、窒素汚染 |

数値は概数です(出典: V. Smil, *Enriching the Earth* (2001)、Erisman et al., *Nature Geoscience* (2008)、国連人口推計 ほか)。

## 再生成

```bash
./make.sh   # narrate.py → capture.js → 音声合成・-14 LUFS 正規化 → upload/
```

- `narrate.py` … 原稿(`SCRIPT`)を VOICEVOX で合成し、シーン尺に収まるよう話速を自動調整。BGM をダッキングしてミックスし、字幕タイミング `output/cues.json` と SRT を出力。字幕は `|` で画面送り、`/` で改行
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを描画(ブラウザで開くとプレビュー)
- `capture.js` … Playwright で 1 フレームずつ撮影して ffmpeg で mp4 化。`--stills 3,10,20` で静止画確認
- `bgm.py` … C メジャー 100BPM のマリンバ風BGM。「影の面」のシーンだけ短調に切り替わる
- VOICEVOX の準備は `../pacific-war-analysis/README.md` と同じ(音声モデルは四国めたんを含む `0.vvm`)。話者スタイルは `VOICEVOX_STYLE`(既定 2 = ノーマル、0 = あまあま、6 = ツンツン)

公開時は VOICEVOX の利用規約に従い「VOICEVOX:四国めたん」のクレジットが必要です(動画末尾と説明文に記載済み)。
