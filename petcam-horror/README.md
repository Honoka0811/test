# ペットカメラ — ホラーショート動画(モキュメンタリー)

留守中のペットカメラの録画という体裁の縦型ホラーショート(1080×1920 / 30fps / 約48秒)。幽霊は出てきません。
映像・効果音・ピアノはすべてコードで生成しており、外部の素材は使っていません。

- **完成動画: `upload/petcam_horror_final.mp4`**(字幕焼き込み・ナレーション・効果音入り、-14 LUFS)
- 字幕: `upload/subtitles_ja.srt` / サムネイル: `upload/thumbnail.jpg` / タイトル・説明文・タグ: `upload/metadata.md`

## ストーリー

| シーン | 内容 |
|---|---|
| 1日目 | 留守中のペットカメラ。柴犬のコタが、誰もいない所(カメラの真下)に尻尾を振ってる |
| 3日目 | 次の日も、その次の日も。同じ場所でお手までしてる |
| 祖母 | そこは去年亡くなったおばあちゃんがいつも座ってた場所。会いに来てくれてるのかなって、ちょっと泣いた(ピアノ) |
| 友達 | 録画を見せたら、友達が急に真顔に。「ねえ……テレビ、見て」 |
| 拡大 | 消えたテレビの黒い画面をデジタル拡大・明るさ補正 |
| 判明 | 反射に、カメラの死角でしゃがんでコタを撫でる知らない男。毎日撫でてたのは、この男だった |
| 今夜 | 寝室にいる私のスマホに「リビングで動きを検知しました」。開くと暗視映像のコタが尻尾を振っている(テレビの反射には男) |

部屋の配置: カメラは部屋の高い角にあり、真下が死角。犬はその死角に向かって座り、正面奥のテレビの画面には死角が映り込みます。
1日目・3日目の映像でも、テレビの反射に男がうっすら映っています(見返すと気づく仕掛け)。

## 再生成の方法

```bash
cd petcam-horror
python3 narrate.py   # ナレーション合成 → output/narration.wav, timeline.js/json(シーン尺), subtitles_ja.srt
python3 sound.py     # 環境音・効果音・ピアノを合成してナレーションとミックス → output/mix.wav
node capture.js      # render.html を1フレームずつ撮影 → output/video_silent.mp4
./export.sh          # 映像と音声を合成し -14 LUFS に正規化 → upload/
```

- `narrate.py` … 原稿は `SCRIPT`。飼い主 = 四国めたん(ノーマル)、友達 = 小夜/SAYO。読み上げの長さからシーンの尺を自動で決めます
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを決定論的に描画。ペットカメラらしさは「低解像度で描いて拡大」「行ごとの横幅変化による魚眼風の歪み」「タイムスタンプ/LIVE/IR 表示」「夜は白黒の暗視」で出しています
- `sound.py` … マイクのノイズ、尻尾が床を叩く音、息づかい、ピアノ、操作音、通知音、衝撃音を numpy だけで合成
- 必要なもの: Node.js + `playwright`(Chromium)、`ffmpeg`、IPAゴシック、Python 3 + `numpy` + `pyopenjtalk` + `voicevox_core`(セットアップは `../pacific-war-analysis/README.md` と同じ。音声モデルは `0.vvm`(四国めたん)と `15.vvm`(小夜))

VOICEVOX の音声を公開する場合は「VOICEVOX:四国めたん」「VOICEVOX:小夜/SAYO」のクレジット表記が必要です(エンドカードと説明文に記載済み)。
