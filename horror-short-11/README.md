# 内側から曇る窓 — ホラーショート動画(11本目)

縦型ショート動画(1080×1920 / 30fps / 約61秒)。夜の古いトンネルを車で通る、オリジナルの怪談です。運転席から見た画面だけで進みます。

- 完成動画: `output/tunnel_kumori.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、最後(岩の向こうの声)=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(エンジンとタイヤ、トンネル内の残響、天井が落ちる音、車体が沈む音、だんだん苦しくなる息づかい、エアコンの送風、小雨、こぼれ落ちる小石、土ごしにガラスをたたく音、ピアノ、低いドローン、不協和ストリングス、心音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。道路とトンネルは簡易3Dで、トンネルの照明が車内を順番に照らす |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

トンネル名と事故は架空のものです。

## 筋(どんでん返し)と、現実の手がかり

- トンネルのまん中で明かりが消え、車が沈む。主人公は、そのまま抜けたと思っている
- 窓が内側から曇り、「何人もの人が息をしているみたい」と語るので、見る人は「幽霊が乗ってきた」と思う
- ところがバックミラーには誰もいない。袖でガラスをふくと、向こうは土と岩
- 車が沈んだのは天井が落ちてきたからで、トンネルは抜けていなかった。曇っていたのは、閉じこめられた自分ひとりの息
- 最後に、同じように埋まった昔の人たちが岩のすき間からガラスをたたいて「あなたも、帰れないね」
- 見返すと分かる手がかり: 天井が落ちると車体が沈む / 外の空気が入らない車内は、ひとりの息でも曇り続ける / エアコンが効かない / ほかの車が一台も通らない
- 音: ガラスの向こうが見えた瞬間、エンジン、送風、雨の音がすべて消え、メーターの針も0に落ちる(それまでの車の音は、まぼろし)。残るのは、だんだん苦しくなる自分の息だけ
- 車は左車線を走り、運転席は右側。バックミラーは運転席から見て左上にある

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
