# 内側から曇る窓 — ホラーショート動画(11本目)

縦型ショート動画(1080×1920 / 30fps / 約61秒)。夜の古いトンネルを車で通る、オリジナルの怪談です。運転席から見た画面だけで進みます。

- 完成動画: `output/tunnel_kumori.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、後ろの席の声=ささやきを3人分に重ねる、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(エンジンとタイヤ、トンネル内の残響、車体が沈む音、何人もの息づかい、ワイパー、小雨、手のひらがガラスに触れる音、ピアノ、低いドローン、不協和ストリングス、心音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。道路とトンネルは簡易3Dで、トンネルの照明が車内を順番に照らす |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

トンネル名と事故は架空のものです。

## 筋と、現実の手がかり

- トンネルは昔の崩落事故で、帰り道の車が何台も埋まった場所(入口の慰霊碑に書いてある)
- 死んだ人たちは、あの日の帰り道のまま、自分ではトンネルから出られない。だから通りかかった車の空いている席に乗りこみ、「みんなの家まで、送ってね」と、一人ひとりの家まで送らせようとする
- 車は左車線を走り、運転席は右側。バックミラーは運転席から見て左上にある
- 人が乗ると車体が沈む / 何人も乗ると、息で窓が内側から曇る / ワイパーは外側しかふけない、という実際に起きることだけで「誰かが乗っている」ことを示す
- 後ろの席は3人がけで、乗っているのも3人。手形は、まん中の席の人が前の席のあいだから身を乗り出して届く範囲についている
- トンネルの照明が消えて車が沈んだ瞬間、バックミラーに一瞬だけ人影が映る(見返し用の伏線)
- 乗りこまれたあとは、エンジン音が重さのぶん少し低くなる

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
