# 革靴ブランド TOP10 — ショート動画

世界の革靴ブランドを10位から1位まで発表するカウントダウン形式の縦型ショート動画です（1080×1920 / 30fps / 約69秒）。

- **完成動画**: `output/leather_shoes_top10.mp4`（音量は YouTube の基準に合わせて約 -15 LUFS）
- ナレーション: VOICEVOX:青山龍星（ノーマル。冒頭・TOP3・1位の発表は「熱血」）
- BGM・効果音: 自作（numpy で合成、権利フリー）
- 映像: 写真は使わず、各ブランドの代表モデルを Canvas でイラストとして描画。フラッシュの演出はなし

## 演出

| シーン | 内容 |
|---|---|
| つかみ | 「一生モノの革靴 どれを選ぶ？」の文字が揺れながら入り、靴のイラストを0.45秒ごとに切り替え |
| イントロ | 9ブランドのカードが順に飛び込む、「1位は最後に発表！」 |
| 10位〜2位 | 靴がスライドイン → スポットライトの下でゆっくり浮遊、光沢の帯が横切る / 大きな順位の数字が画面を揺らしながら入る / 価格がカウントアップ / 上部に進行バー |
| TOP3 | 背景を暖色にし、BGM にメロディーを追加 |
| 1位の前 | 靴をシルエットだけで見せて焦らす、ドラムロール → 無音 |
| 1位 | 回転する金色の光線と紙吹雪、BGM が一番盛り上がる |
| まとめ | 1〜10位の一覧、「最初の一足なら黒のストレートチップ」、保存の呼びかけ |

## 再生成

```bash
python3 narrate.py   # ナレーション合成 → output/narration.wav と timeline.json（シーン尺は音声の長さで決まる）
python3 bgm.py       # BGM・効果音 → output/bgm.wav, output/sfx.wav
node capture.js      # 映像（無音） → output/video_silent.mp4   ※ --stills 1.0,8.5 で確認用の静止画
python3 mix.py       # BGM をナレーション中は下げてミックスし、完成動画を書き出す
```

VOICEVOX のセットアップは `../pacific-war-analysis/README.md` を参照してください（青山龍星は `15.vvm`）。
原稿は `narrate.py` の `SCRIPT`、ブランドの価格・代表作・靴の色/形は `render.html` の `BRANDS` にあります。
ランキングは知名度・品質・歴史をもとにした独自選定、価格は既製靴のおおよその目安です。
