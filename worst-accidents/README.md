# 人類史上最悪の事故 7選 — ショート動画

人類史上最悪とされる事故7件を、年代順にたどる縦型ショート動画です(1080×1920・30fps・約88秒)。
ナレーションは VOICEVOX:青山龍星、BGM はバッハ「G線上のアリア」(アメリカ空軍軍楽隊の演奏、パブリックドメイン)を使っています。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)
- 完成動画(ナレーション+BGM): `output/worst_accidents_narrated.mp4`
- 映像のみ(無音): `output/worst_accidents.mp4`
- ナレーション音声のみ: `output/narration.wav`

## 素材と権利

- **BGM**: J.S.バッハ「管弦楽組曲第3番 BWV1068 より Air(G線上のアリア)」。演奏はアメリカ空軍軍楽隊(United States Air Force Band)。米国政府職員の職務上の著作物なのでパブリックドメインで、曲もパブリックドメイン。入手元: Internet Archive `AirSuiteNo.3InDMajor`(`assets/air_on_g_string_usaf_band.ogg`)。吹奏楽版で、変ロ長調に移調されています。
- **ナレーション**: VOICEVOX:青山龍星(ノーマル)。公開するときは利用規約に従って「VOICEVOX:青山龍星」のクレジットを入れてください(動画の最後と説明文に記載済み)。
- **映像**: 写真や映像素材は使わず、Canvas で描いた線画とテキストだけで構成しています。

## 再生成の方法

```bash
cd worst-accidents
node capture.js        # output/worst_accidents.mp4(無音)を生成
python3 narrate.py     # ナレーション合成 + BGM ダッキング → output/worst_accidents_narrated.mp4
./export_upload.sh     # upload/ に -14 LUFS 正規化した最終版などを書き出す
```

VOICEVOX のセットアップ方法は `../pacific-war-analysis/README.md` と同じです(voicevox_core 0.17.1・`voicevox_onnxruntime` 1.17.3・`15.vvm`)。ナレーション原稿は `narrate.py` の `SCRIPT` にあり、書き換えて再実行すれば差し替えられます。
