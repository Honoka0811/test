# 三億円事件 — ショート動画

1968年12月10日に東京・府中で起きた「三億円事件」を、不気味なトーンでたどる縦型ショート動画(1080×1920 / 30fps / 68秒)。

- **完成動画: `output/sanoku_en_jiken.mp4`**(H.264 + AAC ステレオ、-14 LUFS、字幕焼き込み)
- 字幕ファイル: `output/subtitles_ja.srt`
- ナレーション: VOICEVOX:四国めたん(ノーマル。ラストの一文だけ「ささやき」)
- BGM: `bgm.py` で numpy だけで合成した自作の不気味系BGM(権利フリー)

## 構成

| 時間 | シーン | 内容 |
|---|---|---|
| 0:00–0:07 | タイトル | 「三億円事件」/ 戦後最大の未解決事件 / 「未解決」のハンコ |
| 0:07–0:16 | 現場 | 1968年12月10日 午前9時20分頃、雨の府中。府中刑務所の塀沿いを走る現金輸送車 |
| 0:16–0:24 | 白バイ | 赤色灯の白バイが追いつく。「この車に、ダイナマイトが仕掛けられている」 |
| 0:24–0:32 | 発煙筒 | 車の下に潜った男、噴き出す煙、「爆発するぞ!」、輸送車ごと逃走(犯行時間 約3分) |
| 0:32–0:40 | 真相 | 白バイ→偽物、煙→発煙筒、奪われた現金 ¥294,307,500 |
| 0:40–0:49 | 捜査 | 遺留品120点以上 / 捜査員延べ17万人 / 容疑者11万人以上 |
| 0:49–0:57 | 時効 | 1968→1975 のカウンター、1975.12.10「時効」のハンコ |
| 0:57–1:08 | 余韻 | 顔のない白バイ警官のシルエット(ささやき声)→ クレジット |

人物は実在の写真・モンタージュ写真を使わず、顔のないシルエットで表現しています。

## BGM の中身(`bgm.py`)

うなりのある D の低音ドローン+風音 / 短2度・三全音でぶつかる不協和パッド / 音程が少し狂うオルゴール /
時計の秒針(チク・タク)/ 発煙筒シーンの心音 / シーン転換のインパクト音と逆再生スウェル / 簡易リバーブ。
ナレーション中は自動で音量を下げます(ダッキング)。

## 再生成

```bash
./make.sh   # narrate.py → capture.js → 音声と合成・ラウドネス正規化 → output/sanoku_en_jiken.mp4
```

- `narrate.py` … 原稿(`SCRIPT`)を VOICEVOX で合成し、シーン長に収まるよう話速を自動調整。`output/cues.json`(字幕タイミング)・SRT・BGM・ミックスを書き出す
- `render.html` … Canvas 2D で時刻 t のフレームを決定論的に描画。ブラウザで開くとプレビュー再生
- `capture.js` … Playwright で1フレームずつ撮影して ffmpeg へ。`node capture.js --stills 5,20` で確認用の静止画
- フォント: `fonts/` の Shippori Mincho(SIL Open Font License)と IPAゴシック

### VOICEVOX のセットアップ

| 必要なもの | 取得元 | 環境変数 |
|---|---|---|
| `voicevox_core-0.16.2-cp310-abi3-manylinux_2_34_x86_64.whl` | VOICEVOX/voicevox_core releases → `pip install` | — |
| `voicevox_onnxruntime-linux-x64-1.17.3.tgz` | VOICEVOX/onnxruntime-builder releases | `VOICEVOX_ORT` |
| `0.vvm`(四国めたん ノーマル等)、`5.vvm`(四国めたん ささやき) | VOICEVOX/voicevox_vvm releases (0.16.2) | `VOICEVOX_VVMS` |
| Open JTalk 辞書 | `pyopenjtalk` 同梱 | `VOICEVOX_DICT`(任意) |

VOICEVOX が無い環境では Open JTalk の仮音声にフォールバックします。
公開時は VOICEVOX の利用規約に従い「VOICEVOX:四国めたん」のクレジットが必要です(動画末尾と下記説明文に記載)。
