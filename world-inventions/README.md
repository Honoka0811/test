## 再生成

```bash
./build.sh   # narrate.py → capture.js → 合成・正規化 → upload/
```

| ファイル | 役割 |
|---|---|
| `script.py` | 台本。読み上げ用(`read`、数字は漢数字)と字幕用(`sub`)を分けて記述 |
| `narrate.py` | VOICEVOX でシーンごとに合成し、**発話の長さからシーン尺を決めて** `timeline.js` を書き出す。BGM をナレーション中だけ下げて(ダッキング)`output/mix.wav` を作る |
| `bgm.py` | 120BPM・Cメジャーの王道進行(F→G→Em→Am)。キック/クラップ/ハイハット/ベース/裏打ちコード/マリンバ風アルペジオを合成 |
| `render.html` | Canvas 2D で `render(t)` が時刻 t のフレームを描画。各発明のアイコンもコードで描いたアニメーション。ブラウザで開くとプレビュー再生(`?t=秒` で静止) |
| `capture.js` | Playwright で 1 フレームずつ撮影し ffmpeg で mp4 化 |

- 台本を書き換えて `./build.sh` を再実行すれば、尺も字幕も自動で追従します。
- 話者・話速: `VOICEVOX_STYLE=0 VOICE_SPEED=1.2 ./build.sh`(0 = 四国めたん あまあま、6 = ツンツン、4 = セクシー)
- 必要なもの: Node.js + `playwright`(Chromium)、`ffmpeg`、IPAゴシック、Python 3 + `numpy` + `pyopenjtalk` + `voicevox_core` 0.17.1。
  VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じで、音声モデルは四国めたんを含む `0.vvm`(VOICEVOX/voicevox_vvm releases)を `VOICEVOX_VVMS` のディレクトリに置きます。
