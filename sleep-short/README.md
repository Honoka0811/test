# 睡眠ショート「眠れない夜、目を閉じ続けるのはNG？」

縦型ショート(1080×1920 / 30fps / 約63秒)。ナレーションは VOICEVOX の **四国めたん**、BGM と効果音は numpy で自作(権利フリー)。
投稿用のタイトル・説明文・固定コメントは `metadata.md`。

## 事実確認

- 入浴: 40〜42.5℃・就寝1〜2時間前で寝つきが改善(Haghayegh et al. 2019, 17研究のメタ分析)
- 眠くなってから寝床へ / 眠れなければ寝床を離れる: 厚生労働省「健康づくりのための睡眠ガイド2023」
- 景色の想像: Harvey & Payne (2002)。「羊を数えても眠れない」という俗説は元研究の裏付けが弱いので使っていない
- 睡眠時間: OECD 33か国で日本が最短(7時間22分・2016年の値)。グラフには出典で確認できた南アフリカ・中国・日本の値のみ表示

## ビルド

```bash
./build.sh                 # 合成 → 撮影 → BGM/効果音ミックス → カバー画像
python3 narrate.py --kana  # 全行の読みを確認(読み間違いチェック)
node capture.js --stills 3,10,50   # 確認用の静止画
```

- `script.json` … 原稿([字幕, 読み上げ] の組。字幕の【】は黄色強調、`pause` はカウントダウンの無音)
- `narrate.py` … VOICEVOX 合成と `timeline.json` / SRT の書き出し(`user_dict.json` で「日本人=ニホンジン」を指定)
- `render.html` / `capture.js` … Canvas 描画と撮影
- `bgm.py` … chill-hop BGM(展開をナレーションのタイミングに合わせる)と効果音
- `mix.py` … ナレーション + BGM(ダッキング)+ 効果音を -14 LUFS で合成
- VOICEVOX のセットアップは `../daimyo-descendants/README.md` と同じ(四国めたんは `0.vvm`、既定は style 2・話速 1.28)
