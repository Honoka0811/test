# 行列代行のお仕事 — ショート動画

「行列代行」という仕事を紹介する縦型ショート動画(1080×1920 / 30fps / 58.5秒)。
ナレーションは VOICEVOX:四国めたん(ノーマル)、BGM は numpy で合成した自作のポップ曲(権利フリー)です。

- **完成動画: `output/queue_proxy_short.mp4`**(字幕焼き込み・-14 LUFS 正規化済み)
- 字幕ファイル: `output/subtitles_ja.srt` / サムネイル: `output/thumbnail.jpg`

## 構成

| 時間 | シーン | 内容 |
|---|---|---|
| 0:00–0:06 | つかみ | 並ぶだけでお金がもらえる!? |
| 0:06–0:16 | 行列代行とは | 依頼者の代わりに並ぶ。人気店スイーツ/限定グッズ/整理券 |
| 0:16–0:25 | お仕事の流れ | 依頼 → 並ぶ → 交代 or 受け取り → 報酬 |
| 0:25–0:33 | 報酬の目安 | 1時間あたり 1,000〜2,000円ほど(早朝・悪天候は割増も) |
| 0:33–0:43 | 向き・不向き | 待つのが苦にならない/時間を守れる ⇔ 暑さ寒さ/立ちっぱなし |
| 0:43–0:51 | 注意点 | 代行での行列を禁止するお店・イベントもある → 事前にルール確認 |
| 0:51–0:58 | まとめ | 誰かの待ち時間を引き受ける仕事 + クレジット |

画面下には全編通して行列が流れ、ピンクの「代行」さんが少しずつ前に進み、最後に先頭に着きます。
報酬額は一般的な目安で、依頼内容・地域・会社によって変わる旨を画面に注記しています。

## 再生成

```bash
./build.sh   # narrate.py → capture.js → 音声合成・ラウドネス正規化 まで一括
```

- `narrate.py` … `SCRIPT` の原稿を VOICEVOX で合成し、`output/subs.js`(字幕)・`subtitles_ja.srt`・BGM をダッキングしてミックスした `mix.wav` を出力
- `render.html` … Canvas で `render(t)` が時刻 t のフレームを描画(ブラウザで開くとプレビュー)。字幕は `output/subs.js` を読む
- `capture.js` … Playwright で 1 フレームずつ撮影して ffmpeg で mp4 化
- `bgm.py` … F メジャー/116BPM のポップBGM(キック・クラップ・ハイハット・ベース・マリンバ風コード・ベル風メロディ)
- フォント: M PLUS Rounded 1c(SIL OFL 1.1, `fonts/OFL.txt`)

VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じ(音声モデルは四国めたんを含む `0.vvm`、
voicevox_core 0.16.0、Open JTalk 辞書は `VOICEVOX_DICT` で指定)。

公開時は VOICEVOX 利用規約に従い「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と概要欄に記載してください)。
