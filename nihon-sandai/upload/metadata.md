### 手順A: ブラウザ / アプリから手動で投稿

1. YouTube Studio(studio.youtube.com)→「作成」→「動画をアップロード」で `nihon_sandai_final.mp4` を選ぶ
2. 詳細: タイトル・説明文を貼り付け。「視聴者」は「いいえ、子ども向けではありません」
3. 「その他のオプション」でタグ・言語(日本語)・カテゴリ(旅行とイベント)を設定
4. 「動画の要素」→ 字幕を追加 → ファイルをアップロード → `subtitles_ja.srt`(タイミングあり)
5. 公開設定: 非公開で保存 → スマホで再生して音量・字幕・縦画面表示を確認 → 公開 or 公開予約
6. 公開後、ピン留めコメントを投稿して固定。ショート判定(縦型・60秒・#Shorts)は自動
7. サムネイルを変えたい場合は YouTube アプリ → 自分の動画 → 編集 → サムネイル → `thumbnail.jpg`

### 手順B: スクリプトで投稿(YouTube Data API)

```bash
pip install google-api-python-client google-auth-oauthlib
# Google Cloud Console で YouTube Data API v3 を有効化し、OAuth クライアント(デスクトップ)の client_secret.json を nihon-sandai/ に置く
cd nihon-sandai
python3 youtube_upload.py --dry-run                                   # 送信内容の確認
python3 youtube_upload.py                                             # 非公開で投稿(動画+サムネイル+字幕)
python3 youtube_upload.py --publish-at 2026-11-05T12:00:00+09:00      # 公開予約
```
