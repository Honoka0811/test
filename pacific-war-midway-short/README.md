# 「嘘の電報」とミッドウェー海戦 — YouTube ショート

太平洋戦争の転換点・ミッドウェー海戦(1942年6月)を、**米軍が仕掛けた「AFは水不足」の罠**という謎解き仕立てで描く縦型ショート動画です。

- **完成動画: `upload/midway_short.mp4`**(1080×1920 / 30fps / 約57秒 / -14 LUFS)
- タイトル・説明文・タグ・投稿メモ: `upload/metadata.md`
- 字幕: `upload/subtitles_ja.srt` / サムネイル: `upload/thumbnail.jpg`
- ナレーション: **VOICEVOX:四国めたん**(ノーマル)
- BGM・効果音: すべてプログラムで合成(外部音源なし・権利フリー)

## 仕組み

1. `narrate.py` — `script.json` の原稿を 1 フレーズずつ VOICEVOX で合成。**音声の実際の長さからシーンの長さを決める**ので間延びしない。`timeline.json` と SRT も出力
2. `render.html` — Canvas 2D で `render(t)` が各フレームを描画(地図・艦影・爆発・字幕すべてコード描画)。効果音のタイミング表(`events.json`)もここで作る
3. `capture.js` — Playwright で 1 フレームずつ撮影して mp4 化(`--stills 秒...` で静止画確認)
4. `audio.py` — Dマイナー/120BPM のテンション曲(ブラーム・刻み・太鼓・ライザー・無音ブレイク)と効果音を合成し、ナレーション中は BGM を自動で下げてミックス
5. `build.sh` — 上記を順に実行し、-14 LUFS に正規化して `upload/` に書き出す

```bash
./setup.sh   # VOICEVOX CORE・四国めたんモデル(0.vvm)・辞書・フォントを取得
./build.sh   # 全部ビルド(約4分)
```

原稿を変えたいときは `script.json` を編集して `./build.sh` を再実行するだけです(`t`=字幕、`r`=読み、`hl`=黄色で強調する語)。

## 事実関係について

- 米海軍は日本海軍の暗号(JN-25)を一部解読し、次の作戦目標が「AF」と呼ばれていることを把握。ミッドウェーから真水製造装置の故障を伝える偽の連絡を流させ、日本側の通信に「AFは水不足」が現れたことで AF＝ミッドウェーと確認した
- 南雲機動部隊は陸用爆弾から艦船用兵装への転換中に攻撃を受け、格納庫内の燃料・爆弾が被害を拡大させた
- 低空で来た米雷撃機の攻撃(大半が撃墜)に零戦が引き付けられた直後、急降下爆撃機が赤城・加賀・蒼龍を約6分の間に被弾させた(現地時間 10:22 頃〜)。飛龍も同日夕方に被弾し、翌朝沈没
- 地図と艦影は演出用に簡略化しています。「運命の5分間」(あと5分で攻撃隊が発艦できた)という俗説は近年の研究で否定されているため、動画では使っていません
