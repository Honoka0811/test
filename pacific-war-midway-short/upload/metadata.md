## 1万再生を狙うための演出・運用メモ

動画に入れた仕掛け:

| 仕掛け | 位置 | ねらい |
|---|---|---|
| 1秒目から結論をにおわせる(「流れを変えた」が叩きつけられ、「嘘」のハンコ) | 0:00–0:04 | 最初の2秒で離脱されないようにする |
| 「真実は、最後まで見ると分かる」 | 0:03 | 最後まで見る理由を作る |
| 2〜3秒ごとに画面が切り替わる/フレーズ字幕がポップ表示 | 全体 | 音を消して見る人も内容が追える |
| 謎解きの構成(AF＝どこ？→罠→バレた) | 0:09–0:29 | 「答えが知りたい」で引っ張る |
| 急降下の直前に BGM を完全に止める(無音＋心音) | 0:41 | 緊張と開放でクライマックスを作る |
| 時計 10:22→10:28 と空母が次々炎上 | 0:44–0:50 | 「わずか6分」を体感させる |
| 「あなたなら気づけた？」+ コメント欄を指す矢印 | 0:53– | コメントを増やし、おすすめに乗りやすくする |
| 画面上部の進捗バー | 全体 | 「もうすぐ終わる」で最後まで見てもらう |

投稿後:

- 最初のコメントは自分で固定する(例:「もし日本が罠に気づいていたら、戦争はどうなっていたと思いますか？」)
- 48時間の「視聴維持率」と「スワイプされずに見た割合」を YouTube Studio で確認。冒頭で離脱が多ければタイトル・冒頭テキストを差し替えた別版を検討
- 同じ形式(1つの意外な事実 → 謎解き → 問いかけ)でシリーズ化すると、チャンネル全体で伸びやすい
  - 例: 「真珠湾で撃ち漏らした"石油タンク"」「大和が一度も主砲で戦艦を撃てなかった理由」
