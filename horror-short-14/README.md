## 筋(どんでん返し)と、手がかり

- 不動産屋の担当の男の人はとても親切で、引っ越しの日には雪かきまで手伝ってくれた。「寝室は、二階のこの部屋がいいですよ」と、押し入れに天袋のある和室をすすめる(あとで写真が見つかるのは、この部屋の天袋)
- 「鍵は、これで全部です」と3本渡してくれる(スーツの袖と手だけ映す)
- 初雪の朝、道路から玄関まで足あとが続いていて、戻る足あとがない。誰かが家に入ったと思う
- でも鍵はかかったまま、家には誰もいない。警察を呼ぶと、つま先は道路を向いていた
- 足あとは入ってきたのではなく、家から出ていったもの。雪が降りはじめたのは私が帰ってきたあとなので、誰かが雪の前から、ひと晩じゅう私と同じ家にいた。しかも外から鍵をかけている(合いかぎを持っている。鍵は全部受け取ったはずなのに)
- おまわりさんが寝室の押し入れの上の天袋を開けると、毛布と食べかすと、寝ている私の写真が何十枚も(毎晩の日付と時刻入り)。その人は越してきた日から毎晩、天袋のすき間から私の寝顔を見ていた。最初に家じゅうを探したとき、天袋までは見ていなかった
- その夜は友だちの家に泊まり、次の朝、鍵を替えるために戻る。夜のうちに積もった雪の上に、また足あと。今度はつま先が家を向いていて、出ていく足あとはない。「あの人は今、家の中にいる」
- 私は家に入らず、門の前から警察に電話しようとする。そのとき、すぐうしろで雪を踏む音。雪の上の私の影に、背の高い影が重なる。耳もとで「おかえり。ちゃんと、つま先の向き、見たんだね」。ふり返ると、目の前にスーツの男
- 2日目の足あとは、男がうしろ向きに歩いて家から出てきたものだった。前の日に私が「つま先の向き」で足あとを読むのを知っていて、わざと家の中にいると思わせ、私が家を見つめているすきに、うしろに回った。前半で覚えたルールで、見ている人もだまされる
- その声は、鍵を渡してくれた不動産屋の担当者だった。最後の文字は「足あとの『向き』だけを、信じないでください。」
- 勘違いの理由: 深い雪の足あとは遠くからだとただの穴に見え、向きを気にしなかった
- 主人公の行動: 不審に思う → 家を確かめる → 警察を呼ぶ → 家を離れる → 鍵を替えに戻る → 家に入らず外から通報しようとする

```bash

./build.sh           # narrate.py → sound.py → capture.js → 合成
```
