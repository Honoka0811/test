# 雪の足あと — ホラーショート動画(14本目)

縦型ショート動画(1080×1920 / 30fps / 約100秒)。雪国の一軒家を舞台にした、オリジナルの怪談です。

- 完成動画: `output/yuki_no_ashiato.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、家にいた男=ヒソヒソを低くして、家の中の響きをつける) |
| BGM・効果音 | `sound.py` で numpy 合成(外の風、雪を踏む音、鍵の音、鍵束、古い引き戸、床のきしみ、電話の画面を押す音、ドローン、不協和ストリングス、心音、太鼓、最後の衝撃音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画(2階の窓から見た庭、玄関の鍵、誰もいない和室、しゃがんで足あとを指さすおまわりさん、足あとのアップ、上から見た図、ゆうべの家、合いかぎ、次の朝の玄関)。人物はシルエットだけで、顔は描かない |
| フォント | しっぽり明朝(OFL-1.1) |

## 筋(どんでん返し)と、手がかり

- 越してくるとき、不動産屋の担当の男の人が「鍵は、これで全部です」と3本渡してくれる(スーツの袖と手だけ映す)
- 初雪の朝、道路から玄関まで足あとが続いていて、戻る足あとがない。誰かが家に入ったと思う
- でも鍵はかかったまま、家には誰もいない。警察を呼ぶと、つま先は道路を向いていた
- 足あとは入ってきたのではなく、家から出ていったもの。雪が降りはじめたのは私が帰ってきたあとなので、誰かが雪の前から、ひと晩じゅう私と同じ家にいた。しかも外から鍵をかけている(合いかぎを持っている。鍵は全部受け取ったはずなのに)
- その夜は友だちの家に泊まり、次の朝、鍵を替えるために戻る。夜のうちに積もった雪の上に、また足あと。今度はつま先が家を向いていて、出ていく足あとはない
- 男は今、家の中にいる。外から警察に電話しようとすると、玄関の引き戸が内側から開き「おかえり。ずっと、待ってたよ」
- その声は、鍵を渡してくれた不動産屋の担当者だった。「これで全部です」はうそで、合いかぎを1本残し、気に入った彼女の家に出入りしていた。暗がりの人影の胸元には、スーツの白い襟とネクタイ
- 勘違いの理由: 深い雪の足あとは遠くからだとただの穴に見え、向きを気にしなかった
- 主人公の行動: 不審に思う → 家を確かめる → 警察を呼ぶ → 家を離れる → 鍵を替えに戻る → 家に入らず外から通報しようとする

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
