# 体重計の記録 — ホラーショート動画(6本目)

縦型ショート動画(1080×1920 / 30fps / 約48秒)。スマート体重計のアプリ画面で進むオリジナルの「意味が分かると怖い話」です。

- 完成動画: `output/taijukei_kiroku.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(暗いパッド、少しずつ狂う3拍子のワルツ、不協和ストリングス、心音、体重計の測定音、足音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画(体重計の表示 → 自分の記録 → 未登録の測定 → 毎晩の記録 → 足し算 → 図解) |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

アプリ「ヘルスノート」は架空のものです。

## 現実との整合

スマート体重計は、登録ユーザーの誰とも体重が合わない測定を「未登録の測定」として残し、誰のものか確認を求める機種があります。話はこの機能だけで成り立つようにしてあります。

## 視聴維持のための仕掛け

- 冒頭1秒で、赤い「58.4kg 未登録の測定 午前3:10」を見せる
- 106.6kg を先に見せ、少し間をおいてから 58.4 + 48.2 の足し算で種明かしする(先に気づいた人がコメントしたくなる)
- 最後は図解で「誰かが私を抱えて乗った」ことを絵で示し、音なしでも筋が追える

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
