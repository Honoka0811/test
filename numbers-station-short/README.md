# 乱数放送 YouTubeショート（VOICEVOX:四国めたん）

1080x1920 / 30fps / 約50〜60秒の縦型ショート動画を、コードだけで生成するプロジェクト。
映像・BGM・効果音はすべてプログラムで合成しているので、著作権の心配はない。

## 作り方

```bash
pip install numpy scipy pillow
# 1) VOICEVOX アプリを起動（エンジンが 127.0.0.1:50021 で立ち上がる）
python tts.py          # 四国めたんのナレーション → out/voice/*.wav
# 2) 映像＋BGM＋ナレーションを合成
python build.py        # → out/numbers_station_short.mp4
# ナレーション無しで演出だけ確認したい場合
python build.py --dry-run
```

尺はナレーションの長さに合わせて自動で決まる。台本は `scenes.py` を編集する。

## 構成と視聴維持の仕掛け

| 秒 | シーン | 演出 |
|---|---|---|
| 0 | 砂嵐 → フック | 1フレーム目から砂嵐＋グリッチ。ささやき声で「謎の数字が聞こえてきたら…」 |
| 4 | スパイへの暗号指令 | 赤い警告枠と「CLASSIFIED」スタンプ（衝撃音つき） |
| 8 | 乱数放送とは | 電波の波紋と RGB ずれのタイトル。心音とオルゴールの BGM が始まる |
| 14 | 冷戦・工作員 | タイプライター音に合わせて暗号電文を打ち込み、「TOP SECRET」 |
| 21 | ワンタイムパッド | 平文＋乱数表＝暗号 を 1 桁ずつ見せる |
| 29 | UVB-76「ザ・バザー」 | 周波数が 4625kHz に固定、ブザー音に合わせて画面が揺れる |
| 38 | 謎の言葉 | 黒塗りの受信ログ |
| 42 | 北朝鮮 2016年再開 | 2000→2016 のカウンター |
| 49 | 今も流れている | レーダー |
| 54 | 隠し数字 | ライザー → 衝撃音 → 「この動画にも4つの数字を隠した」 |
| 末尾 | 砂嵐 | 冒頭と同じ砂嵐でつながり、ループ再生される |

- **隠し数字**：0〜25秒のあいだに 4・6・2・5 が 4 フレームずつ一瞬だけ映る。
  答えは後半で出てくる UVB-76 の周波数「4625kHz」なので、気づいた人がもう一度見る（リピート再生）、コメントする、の両方が起きやすい。
- 画面上部の受信機の周波数は前半ずっと動き回り、UVB-76 の場面で 4625.0kHz に止まる。これも伏線。
- テロップは 3 行以内、キーワードを黄色で強調。Shorts の UI に隠れない位置（下 370px と上端は避けてある）。
- BGM：低いドローン＋短波ノイズ＋だんだん速くなる心音＋短調のオルゴール。ナレーション中は自動で音量が下がる。最終音量は -14 LUFS（YouTube 基準）。

## 投稿用テキスト（例）

**タイトル**
深夜のラジオから謎の数字が…正体は？【乱数放送】#shorts

**説明欄**
```
短波ラジオで数字だけを読み上げる謎の放送「乱数放送」。
この動画には4つの数字が隠されています。見つけられたらコメントで👇

VOICEVOX:四国めたん
#乱数放送 #都市伝説 #UVB76 #暗号 #スパイ #ミステリー #shorts
```

**固定コメント**
```
隠された4つの数字、全部見つけられた？👀
答えはこのコメントの返信に（ネタバレ注意）
```
→ 返信：「4・6・2・5 ＝ UVB-76 の周波数 4625kHz でした📻」

## クレジット・注意

- ナレーションは VOICEVOX:四国めたん。動画の説明欄に「VOICEVOX:四国めたん」のクレジット表記が必要（VOICEVOX・四国めたんの利用規約）。
- 内容の事実：UVB-76 は 4625kHz で 1970年代から放送されている。北朝鮮の平壌放送は 2016年6月に、約16年ぶりに乱数放送を再開した。
