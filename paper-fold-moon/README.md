# 紙を42回折ると月に届く — YouTube ショート動画

「厚さ0.1mmの紙を42回折ると月に届く」という意外な事実から入り、
**「全体の半分は最後のたった1回で生まれる」→「毎日1%の差」→「やめたくなった時、それは41回目かもしれない」**
という2段・3段の気付きにつなげる縦型ショート(1080×1920 / 30fps / 約58秒)。

- **アップロード用一式: `upload/`**
  - `paper_fold_moon.mp4` … 完成動画(-14 LUFS 正規化、AAC 192kbps ステレオ)
  - `thumbnail.jpg` / `subtitles_ja.srt` / `metadata.md`(タイトル案・説明文・タグ・固定コメント・投稿チェックリスト)
- ナレーション: **VOICEVOX:四国めたん(ノーマル)** ※動画内・説明文にクレジット表記済み
- BGM・効果音: numpy で自作(外部音源なし・権利フリー)

## 構成

| 時間 | シーン | 演出 |
|---|---|---|
| 0:00 | フック「42回折ると、月に届きます」 | 1フレーム目から「42回」の巨大文字、月が降りてきて衝撃音+フラッシュ |
| 0:05 | 「ウソだと思いました？」 | 揺れる「？」→ 計算式 → 「本当」スタンプ |
| 0:09 | 10回 / 20回 / 30回 | 折るたびにカウンター+クリック音、スマホ→ビル→宇宙と比較対象が変化、背景も部屋→空→宇宙へ |
| 0:21 | 42回目 | ライザーで溜めて、紙の柱が月を貫く瞬間に特大インパクト+無音のブレイク |
| 0:27 | 41回目ではまだ半分 | 38〜42回目の棒グラフ。最後の1回で増えた部分を金色に |
| 0:38 | 1.01³⁶⁵ と 0.99³⁶⁵ | 成長曲線が伸びる / 地を這う。「その差 約1,500倍」 |
| 0:48 | 「それは41回目かもしれない」 | ピアノとパッドだけの静かなパートで感情に訴える |
| 0:53 | 「あなたは今、何回目？」 | コメント誘導 → 冒頭と同じ宇宙背景にフェードしてループ再生につなぐ |

BGM は Aマイナー / 120BPM のプラック・アルペジオ。導入は謎めいた雰囲気、10回目以降キック→ハイハット→クラップと段階的に厚くして期待感を上げ、42回目で頂点、その後はハーフタイム → 再加速 → 静かなピアノ → 終止和音。ナレーション中は自動で音量を下げ(ダッキング)、BGM+効果音は声より約9dB下にそろえています。

## 数値の根拠

| 項目 | 計算 |
|---|---|
| 42回折った厚さ | 0.1mm × 2⁴² ≈ 439,805km(約44万km) |
| 41回目 | 約22万km(月までの約57%) |
| 月までの平均距離 | 約384,400km |
| 10 / 20 / 30回 | 約10.2cm / 約105m / 約107km(宇宙の境界とされる高度100km=カーマン・ライン超え) |
| 毎日1% | 1.01³⁶⁵ ≈ 37.8、0.99³⁶⁵ ≈ 0.026 → 差は約1,500倍 |

※計算上の話であることを動画内に注記(実際に紙を折れた最高記録は12回、2002年 ブリトニー・ガリバン)。

## 再生成の方法

```bash
# 1. VOICEVOX ENGINE (CPU版) を起動しておく(GitHub の VOICEVOX/voicevox_engine releases から取得)
./run --host 127.0.0.1 --port 50021

cd paper-fold-moon
npm install                # フォント(@fontsource/noto-sans-jp)
python3 narrate.py         # ナレーション合成 → output/narration.wav, timeline.json(句ごとの発話時刻付き), subtitles_ja.srt
node capture.js            # 映像を1フレームずつ描画 → output/video_silent.mp4 と効果音タイミング output/events.json
python3 bgm.py             # BGM + 効果音を合成してミックス → output/mix.wav
./export_upload.sh         # upload/ に完成mp4・サムネイル・字幕を書き出す
```

- `narrate.py` … 原稿(`LINES`)を VOICEVOX ENGINE の HTTP API で合成。各アクセント句の発話時刻を記録し、映像の文字の出現や衝撃演出をナレーションの単語にぴったり合わせる
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを決定論的に描画。ブラウザで開くとプレビュー再生
- `capture.js` … Playwright(Chromium)でフレームを撮影し ffmpeg(libx264)で mp4 化。`--stills 1.5 10 …` で確認用の静止画のみ出力
- `bgm.py` … BGM・効果音(ウーッシュ、クリック、ポップ、ディング、ライザー、インパクト、スタンプ)を合成し、ダッキングしてミックス

原稿を書き換えたら 1 → 2 → 3 → 4 の順で再実行すれば、映像・効果音のタイミングは自動で追従します。
