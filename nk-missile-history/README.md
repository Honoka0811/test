# 北朝鮮ミサイル 30年の推移 — ショート動画

1993年のノドンから2026年まで、北朝鮮の弾道ミサイル発射が日本に対してどう変化してきたかを、
地図アニメーションとデータでたどる縦型ショート動画(1080×1920 / 30fps / 約76秒)です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイル・タイトル/説明文/タグの `metadata.md`)
- ナレーション: VOICEVOX:青山龍星(ノーマル, style 13, 話速 1.24)
- BGM・効果音: numpy/scipy で合成した自作音源(権利フリー)

## 再生成

```bash
cd nk-missile-history
./build.sh                 # すべて(ナレーション → 映像 → 音 → upload/ 書き出し)
SKIP_NARRATION=1 ./build.sh  # 原稿を変えていないとき
node capture.js --stills 4.6,42.9   # 指定秒の静止画だけ確認
```

- `scenes.json` … 原稿(読み上げ用 `say` / 字幕用 `show`、`[[ ]]` は黄色強調)と演出キュー。ここを書き換えれば尺は自動で決まる
- `narrate.py` … VOICEVOX で1文ずつ合成し、シーン尺・字幕・キューの絶対時刻を `output/timeline.json` に出力
- `render.html` … Canvas 2D で `render(t)` がフレームを描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright で1フレームずつ撮影し ffmpeg で mp4 化
- `audio.py` … 軍事ドキュメンタリー風 BGM(D マイナー 100BPM、ギャロップの低音リフ・マーチングスネア・太鼓・ブラスのヒット・ライザー)と効果音(発射・着弾・スタンプ・カウンター・警告音)を合成し、ナレーション中は BGM を自動で下げてミックス
- VOICEVOX CORE のセットアップは `../pacific-war-analysis/README.md` と同じ(`15.vvm` が青山龍星)

警告音は実在の J アラートの音に似せていません(視聴者が本物と誤認しないため)。
VOICEVOX の音声を公開する場合は「VOICEVOX:青山龍星」のクレジット表記が必要です(動画の最後と説明文に記載済み)。
