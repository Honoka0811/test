# スマートロックの履歴 — ホラーショート動画(5本目)

縦型ショート動画(1080×1920 / 30fps / 約51秒)。スマートロックのアプリ画面で進むオリジナルの「意味が分かると怖い話」です。

- 完成動画: `output/smartlock_rireki.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(暗いパッド、同じ音型をくり返すピアノ、不協和ストリングス、心音、鍵が回る音、ドアの音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画(ホーム画面 → 履歴 → 過去7日間 → ドアの図解 → 今夜の通知) |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

アプリ「カギログ」は架空のものです。

## 現実との整合

話は、実在のスマートロックにある機能だけで成り立つようにしてあります。

- 室内側のつまみ(サムターン)を手で回した解錠・施錠は「手動」として履歴に残る
- 開閉センサーがあれば、ドアの開閉も履歴に残る
- 解錠されたときにスマホへ通知が届く

## 視聴維持のための仕掛け

- 冒頭1秒で、赤く光る「03:14 解錠・手動(室内側)」の履歴を見せる
- 「なぜ怖いのか」をドアの図解で説明し、音なしでも筋が追えるようにする
- 最後に、今夜の 3:14 に同じ通知が届く

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
