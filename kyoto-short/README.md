# 京都のヤバい雑学 TOP3 — YouTube ショート

縦型ショート動画(1080×1920 / 30fps / 約47秒)。ナレーションは **VOICEVOX:四国めたん**、BGM・効果音・映像はすべてプログラムで自作(権利フリー)。

- **アップロード用一式: `upload/`**(`kyoto_yabai_zatsugaku_top3.mp4`・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)

BGM: 和風トラップ 120BPM(平調子風スケールの箏リフ、808系キック/ベース、クラップ、ハイハットロール)。1位で盛り上がるアレンジ。

## 生成方法
```bash
./build.sh   # narrate.py → audio.py → capture.js → upload/ に書き出し
```
- `narrate.py` … 台本(`SCENES`)を VOICEVOX で合成し、`timeline.js/json`(シーン・字幕の時刻)と SRT を出力
- `audio.py` … BGM・効果音を合成し、タイムラインに同期してミックス
- `render.html` … Canvas で `render(t)` がフレームを描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright で全フレームを撮影し mp4 化

VOICEVOX CORE 0.16.2(`voicevox_core` wheel、`voicevox_onnxruntime` 1.17.3、`0.vvm`、Open JTalk 辞書)を使用。パスは `VOICEVOX_ORT` / `VOICEVOX_VVMS` / `VOICEVOX_DICT` で指定。
