## 設定
- カテゴリ: People & Blogs(22)
- 言語: 日本語 / 音声言語: 日本語
- 子ども向け: いいえ
- 公開設定: 最初は「非公開」で投稿し、再生して確認してから「公開」に切り替える(`metadata.json` の privacyStatus)
- 字幕: `subtitles_ja.srt`(日本語)
- サムネイル: `thumbnail.jpg`(ショートはスマホアプリからフレーム選択が基本。デスクトップでは反映されない場合あり)

## 投稿方法
- API で投稿: `python3 youtube_upload.py --check` で検証 → `python3 youtube_upload.py` で投稿(手順は `youtube_upload.py` 冒頭)
- 手動投稿: YouTube Studio →「作成」→「動画をアップロード」→ `twenties_10_final.mp4` を選び、上の値を貼り付け → 字幕タブで SRT を追加
