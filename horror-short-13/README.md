# 葬式に来る女 — ホラーショート動画(13本目)

縦型ショート動画(1080×1920 / 30fps / 約58秒)。親戚のお葬式と古いアルバムを舞台にした、オリジナルの怪談です。

- 完成動画: `output/soushiki_no_onna.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、女の人の声=ささやき) |
| BGM・効果音 | `sound.py` で numpy 合成(おりん、木魚、斎場の空気、ページをめくる音、ドローン、不協和ストリングス、心音、太鼓、最後の衝撃音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画(斎場、出口、電気スタンドの机とアルバム、色あせた集合写真2枚の見比べ)。古い写真ほどセピアで傷が多い。`lowLight()` で暗い場所の見え方にする |
| フォント | しっぽり明朝(OFL-1.1) |

## 筋と、手がかり

- 祖父のお葬式に、親戚の誰も知らない黒い着物の女の人が来ていて、帰りぎわに「私」をじっと見て頭を下げる
- アルバムを見ると、10年前の祖母の葬式にも、30年前のひいおじいちゃんの葬式にも、同じ着物・同じ顔(年をとっていない)で写っている
- 写真の中で、あの人は毎回だれかひとりの方を向いている。30年前は祖母、10年前は祖父。その人が、次のお葬式で遺影になっていた
- 今日、あの人が見つめて頭を下げた相手は「私」。最後に耳もとで「また、すぐにお会いしますね」。次のお葬式は、私の番
- 見返すと分かる手がかり: 写真の女の人の顔の向き / 30年前の写真で見られていた祖母が、10年前の写真の遺影になっている / 冒頭の「帰りぎわ、私をじっと見て」

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
