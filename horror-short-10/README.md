# バス停の約束 — ホラーショート動画(10本目)

縦型ショート動画(1080×1920 / 30fps / 約51秒)。雨の夜のバス停を題材にした、オリジナルの怪談です。

- 完成動画: `output/bus_tei.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーションと「私」の台詞=ノーマル、女の子=あまあまを高めに、女の子のささやき=ささやき) |
| BGM・効果音 | `sound.py` で numpy 合成(オルゴールの子守唄(自作)、雨、屋根のしずく、遠い雷、濡れた道を走るバス、低いドローン、不協和ストリングス、心音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。街灯の光の中だけ雨が明るく見え、路面に波紋が広がる |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

## 筋と演出

- 女の子の目的は「ひとりで待つのがいやだから、ずっといっしょに待ってくれる人がほしい」。約束させ、袖をつかみ、最後に「ずっと、いっしょだね」と言う
- バスが止まらない理由は絵で示す。行き先表示は「回送」、バス停は2006年に廃止されている
- 「廃止」の貼り紙は冒頭から標識に貼ってあるが、色あせていて、カメラが寄るまで読めない
- 約束のあと、オルゴールは少しずつ遅く、低くなる

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
