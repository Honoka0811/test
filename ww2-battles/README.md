## BGM について

`air.py` が J.S.バッハ「G線上のアリア」(管弦楽組曲第3番 BWV1068 Air)を楽譜データから合成します。
- 楽譜: [Mutopia Project](https://www.mutopiaproject.org/) "Air, from Suite No.3 in D"(Ross Keenum 編、**Public Domain**)の MIDI を `assets/air-bwv1068.mid` に同梱
- 4声を弦楽合奏風の音色(加算合成)で鳴らし、曲の終わりが動画の終わりに来るようテンポを自動調整(約50BPM)
- 既存の録音を使っていないので、作曲(パブリックドメイン)・録音とも権利上の問題はありません
- ナレーション中は BGM を自動で下げています(ダッキング)

## 再生成

```bash
./build.sh   # narrate.py → capture.js → 合成・音量正規化 → upload/
```

- `narrate.py` … 原稿(`BATTLE_LINES` など)を音声合成し、字幕データ `output/cues.js` と SRT、BGMミックスを出力
- `render.html` … Canvas で `render(t)` がフレームを描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright で全フレームを撮影し ffmpeg で mp4 化
- `midi_read.py` … 依存なしの最小 MIDI パーサ

ナレーションは VOICEVOX(青山龍星 / style 13)を使います。セットアップ手順は `../pacific-war-analysis/README.md` の「VOICEVOX のセットアップ」と同じです。
`voicevox_core` が無い環境では Open JTalk で代替され、エンドカードのクレジットも自動で実際のエンジン名になります(`output/engine.txt` で確認可)。
VOICEVOX 音声を公開する際は「VOICEVOX:青山龍星」のクレジット表記が必要です。
