# 鳴るはずのない踏切 — ホラーショート動画(9本目)

縦型ショート動画(1080×1920 / 30fps / 約59秒)。深夜の踏切を題材にした、オリジナルの怪談です。

- 完成動画: `output/fumikiri.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(踏切の警報音、遮断機のモーター音、揺さぶられる遮断棒、切れかけの街灯、ヒールの足音、風、低いドローン、不協和ストリングス、心音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。左右交互に光る警報ランプが地面や遮断棒を赤く照らす |
| フォント | しっぽり明朝(OFL-1.1) |

## 演出

- 警報ランプは警報音と同じ間隔で左右交互に点滅する。列車の方向指示器は最後まで点かない
- 女は向こう側の遮断棒のすぐ後ろに立ち、後半は棒をつかんで揺さぶる
- 警報が止まると音楽も止まり、遮断機が上がる。切れかけの街灯がつくたびに、女が近づいている

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
