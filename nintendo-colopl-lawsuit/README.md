# 任天堂 vs コロプラ 特許訴訟 — 解説動画

『白猫プロジェクト』をめぐる任天堂とコロプラの特許訴訟(2016年の指摘 → 2017年12月提訴 → 2021年8月和解)を、
四国めたん(VOICEVOX)のナレーションで解説する 16:9 の YouTube 動画(1920×1080 / 30fps / 約5分19秒)です。
字幕は動画に焼き込み済みで、SRT も同梱しています。BGM は自作(プログラム生成)です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)
- 完成動画: `output/nintendo_vs_colopl.mp4`
- ナレーション音声のみ: `output/narration.wav` / BGMのみ: `output/bgm.wav`
- サムネイル: `output/thumbnail.png`

## 再生成の方法

```bash
cd nintendo-colopl-lawsuit
python3 narrate.py          # script.py の原稿を VOICEVOX(四国めたん)で合成 → output/timing.json, narration.wav, subtitles_ja.srt
node capture.js             # render.html を 1 フレームずつ撮影 → output/video_silent.mp4(約16分)
python3 mix.py              # BGM を生成・ダッキングしてミックス → output/nintendo_vs_colopl.mp4
node thumbnail.js           # output/thumbnail.png
./export_upload.sh          # upload/ に -14 LUFS 正規化した最終版・SRT・JPG を書き出す
```

- `script.py` … ナレーション原稿(シーンごと・1文=1字幕)。書き換えて `narrate.py` から再実行すれば差し替わる
- `narrate.py` … WEB版 VOICEVOX API(tts.quest v3, APIキー不要の低速API)で 1 文ずつ合成し、`cache/` に保存。文の長さからシーン尺を決めて `timing.json` を出力
- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(字幕・タイムライン・各シーンのアニメーション)。ブラウザで開くとプレビュー再生
- `capture.js` … Playwright(Chromium)で撮影し ffmpeg(libx264)へパイプ
- `bgm.py` … 王道進行(F△7→G6→Em7→Am7)/92BPM のエレピ+ベース+軽いドラム+パッドを numpy だけで合成
- `mix.py` … ナレーションの包絡で BGM をダッキング(無音時 約-9dB、発話時 約-17dB)してミックス・多重化
- 必要なもの: Node.js + `playwright`(Chromium), `ffmpeg`, 日本語フォント(IPAゴシック), Python 3 + `numpy`, `curl`

## クレジットと利用上の注意

- ナレーション: **VOICEVOX:四国めたん**(動画末尾のカードと `upload/metadata.md` の説明文に記載)。VOICEVOX および四国めたんの音源利用規約に従い、クレジット表記が必要です
- 音声合成に使った tts.quest の WEB API は「個人利用を想定」とされています。収益化する場合は、ローカルの VOICEVOX で `cache/` の音声を作り直すことを推奨します(`narrate.py` の `synth()` を差し替えるだけで同じパイプラインが使えます)
- BGM は自作のため権利表記は不要です
- 本動画は公開報道に基づく解説であり、法的助言ではありません
