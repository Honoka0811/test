# 下山事件 — ショート動画

1949年7月、国鉄初代総裁・下山定則が出勤途中に失踪し、翌日未明に常磐線の線路上で轢死体となって見つかった「下山事件」を、
不気味なトーンで約72秒にまとめた縦型ショート動画(1080×1920 / 30fps)です。

- **アップロード用一式: `upload/`**
  - `shimoyama_case_final.mp4` … 完成動画(字幕焼き込み・ナレーション・BGM・効果音、-14 LUFS、H.264 + AAC ステレオ)
  - `subtitles_ja.srt` … 字幕ファイル
  - `thumbnail.jpg` … サムネイル(タイトル画面)
  - `metadata.md` … タイトル案・説明文・タグ
- ナレーション: **VOICEVOX:四国めたん**(ノーマル, style 2)
- BGM・効果音: `bgm.py` で numpy/scipy から合成した自作音源(権利フリー)

## 音のデザイン

- BGM: 半音でうなる低音ドローン(A と B♭)、減七和音のパッド、音程が少しずつ狂っていくオルゴール、風のノイズ、
  中盤から速くなる心音、場面転換前の逆再生風スウェル、暗めの長いリバーブ
- 効果音: 時計の秒針(三越の場面)、判子、列車の通過とブレーキの軋み、場面転換の低い衝撃音
- ナレーション中は BGM を自動で下げる(ダッキング)

## 再生成の方法

VOICEVOX ENGINE を起動してから `build.sh` を実行します。

```bash
docker run -d -p 50021:50021 voicevox/voicevox_engine:cpu-latest
cd shimoyama-case
./build.sh      # narrate.py → capture.js → 音声合成 → upload/ に書き出し
```

- `narrate.py` … 原稿(`SCRIPT`)を VOICEVOX ENGINE の HTTP API で合成し、各シーンに収まるよう話速を自動調整。
  字幕のタイミング(`output/cues.js`, `output/subtitles_ja.srt`)を書き出し、BGM・効果音とミックス
  (`VOICEVOX_STYLE=37` でヒソヒソ声などに変更可)
- `bgm.py` … BGM と効果音の合成(`python3 bgm.py 72 bgm.wav` で BGM 単体を書き出し)
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright で 1 フレームずつ撮影し ffmpeg で mp4 化
- 必要なもの: Docker(VOICEVOX ENGINE)、Node.js + Playwright、ffmpeg、Python 3 + numpy + scipy、IPA 明朝・IPA ゴシック

## 事実関係について

事件の経過は広く知られている通説に基づいていますが、時刻・数字・証言の細部は資料によって異なります。
動画の最後に「諸説あります」と表記しています。主な参考: 松本清張『日本の黒い霧』(1960)、柴田哲孝『下山事件 最後の証言』(2005)、
各種新聞報道・事件解説。

VOICEVOX の音声を公開する場合は利用規約に従い「VOICEVOX:四国めたん」のクレジット表記が必要です(動画の最後と説明文に記載済み)。
