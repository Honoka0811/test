# 空自スクランブル(緊急発進)の推移 — ショート動画

航空自衛隊の緊急発進(スクランブル)回数が、2010年度から2026年度上半期までどう推移したかを
数字で追う縦型ショート動画(1080×1920 / 30fps / 68秒)です。字幕とナレーション付き。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグ/チェックリストの `metadata.md`)
- 完成動画(ナレーション付き): `output/scramble_trend_narrated.mp4`
- 完成動画(無音・字幕なし): `output/scramble_trend.mp4`
- ナレーション音声のみ: `output/narration.wav`
- サムネイル: `output/thumbnail.png`

## 構成(68秒)

| 時間 | シーン | 内容 |
|---|---|---|
| 0:00–0:08 | フック | 2025年度 595回 = 1日あたり約1.6回。「ピーク時はこの2倍だった」 |
| 0:08–0:17 | スクランブルとは | レーダー探知 → 5分以内に離陸 → 並走・警告で領空侵犯を防ぐ |
| 0:17–0:33 | 年度別の推移 | 2010→2025年度の棒グラフ。ピーク2016年度 1,168回(1日3回以上)、2025年度は過去5年で最少 |
| 0:33–0:44 | 相手はどこの国か | 中国機・ロシア機の折れ線(2010→2025)、2025年度の内訳 中国61%・ロシア36% |
| 0:44–0:52 | どこで起きているか | 航空方面隊別。南西航空方面隊(那覇)が348回で約6割 |

| 1:01–1:08 | まとめ | 3つのポイント + 出典・クレジット |

## 再生成の方法

```bash
cd scramble-trend
node capture.js            # output/scramble_trend.mp4 (無音版) を生成
python3 narrate.py         # ナレーション合成 + BGM ミックスで output/scramble_trend_narrated.mp4 を生成
node thumbnail.js          # output/thumbnail.png を生成
./export_upload.sh         # upload/ にアップロード用一式を書き出す(-14 LUFS 正規化・ステレオAAC・SRT・JPG)
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)。`renderThumb()` がサムネイル用の静止画
- `capture.js` … Playwright(Chromium)で 1 フレームずつ撮影し、ffmpeg(libx264)にパイプして mp4 化
- `bgm.py` … `pacific-war-analysis/bgm.py` と同じ自作BGM(テンポを 84BPM に変更)。権利表記は不要
- `narrate.py` … シーンごとの原稿を合成し、各シーンの長さに収まるよう話速を自動調整。BGM はナレーション中に自動で音量を下げてミックス
- 必要なもの: Node.js, `playwright`(Chromium), `ffmpeg`, 日本語フォント(IPAゴシック), Python 3 + `numpy` + `pyopenjtalk`

### ナレーションの音声について

現在の `upload/` に入っている動画のナレーションは **Open JTalk(pyopenjtalk)** で合成しています。
`pacific-war-analysis` と同じく **VOICEVOX(青山龍星)** を使いたい場合は、`pacific-war-analysis/README.md` の
「VOICEVOX のセットアップ」の手順でコアと音声モデルを導入してから `python3 narrate.py` を再実行してください
(`narrate.py` は `voicevox_core` があれば自動でそちらを使います)。その際は `render.html` の `VOICE_CREDIT` を
`音声: VOICEVOX:青山龍星` に書き換え、`upload/metadata.md` のクレジットも合わせて変更し、`node capture.js` から再生成してください。

Open JTalk は VOICEVOX より話速が遅いため、原稿は VOICEVOX 向けより短めにしてあります。VOICEVOX に切り替える場合は
`narrate.py` の `SCRIPT` を少し長くしても尺に収まります。

色は 中国=オレンジ `#F0785A`、ロシア=青 `#4FA3E8`、強調=黄 `#F5C451` の固定。
