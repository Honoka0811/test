# 空自スクランブル(緊急発進)の推移 — ショート動画

航空自衛隊の緊急発進(スクランブル)回数が、2010年度から2026年度上半期までどう推移したかを
数字で追い、ピークから減少した理由の分析を加えた縦型ショート動画(1080×1920 / 30fps / 85秒)です。字幕とナレーション付き。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・コピペ用の `youtube_title.txt` / `youtube_description.txt` / `youtube_tags.txt`・YouTube Studio での手順とチェックリストを書いた `metadata.md`)
- 完成動画(ナレーション付き): `output/scramble_trend_narrated.mp4`
- 完成動画(無音・字幕なし): `output/scramble_trend.mp4`
- ナレーション音声のみ: `output/narration.wav`
- サムネイル: `output/thumbnail.png`

## 減少理由の分析(動画 0:52〜 のシーン)

防衛省・統合幕僚監部は減少理由を「さまざまな要因を勘案する必要がある」と述べるにとどめ、公式には明言していません。
動画では報道・専門家の見解から次の3つの見方を「仮説」として提示しています。いずれも公式に因果が確認されたものではありません。

| # | 見方 | 根拠となる事実 | 主な出典 |
|---|---|---|---|
| 1 | 中国機の飛び方の「定型化」 | 2016年度は中国戦闘機の東シナ海飛来が急増し中国機対応が851回。2017年度は500回に減った一方、防衛省が公表する「特異な飛行」は2017年4〜12月で前年同期比12件増 | 統幕公表資料、Newsweek日本版(ロイター)2018年1月 |
| 2 | ロシア側の事情 | ウクライナ侵攻が始まった2022年度、ロシア機への対応は150回と2013年度以降で最少(前年度266回) | 統幕公表資料、日本経済新聞 2023年4月 |
| 3 | 空自側の限界と「効率化」 | 元自衛官の軍事評論家は「脅威が減ったのではなく対応能力が限界」と指摘。中国無人機への発進は2023年度8回→2024年度23回に増え、燃料・整備・疲労の面から「全てに戦闘機で応じない」運用が模索されている | JBpress(数多久遠)、乗りものニュース、Yahoo!ニュース エキスパート(高橋浩祐) |

あわせて、回数が減った2025年度にも中国ヘリの領空侵犯(5月)、中国艦載戦闘機によるレーダー照射、中ロ爆撃機の共同飛行が起きており、
「回数の減少 ≠ 脅威の低下」という整理にしています。

## 再生成の方法

```bash
cd scramble-trend
node capture.js            # output/scramble_trend.mp4 (無音版) を生成
python3 narrate.py         # ナレーション合成 + BGM ミックスで output/scramble_trend_narrated.mp4 を生成
node thumbnail.js          # output/thumbnail.png を生成
./export_upload.sh         # upload/ にアップロード用一式を書き出す(-14 LUFS 正規化・ステレオAAC・SRT・JPG)
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画(ブラウザで開くとプレビュー再生)。`renderThumb()` がサムネイル用の静止画。`render()` は描画全体を 0.9 倍に縮めて左寄せし、ショート動画の UI(下部のタイトル欄・右側のアイコン列)に字幕や出典が隠れないセーフエリアに収めている(`SAFE_SCALE` / `SAFE_DX` / `SAFE_DY`)
- `capture.js` … Playwright(Chromium)で 1 フレームずつ撮影し、ffmpeg(libx264)にパイプして mp4 化
- `bgm.py` … `pacific-war-analysis/bgm.py` と同じ自作BGM(テンポを 84BPM に変更)。権利表記は不要
- `narrate.py` … シーンごとの原稿を合成し、各シーンの長さに収まるよう話速を自動調整。BGM はナレーション中に自動で音量を下げてミックス
- 必要なもの: Node.js, `playwright`(Chromium), `ffmpeg`, 日本語フォント(IPAゴシック), Python 3 + `numpy` + `pyopenjtalk`(辞書用) + `voicevox_core`

### ナレーションの音声について

`upload/` の動画のナレーションは **VOICEVOX(青山龍星 ノーマル, style 13)** で合成しています。
VOICEVOX の音声を公開する場合は、利用規約に従い「VOICEVOX:青山龍星」のクレジット表記が必要です
(動画の最後のカードと `upload/metadata.md` の説明文に記載済み)。

セットアップは `pacific-war-analysis/README.md` の「VOICEVOX のセットアップ」と同じで、
`voicevox_core` の wheel を `pip install` し、ONNX Runtime と `15.vvm` を次の既定パスに置きます
(別の場所に置く場合は環境変数 `VOICEVOX_ORT` / `VOICEVOX_VVMS` で指定)。

| 必要なもの | 既定パス |
|---|---|
| ONNX Runtime | `/home/user/vv/ort/voicevox_onnxruntime-linux-x64-1.17.3/lib/libvoicevox_onnxruntime.so` |
| 音声モデル `15.vvm`(青山龍星) | `/home/user/vv/vvms/` |

`voicevox_core` が無い環境では `narrate.py` が自動で Open JTalk(pyopenjtalk)にフォールバックします。
その場合は VOICEVOX より話速が遅いため、`SCRIPT` を1〜2割短くしないと尺に収まらないことがあります
(各シーンの合成秒数と上限は実行時に表示されます)。また `render.html` の `VOICE_CREDIT` と
`upload/metadata.md` のクレジットを「Open JTalk」に書き換えてください。

色は 中国=オレンジ `#F0785A`、ロシア=青 `#4FA3E8`、強調=黄 `#F5C451` の固定。
