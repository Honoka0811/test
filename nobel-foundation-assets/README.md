# ノーベル財団の資産の推移 — ショート動画

ノーベルの遺産(約3,100万クローナ)が、125年で約67億クローナ(約200倍)になるまでを追う縦型ショート動画(1080×1920 / 30fps / 約66秒)。
ナレーションは **VOICEVOX:四国めたん(ノーマル)**、BGM は numpy で合成した自作曲(権利フリー)。字幕は動画に焼き込み済み。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)
- 中間成果物: `output/nobel_foundation_assets.mp4`、`output/subtitles_ja.srt`、`output/cues.js`

## 使用データ(概数・名目値)

| 項目 | 値 | 出典 |
|---|---|---|
| 基金(1900年) | 約3,100万クローナ(遺産の94%) | nobelprize.org、Wikipedia「Nobel Foundation」 |
| 賞金の実質価値の低下 | 1945年ごろ当初の1/3未満 | nobelprize.org「Financial management」ほか |
| 非課税化 | スウェーデン 1946年 / 米国の投資課税 1953年 | 同上 |
| 投資規制の緩和 | 1953年(1950年代初め)株式等への投資が可能に | 同上 |
| 運用資本 | 2012年初 約30億弱 / 2017 44.96億 / 2022 57.99億 / 2024 67.97億 / 2025 67.44億 | ノーベル財団 年次報告書・報道 |
| 賞金 | 1901 約15万 / 2001 1,000万 / 2012 800万 / 2017 900万 / 2020 1,000万 / 2023 1,100万 / 2026 1,200万 | ノーベル財団 プレスリリース |

2012年は期初の運用資本、それ以外は年末の総運用資本(市場価値)。測り方が年によって少し違うため、動画内でも「概数・名目値」と明記している。

## 再生成

```bash
python3 narrate.py      # ナレーション合成(四国めたん)+字幕 cues.js / SRT + BGM ダッキングミックス → output/mix.wav
node capture.js         # render.html を撮影し、mix.wav を多重化 → output/nobel_foundation_assets.mp4
./export_upload.sh      # -14 LUFS 正規化・サムネイル生成 → upload/
```

- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを描画(字幕は `output/cues.js` から焼き込み)。ブラウザで開くとプレビュー再生
- `bgm.py` … Cメジャー/100BPM の明るい解説系BGM(エレピ・ベース・ドラム・ベル)を合成
- `narrate.py` … シーンごとに話速を自動調整して合成。原稿は `SCRIPT`(読み上げ用と字幕用の2列)
- VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じ。四国めたんは `0.vvm`(style 2 = ノーマル、0 = あまあま)
- 公開時は VOICEVOX 利用規約に従い「VOICEVOX:四国めたん」のクレジットが必要(動画の最後と説明文に記載済み)
