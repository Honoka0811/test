# YouTube Shorts：「どの色が最初に脱出する？」

`short.mp4` … 縦型 1080×1920 / 60fps / 38秒 / 効果音付き（すぐ投稿できます）

回転するリングの中で5色のボールが跳ね回り、隙間から脱出した順に順位が付く物理シミュレーション動画です。
跳ねるたびにペンタトニックの音が鳴り、脱出時にはチャイムが鳴ります。

## なぜこの企画なのか（1万再生を狙う理由）
- **結果が気になる**：「どれが勝つ？」という問いで、最後まで見られやすい（視聴維持率が上がる）
- **コメントが集まる**：冒頭で「コメントで予想してね」と促しているので、エンゲージメントが増える
- **言葉がいらない**：色と動きだけで伝わるので、海外の視聴者にも届く
- **心地よい映像と音**：物理シミュレーション系のショートは、ループ再生されやすい定番ジャンル
- **38秒と短い**：Shorts は短くて展開がはっきりしている方が伸びやすい
- **展開を調整済み**：1位が9秒、最下位の赤が34秒までひとり残る、という盛り上がる展開になるシード（182）を選んでいます

## 投稿のコツ
1. 日本向けは **平日19〜22時 / 土日12時ごろ** に投稿する
2. 投稿したらすぐ固定コメントを付け、最初の1時間についたコメントには全部返信する
3. **シリーズ化**が一番効きます。シードを変えて毎日1本ずつ投稿すると、
   アルゴリズムがチャンネルの方向性を覚えて、伸びる動画が出やすくなります
   ```
   python3 make_short.py --search        # 展開が面白いシード候補を表示
   python3 make_short.py --seed 164 --out part2.mp4
   ```
   （例：164 は最後の1つが47秒まで残る「一騎打ち」型の展開）
4. 「脱出したボールが2倍に増える」「ボール100個」などの派生企画も作れます（`make_short.py` の定数を変えるだけ）

## 再生成
必要なもの：Python 3 + numpy + Pillow、ffmpeg、IPAゴシックフォント
```
python3 make_short.py --seed 182
```
