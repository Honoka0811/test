# 歌ってみた動画キット「ミライシグナル」(オリジナル曲)

著作権の心配がない **完全オリジナル曲** で、そのまま歌って録音・投稿できる素材一式です。

| ファイル | 用途 |
|---|---|
| `mirai_signal_guide_karaoke.mp4` | ガイドメロディ入りカラオケ動画（練習用） |
| `mirai_signal_offvocal_karaoke.mp4` | オフボーカル＋歌詞ワイプ動画（**投稿用のベース映像**） |
| `mirai_signal_offvocal.wav` | オフボーカル音源（録音・ミックス用, 44.1kHz/16bit） |
| `lyrics_karaoke.ass` | カラオケ字幕（ワイプ付き） |
| `thumbnail.png` | サムネイル 1280×720 |
| `src/song.py`, `src/art.py` | 音源・字幕・画像の生成スクリプト（作り直し用） |

曲データ：BPM128 / Key C / 約70秒（イントロ → Aメロ → Bメロ → サビ×2 → アウトロ）
コード進行：サビは王道進行（F→G→Em→Am）

```
眠らない夜を越えて 朝まで歌うよ

響け ミライシグナル この声が届くまで
泣いてた昨日を越えて 笑顔で歌うよ
```

## 完成までの手順（あと少し！）
1. ガイド入り動画で練習し、`mirai_signal_offvocal.wav` を流しながらイヤホンで歌を録音（スマホでもOK）
2. 録音した声をオフボーカルと合わせる（BandLab・GarageBand など無料アプリで可。声にリバーブを少し）
3. 合わせた音声を `mirai_signal_offvocal_karaoke.mp4` の映像に差し替え
   ```
   ffmpeg -i mirai_signal_offvocal_karaoke.mp4 -i mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest final.mp4
   ```

## 1万再生を狙うための作戦
再生数は保証できませんが、伸びやすくする定番の打ち手はこれです。
- **ショート動画を同時投稿**：サビ（0:30〜0:45あたり）を縦型で切り出して「本編はこちら」と誘導。新人の再生はほぼショート経由で生まれます
- **最初の3秒で声を聴かせる**：本編も冒頭にサビを数秒入れると離脱が減ります
- **サムネは文字少なく・大きく**：同梱サムネはその方針で作っています。顔出しなしならイラストを足すと◎
- **投稿は夜（20〜22時）**：曲のテーマ「眠れない夜」と時間帯を合わせる
- **X / TikTok でも同時告知**、コメントには全部返信して最初の視聴者を固定ファンに
- **週1本ペースで続ける**：1本目より「チャンネル全体」で1万を狙うのが現実的
