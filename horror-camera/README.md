# 人物を検知しました — 見守りカメラのホラーショート

猫のために置いた見守りカメラから、毎日同じ時刻に「人物を検知しました」と通知が届く。
録画には誰も映っていないのに、AI は何もない場所を緑の枠で囲んでいる——。
四国めたん(VOICEVOX)が語るオリジナルの短編ホラーです。縦型 1080×1920 / 30fps / 約65秒。
画面全体を「スマホの画面」として作ってあり、ロック画面の通知・カメラアプリ・通知履歴がそのまま映像になります。

- **完成動画: `output/jinbutsu_kenchi.mp4`**(ナレーション・効果音・字幕焼き込み済み)
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt` / タイムライン: `output/timeline.json`

> ⚠ 終盤(約 0:56)に大きな音と顔が出るジャンプスケアがあります。

## 声と音

- ナレーションはすべて **VOICEVOX:四国めたん**
  - 語り = ノーマル / 通知の読み上げ「人物を検知しました」= ノーマルの抑揚を消して機械的に
  - 「枠は、私の、目の前にありました」「そのスマホのカメラにも〜」= ヒソヒソ
  - 「ねえ、見えてないの?」= ささやきを約3半音下げ、逆残響の吸い込みから始めて左右中央=目の前に定位
- 効果音はすべて numpy/scipy で合成(外部音源なし): 通知音、机の上で震えるスマホ、猫の威嚇、カメラが夜間モードに切り替わる「カチッ」、AI の検知枠が出るときの電子音、カメラのマイクが拾うサーッというノイズ(ときどきデジタルの途切れ)、心音、緊張音、スケアの衝撃音
- 音量: 全体 約 -16 LUFS。スケアがナレーションより約 +8dB 大きい

## 映像の作り

- 見守りカメラの映像は、部屋を簡易 3D(床・壁・ベッド・クローゼット・窓・ラグ・テーブル・猫)で組み、天井近くの隅に置いたカメラから透視投影して描画。昼はカラー、夜は赤外線(白黒・カメラからの距離で暗くなる・猫の目が光る)
- AI の検知枠は、3D 空間の「人がいる位置」の箱を投影した外接矩形。毎フレーム少し揺れる(物体検出らしさ)
- 映像は半分の解像度で描いて引き伸ばし、ノイズと走査線を重ねて監視カメラらしい甘さを出す。最後のデジタルズームではわざと画素を粗くする

## 再生成

```bash
cd horror-camera
./setup.sh      # VOICEVOX CORE 0.17.1・ONNX Runtime・音声モデル(0.vvm, 5.vvm)・Noto Serif JP
./build.sh      # 音声 → 映像 → サムネイル → 合成 → output/jinbutsu_kenchi.mp4
```

台本は `audio.py` の `TIMELINE`。検知枠が出るタイミングは `mark`(`box_on` / `box2_on` / `box_face`)、枠の位置は `render.html` の `BOX_*` と `APPROACH` で変えられます。
