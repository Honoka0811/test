# もういいかい — かくれんぼの怪談

「その子が鬼のときは、何度聞かれても『まあだだよ』と答えなさい。」
おばあちゃんの家で、毎年夏にかくれんぼをした、大人には見えない女の子。
二十年後、祖母の葬儀で帰った夜、押入れの中から「もういいかい」と聞こえてくる——。

## 声と音

- ナレーションはすべて **VOICEVOX:四国めたん**
  - 語り = ノーマル / おばあちゃんの言いつけ = セクシーを低く・ゆっくり
  - 子どもの「もういいかい」「みいつけた」、偽物の「もういいよ」、囁きの「まあだだよ」は **VOICEVOX の歌唱機能**で歌わせた(楽譜 → 歌の先生 波音リツが音程を作り、四国めたんの歌声スタイル あまあま / ノーマル / ヒソヒソで発声)。かくれんぼの節(ソ→ミ)のまま歌う
  - 子どもの声は約1半音上げ、聞こえる場所(遠く / 押入れの中 / 障子のすぐ向こう)で響きを変える
  - 「もういいよ」は語り手と同じ四国めたん ノーマルの声で、右うしろのすぐ近くから鳴る(=自分の声が後ろで答える)
- 効果音はすべて numpy/scipy で合成(外部音源なし): ひぐらし、風鈴、仏壇のおりん、柱時計の振り子、夜の虫の声(障子のシーンで鳴きやむ)、子どもの素足が板の間を歩く音と床のきしみ、指で障子紙を突き破る音、心音、緊張音、スケアの衝撃音
- 音量: 全体 約 -16 LUFS。スケアがナレーションより約 +8dB 大きい

## 再生成

```bash
cd horror-kakurenbo
./setup.sh      # VOICEVOX CORE 0.17.1・ONNX Runtime・音声モデル(0.vvm, 5.vvm, s0.vvm)・Noto Serif JP
./build.sh      # 音声 → 映像 → サムネイル → 合成 → output/mou_iikai.mp4
```

歌わせる台詞の楽譜は `audio.py` の `VOICES`(`notes` = 歌詞・MIDI 音高・秒)にあります。
