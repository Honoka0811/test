# もういいかい — かくれんぼの怪談

「その子が鬼のときは、何度聞かれても『まあだだよ』と答えなさい。」
おばあちゃんの家で、毎年夏にかくれんぼをした、大人には見えない女の子。
二十年後、祖母の葬儀で帰った家で見つけたのは、昭和三十一年から書き続けられた祖母の日記だった——。
その夜——お葬式の夜、柱時計が一時を打つと、押入れの中から「もういいかい」と聞こえてくる。
四国めたん(VOICEVOX)が語るオリジナルの短編ホラーです。縦型 1080×1920 / 30fps / 約98秒。

前日譚(女の子の正体)入り: 女の子は、昭和三十一年の夏、かくれんぼで押入れに隠れたまま見つからず亡くなった祖母の妹。
鬼だった祖母は、それから七十年、毎晩「まあだだよ」と答え続けて孫たちを守っていた。祖母が亡くなり、答える人がいなくなった——。

起きるのはすべて**お葬式の夜、ひと晩のうち**(一時・二時・三時)。答えるたびに、声が一歩ずつ近づいてくる。

オチは「もういいよ」の二重の意味(かくれんぼの「もう隠れたよ」/ 日常語の「もうやめて」)。祖母の言いつけ(=決まり)は最後まで破られず、破ったのは主人公自身の、悪気のない一言。冒頭の「絶対に言っちゃいけない言葉」に戻ってくる。

## 声と音

- ナレーションはすべて **VOICEVOX:四国めたん**
  - 語り = ノーマル / おばあちゃんの言いつけと日記 = セクシーを低く・ゆっくり
  - 子どもの「もういいかい」「みいつけた」と囁きの「まあだだよ」は、遠くへ呼びかけるように伸ばした話し声(「もーいーかーい」「みーつけた」「まーだだよー」)。四国めたん あまあま / ささやき / ヒソヒソ。歌唱機能で節をつける案も試したが、呼びかけとしては不自然だったため話し声にした
  - 子どもの声は約1半音上げ、聞こえる場所(遠く / 押入れの中 / 障子のすぐ向こう)で響きを変える
  - 主人公の「もう、いいよ……やめて……」= 四国めたん ノーマルを遅く・抑揚を落として、泣きそうに
- 日記のページをめくる場面では、四国めたん(ヒソヒソ)の「まあだだよ」を5回、少しずつ低く・遅く(=年老いていくように)重ねて「七十年分の夜」を表現
- 効果音はすべて numpy/scipy で合成(外部音源なし): ひぐらし、風鈴、仏壇のおりん、古いノートのページをめくる音、柱時計が時を打つ音(ボーン)、柱時計の振り子、夜の虫の声(障子のシーンで鳴きやむ)、子どもの素足が板の間を歩く音と床のきしみ、指で障子紙を突き破る音、心音、緊張音、スケアの衝撃音
- 音量: 全体 約 -16 LUFS。スケアがナレーションより約 +8dB 大きい

cd horror-kakurenbo
./setup.sh      # VOICEVOX CORE 0.17.1・ONNX Runtime・音声モデル(0.vvm, 5.vvm(s0.vvm は歌唱を使う場合のみ))・Noto Serif JP

台詞は `audio.py` の `TIMELINE`。子どもの声などは `{'dur': 秒}` で長さを固定してあり、声だけ差し替えても映像の時刻は変わりません(`VOICES` に `sing` と `notes` を書けば歌唱機能で歌わせることもできます)。
