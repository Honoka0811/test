# データで見る 日本の外国人 — ショート動画

日本で暮らす外国人(在留外国人)と外国人労働者の推移・内訳・将来推計を数字で追う、縦型ショート動画(1080×1920 / 30fps / 約67秒)です。
ナレーションは **VOICEVOX:四国めたん(ノーマル)**、BGMは `bgm.py` で合成した自作曲(権利フリー)。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)
- 完成動画(ナレーション+BGM): `output/japan_immigration_narrated.mp4`
- 無音版: `output/japan_immigration.mp4` / ナレーションのみ: `output/narration.wav`
- 原稿: `narration_script.txt`(読み上げ用の原稿は `narrate.py` の `SCRIPT`)

## 再生成の方法

```bash
node capture.js        # output/japan_immigration.mp4(無音版)
python3 narrate.py     # 四国めたんのナレーション合成 + BGMダッキングミックス → output/japan_immigration_narrated.mp4
./export_upload.sh     # upload/ に -14 LUFS 正規化した最終版・字幕・サムネイル
```

VOICEVOX CORE のセットアップは `../pacific-war-analysis/README.md` と同じです。四国めたんは音声モデル **`0.vvm`** に入っています(スタイルID 2 = ノーマル、0 = あまあま、6 = ツンツン。`VOICEVOX_STYLE=0 python3 narrate.py` で変更可)。
公開時は利用規約に従い「VOICEVOX:四国めたん」のクレジット表記が必要です(動画の最後と説明文に記載済み)。
