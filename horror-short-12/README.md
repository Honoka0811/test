# クローゼットの女 — ホラーショート動画(12本目)

縦型ショート動画(1080×1920 / 30fps / 約67秒)。一人暮らしの部屋を舞台にした、オリジナルの怪談です。

- 完成動画: `output/closet_no_onna.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、天井裏の男=ヒソヒソを低くして、こもらせる) |
| BGM・効果音 | `sound.py` で numpy 合成(夜の部屋の音、時計の秒針、低いピアノ、ドローン、不協和ストリングス、心音、ガムテープ、引き戸、ライトのスイッチ、天井のきしみ、落ちるほこり、点検口のふたがずれる音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画(ベッドから見た部屋、すき間のアップ、朝の部屋、ライトで照らしたクローゼットの天井) |
| フォント | しっぽり明朝(OFL-1.1) |

## 筋(どんでん返し)と、手がかり

- 夜中、クローゼットのすき間に白い顔が見えた気がする。寝ぼけたと思う
- 朝、戸は本当に開いている。気のせいか確かめるため、戸にテープを貼って寝る
- 夜中、テープははがされ、女の人が黙って上を指さし、声を出さずに「にげて」と口を動かす
- 朝いちばんに管理会社へ電話すると、前の住人の女性は荷物を残したまま急にいなくなっていた。今夜は友達の家に泊まることにする
- 着がえを取ろうとクローゼットを照らすと、天井の点検口のふたがずれていて、まわりに指の跡がある
- テープをはがしていたのは女の人ではなく、天井裏の男だった。女の人(前の住人)は、それを知らせていた
- 最後に天井裏から「どこに泊まりに行くの」。管理会社への電話も、泊まりに行く話も、ぜんぶ聞かれていた
- 主人公の行動は、現実の人がとる順番にしてある: 寝ぼけたと思う → 確かめる → 相談する → 逃げる準備をする
- 見返すと分かる手がかり: はがされたテープが、すき間の内側へめくれている(中から引っぱられた) / 女の人は、こわがらせるのではなく、上を指さしている / 日本の集合住宅のクローゼットには、たいてい天井に点検口がある

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
