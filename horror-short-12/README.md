# クローゼットの女 — ホラーショート動画(12本目)

縦型ショート動画(1080×1920 / 30fps / 約63秒)。一人暮らしの部屋を舞台にした、オリジナルの怪談です。

- 完成動画: `output/closet_no_onna.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、天井裏の男=ヒソヒソを低くして、こもらせる) |
| BGM・効果音 | `sound.py` で numpy 合成(夜の部屋の音、時計の秒針、低いピアノ、ドローン、不協和ストリングス、心音、ガムテープ、引き戸、ライトのスイッチ、天井のきしみ、落ちるほこり、点検口のふたがずれる音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画(ベッドから見た部屋、すき間のアップ、朝の部屋、ライトで照らしたクローゼットの天井) |
| フォント | しっぽり明朝(OFL-1.1) |

## 筋(どんでん返し)と、手がかり

- 毎晩、クローゼットのすき間から女の人がのぞいている。見る人は「この女の人が怖いもの」と思う
- 戸をガムテープでとめても、次の夜には開いている。女の人は黙って上を指さす
- 前の住人の女性は、ある日急にいなくなっていた。女の人は声を出さずに「にげて」と口を動かす
- クローゼットの天井の点検口を照らすと、ふたがずれていて、まわりに指の跡がある
- ガムテープをはがしていたのも、毎晩戸を開けていたのも、女の人ではなく、天井裏に住んでいる男だった。女の人(前の住人)は、ずっとそれを知らせていた
- 最後に天井裏から「今日は、起きてるんだね」。男は毎晩、寝顔を見に下りてきていた
- 見返すと分かる手がかり: はがされたガムテープが、すき間の内側へめくれている(中から引っぱられた) / 女の人は最初から、こわがらせるのではなく、上を指さしている / 日本の集合住宅のクローゼットには、たいてい天井に点検口がある

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
