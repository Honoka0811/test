# 半導体業界ショート「ただの砂が100兆円に化ける」

YouTube ショート向けの縦型動画(1080×1920 / 30fps / 約60秒)です。
ナレーションは VOICEVOX:四国めたん。BGM と効果音はプログラムで合成した自作音源(権利フリー)です。

- **アップロード用一式: `upload/`**(動画 mp4・字幕 SRT・サムネイル JPG・タイトル/説明文/タグの `metadata.md`)
- ナレーション音声のみ: `output/narration.wav`
- BGM のみ: `output/bgm.wav`

## 構成(約60秒)

| 時間 | 章 | 内容 | 主な演出 |
|---|---|---|---|
| 0:00 | フック | ただの砂が年間100兆円に化ける | 砂山が「100兆円」の衝撃で弾け、粒子がチップの形に集まる |
| 0:05 | #1 原料 | 純度 99.999999999%(イレブンナイン) | インゴット、9 を1桁ずつ打ち込むカウンター、判子 |
| 0:11 | #2 微細化 | 最先端は「2nm」世代、髪の毛の4万分の1 | 入れ子のチップ枠のズームトンネル、髪の毛との比較 |
| 0:17 | #3 集積 | トランジスタ2,000億個、工程1,000以上、3か月 | セルが点灯するダイ、積み上がる層、進捗バー |
| 0:24 | #4 一極集中 | 先端品の9割は台湾TSMC 1社 | 台湾のドット地図、警告画面、スマホ・車・AI に赤い× |
| 0:34 | #5 独占装置 | EUV 露光装置は ASML 1社、1台数百億円 | 光路が走る装置、空欄だらけのランキング、価格カウンター |
| 0:42 | #6 日本の強み | 材料で世界トップ、熊本 TSMC と北海道 Rapidus | 日本のドット地図、シェアのバー、拠点ピン |
| 0:53 | 締め | 次に勝つのはどの国? | A〜E の投票ルーレット、コメントボタンを指す矢印、冒頭の砂山に戻ってループ |

視聴維持のための仕掛け:

- 0秒目から衝撃音つきで始まり、最初の1.4秒で「100兆円」を見せる
- 字幕はフレーズ単位で音声に合わせて飛び出し、キーワードを黄色で強調(音声とのずれは ±0.08 秒以内を確認済み)
- 章番号タグと上部の章進捗バーで「あと何章か」が見える
- 場面転換ごとにグリッチ・フラッシュ・カメラの揺れ・ウーシュ音
- BGM は台湾(TSMC)の場面の頭でサビ(ドロップ)になるようテンポを逆算(約130.6 BPM)。直前にスネアロールとライザーで溜める
- 最後に視聴者への質問(A〜E で答えられる)でコメントを促し、最終フレームが冒頭とつながるのでループ再生されやすい

## 作り方

```bash
cd semiconductor-shorts
./setup.sh   # VOICEVOX CORE・ONNX Runtime・音声モデル・辞書・フォントを vendor/ に取得(初回のみ)
./build.sh   # ナレーション → 映像 → BGM/効果音ミックス → upload/ まで全部作り直す
```

個別に動かす場合:

| スクリプト | 役割 |
|---|---|
| `narrate.py` | 原稿をシーンごとに VOICEVOX(四国めたん ノーマル, style 2)で合成。音声の長さからシーン尺を決め、句読点の位置から字幕の切り替え時刻を計算して `output/timeline.json` / `timeline.js` / `subtitles_ja.srt` / `narration.wav` を出力 |
| `render.html` | Canvas 2D で時刻 t のフレームを決定論的に描く。ブラウザで開くとプレビュー再生 |
| `capture.js` | Playwright(Chromium)で全フレームを撮影して無音 mp4 にし、効果音の時刻表 `output/events.json` を書き出す |
| `audio.py` | BGM と効果音を numpy/scipy で合成し、ナレーション中は BGM を自動で下げてミックス、-14 LUFS に正規化して動画に合成 |
| `preview.js` | 指定時刻のフレームを PNG で書き出す(確認用) |

原稿は `narrate.py` の `SCRIPT` にあります。読み上げ用の文と画面字幕を別々に書けます(字幕の `[ ]` は強調色、`/` は改行)。
話者を変えるときは `VOICEVOX_STYLE=0 python3 narrate.py`(0 = 四国めたん あまあま、6 = ツンツン、3 = ずんだもん)。
