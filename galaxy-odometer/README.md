# じっとしているあなたが、この56秒で進む距離…(YouTube ショート)

動画の時計と連動した「実走メーター」が、再生開始からあなたが運ばれた距離を数え続ける縦型ショートです。
メーターは **秒速およそ227km × 経過秒**(太陽系が天の川銀河の中心を回る速さ)。
12,742km(地球の平均直径)÷ 227km/s ≒ **56.13秒** なので、最後のフレームでメーターがちょうど地球1個ぶんに届きます。

- **アップロード用一式: `upload/`**(mp4・字幕SRT・サムネイルJPG・タイトル/説明文/チェックリストの `metadata.md`)
- 仕様: 1080×1920 / 60fps / 56.15秒 / H.264 + AAC ステレオ / -14 LUFS

## 構成(約56秒)

| 時間 | 内容 |
|---|---|
| 0:00 | フック「この動画が始まってから、あなたはもう500キロ動いた」(メーターが 2.20 秒で 500km を通過) |
| 0:03 | 容疑者は3つ: 自転・公転・？？？。ゴールは「？？？1個ぶん」と伏せたまま |
| 0:06 | 容疑者1 自転: 東京の地面は時速 約1,360km。でもそれで進めたのは 5km → 足りない |
| 0:14 | 容疑者2 公転: 秒速 約30km。それでも 600km → 2つ足してもメーターの 13% |
| 0:24 | 真犯人: 天の川銀河。秒速およそ227km でメーターとぴったり一致 |
| 0:32 | 残るはゴール(あるもの1個ぶん)。残り秒数のカウントダウン開始 |
| 0:35 | 人類最速の探査機(の記録)より速い → 1周およそ2億年 → 前回は恐竜が現れたころ → 人類の歴史は1周の 1/700 |
| 0:46 | 1年で約72億km(年齢×72億km のコメント呼びかけ)→ 生まれてから一度も同じ場所にいたことがない |
| 0:51 | 見始めた場所は、もう——ほぼ地球1個ぶん、うしろ。「何度見ても、」→ 冒頭へループ |

画面には常時、(1) 実走メーター、(2) ゴールゲージ(通過した 月→水星→火星→金星 の直径が刻まれる)、
(3) 通過ログ(東京→大阪 400km など、実際にその距離に達した時刻に出る)が出ています。

## 作り方(再生成)

```bash
cd galaxy-odometer
./build.sh          # 全工程(約8分)。upload/ に一式を書き出す
./build.sh audio    # 音声だけ作り直す(映像は撮り直さない)
node tools/sheet.js "0,2.25,26,56.1334" build/sheet.png --ui 1   # 指定時刻の静止画を並べて確認(--ui 1 でショートの UI 領域を重ねる)
```

| ファイル | 役割 |
|---|---|
| `script.json` | 台本。1行 = 1文、`chunks` がテロップの区切り。`say` は読み方の指定、`cue` は映像・効果音の合図 |
| `tts.py` | VOICEVOX でナレーションを**先に**合成し、モーラ単位の実測時刻から `build/timeline.json` を作る |
| `src/plan.js` | タイムライン → シーン時刻・通過点・効果音イベント(映像と音声で共通) |
| `src/lib.js` `src/parts.js` `src/video.js` | Canvas 2D の描画。`render(t)` が時刻 t 秒のフレームを決定論的に描く |
| `render.html` | ブラウザで開くとプレビュー再生(`?t=12.5` でその時刻の静止画) |
| `capture.js` | Playwright(Chromium)で 1 フレームずつ並列撮影 → ffmpeg(libx264)で mp4 |
| `bgm.py` `sfx.py` `mix.py` | BGM と効果音を numpy だけで合成し、ナレーションに合わせて BGM を下げてミックス |
| `build.sh` | 上記を順に実行し、-14 LUFS に正規化して `upload/` に書き出す |
| `tools/make_land.py` | Natural Earth の陸地データから地球儀用のマスク(`data/land.js`)を作る |

音声が先、映像が後なので、台本を書き換えて `./build.sh` を回せば、テロップ・シーン・効果音の時刻は自動で合います。
時刻に依存する台詞(「もう500キロ」「たった5キロ」「やっと600キロ」)は、`python3 tts.py script.json --check` で
話す時刻を確認し、その時刻の実際の値(銀河 227×t、自転 0.378×t、公転 29.78×t km)と合っていることを確かめてください。

## 数字と出典

| 項目 | 値 | 出典・計算 |
|---|---|---|
| 銀河の回転速度(太陽系の位置) | 秒速 およそ227km(誤差 約5%) | 国立天文台 VERA(2020), PASJ 72, 50 |
| 銀河の中心までの距離 | 約2万5800光年 | 同上 |
| 銀河1周 | およそ2億年(計算値 約2.1億年) | 2π × 25,800光年 ÷ 227km/s。NASA は約2.3億年 |
| 自転(東京・北緯35.68°) | 時速 約1,360km(秒速 0.378km) | NASA Earth Fact Sheet(赤道半径・恒星日)から計算 |
| 音速 | 時速 約1,225km(気温15℃) | ICAO 標準大気 |
| 公転 | 秒速 約29.78km(平均) | NASA Earth Fact Sheet |
| 地球の直径(平均) | 12,742km | NASA(平均半径 6,371.0km) |
| 月・水星・火星・金星の直径 | 3,475 / 4,879 / 6,779 / 12,104km | NASA Planetary Fact Sheet(平均半径 × 2) |
| 探査機の最高速度の記録 | 秒速 約192km(太陽に対して) | NASA / ギネス世界記録(Parker Solar Probe, 2024-12-24) |
| 1年で進む距離 | 約72億km | 227km/s × 1年。太陽〜海王星 約45億kmの約1.6倍 |
| 最古級の恐竜 | 約2億3000万年前(三畳紀後期) | Sues (2016) PNAS ほか |
| ホモ・サピエンス | 約30万年 → 1周の約1/700 | Hublin et al. (2017) Nature |
| 都市間の距離 | 東京駅起点の大圏距離(地表に沿った最短)の概算 | 東京→大阪 400 / 札幌 830 / 那覇 1,550 / ホノルル 6,200 / シドニー 7,820 / ロンドン 9,560 / ニューヨーク 10,850km |

速さは「何に対してか」で値が変わるため、速さを出す場面では基準(地球の中心/太陽/銀河の中心)を添えています。
メーターが数えているのは太陽系の位置での銀河回転(秒速およそ227km・誤差約5%)のぶんだけで、太陽系そのものはこれより少し速く(約240〜250km/s)、
地球の公転(約30km/s)でも向きによって増減します。そのため「およそ」「ほぼ」と表現しています。
