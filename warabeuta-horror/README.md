# 【意味がわかると怖い】祖母の数え歌

- `kazoeuta_horror.mp4` … 縦型 1080x1920 / 30fps / 約58秒（YouTube Shorts・TikTok・リール向け）
- `make_video.py` … 映像も音声もすべてプログラムで生成するスクリプト（`python3 make_video.py`）
  - 必要: ffmpeg / numpy / Pillow / IPAフォント / open-jtalk（naist-jdic・nitech m001 音声）

## 仕掛け
数字の次の一文字を縦に読むと「わたしがうめた」。

| 歌詞 | |
|---|---|
| ひとつ　**わ**らって　てをつなぎ | 二人で手をつないで |
| ふたつ　**た**んぼの　あぜみちを | あぜ道を歩き |
| みっつ　**し**ずかに　ふたりきり | 誰もいないところへ |
| よっつ　**が**けした　いどのそば | 崖の下の井戸 |
| いつつ　**う**しろで　ないてても | 泣いても |
| むっつ　**め**かくし　ふたをして | 蓋をして |
| ななつ　**た**ったひとりで　かえりみち | 七つのとき、ひとりで帰った |
