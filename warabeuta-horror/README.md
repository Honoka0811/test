# 七つ目の数え歌（わらべうた系ホラー・ショート）

- `kazoeuta_horror.mp4` … 縦型 1080x1920 / 30fps / 約54秒（YouTube Shorts・TikTok・リール向け）
- `make_video.py` … 映像も音声もすべてプログラムで生成するスクリプト（`python3 make_video.py`）
  - 必要: ffmpeg / numpy / Pillow / IPAフォント / open-jtalk（naist-jdic・nitech m001 音声）

## 構成
| 時間 | パート | 内容 |
|---|---|---|
| 0:00 | つかみ | 「この動画、最後まで聴かないでください。」 |
| 0:04 | ルール | 祖母の村には七つ目を歌ってはいけない数え歌がある／数えるたびに“なにか”が近づく |
| 0:17 | 数え歌 | ひとつ〜むっつ（子どもの声＋琴）。数えるたびに鳥居の奥の影が近づく |
| 0:32 | 静寂 | 「むっつで、やめた。……やめた、はずだった。」 |
| 0:38 | ななつ | 誰かが七つ目を歌う。影が目の前で首をかしげる |
| 0:40 | やっつ | 「わたしは、歌っていない」→ 左耳から「やっつ」→「声は、すぐうしろから聞こえた」 |
| 0:48 | 振り向く | 無音 → 振り向き → 顔「みぃつけた」 |
| 0:50 | 余韻 | 「ここのつ目は、あなたの番」（冒頭の一言にループ） |

歌詞・メロディ（都節音階）・絵・ナレーション原稿はすべてオリジナル。
