# 【意味がわかると怖い】七つの数え歌（メタナレーション版）

- `kazoeuta_horror.mp4` … 縦型 1080x1920 / 30fps / 約59秒（YouTube Shorts・TikTok・リール向け）
- `make_video.py` … 映像も音声もすべてプログラムで生成するスクリプト（`python3 make_video.py`）
  - 必要: ffmpeg / numpy / Pillow / IPAフォント / open-jtalk（naist-jdic・nitech m001 音声）

## 仕掛け
数字の次の一文字を縦に読むと「わたしがうめた」。

| 歌詞 | |
|---|---|
| ひとつ　**わ**らって　てをつなぎ | 二人で手をつないで |
| ふたつ　**た**んぼの　あぜみちを | あぜ道を歩き |
| みっつ　**し**ずかに　ふたりきり | 誰もいないところへ |
| よっつ　**が**けした　いどのそば | 崖の下の井戸 |
| いつつ　**う**しろで　ないてても | 泣いても |
| むっつ　**め**かくし　ふたをして | 蓋をして |
| ななつ　**た**ったひとりで　かえりみち | 七つのとき、ひとりで帰った |

## 構成
ナレーションは「これが動画であること」を自覚して、視聴者に直接話しかける。

| 時間 | 場面 | ナレーション |
|---|---|---|
| 0:00 | 部屋の老婆の影 | この動画は、59秒です。字幕を、目で追ってください。 |
| 0:05 | 夕暮れのあぜ道 | （数え歌。二人の子どもが井戸へ歩き、一人だけ帰ってくる） |
| 0:19 | 古い写真 | 今、スワイプしようとしましたね。あと35秒です。／この歌を作った人には妹がいました。七つのとき、井戸の近くでいなくなりました。 |
| 0:31 | 歌詞の紙 | では、もう一度歌詞を見てください。数字の次の一文字だけです。→「わたしがうめた」／答えはコメント欄に書かないでください。 |
| 0:44 | 部屋の老婆の影 | ひとつ言っていなかったことがあります。この歌を作った人は、まだ生きています。この声は合成音声です。本当の声は、聞かせられないので。 |
| 0:55 | 老婆がこちらを向く | あと、三秒です。（本当に三秒で終わる） |

「◯秒」はスクリプトが実際の尺から自動計算する。
