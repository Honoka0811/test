## 仕掛け
数字の次の一文字を縦に読むと「わたしがうめた」。

| 歌詞 | |
|---|---|
| ひとつ　**わ**らって　てをつなぎ | 二人で手をつないで |
| ふたつ　**た**んぼの　あぜみちを | あぜ道を歩き |
| みっつ　**し**ずかに　ふたりきり | 誰もいないところへ |
| よっつ　**が**けした　いどのそば | 崖の下の井戸 |
| いつつ　**う**しろで　ないてても | 泣いても |
| むっつ　**め**かくし　ふたをして | 蓋をして |
| ななつ　**た**だいま　ひとりきり | 「ただいま」と、ひとりで帰る（三行目の「ふたりきり」と対） |

## 裏設定（動機）
村には「七つまでは神のうち」として、七つになった子を井戸に“返す”しきたりがあった。
数え歌は祖母の自作ではなく村に昔から伝わる歌で、その手順を姉に覚えさせるためのもの。
縦読みは作った誰かが最初から仕込んだもので、歌う姉は全員「わたしがうめた」と口にしてきた。紙と赤丸は祖母が子どもの頃に、祖母に歌を教えた誰かがつけたもの。次の姉に役目をわからせるための教材で、孫がそれを「見つけた」のも手順のうち。
「わたしがうめた」の「わたし」は祖母ではなく“歌う姉”。
祖母が毎晩この歌を聴かせていた語り手こそ、次の姉。
妹にも歌を教えるのは、妹が“目隠しの遊び歌”だと思って、笑って手をつなぎ、自分から井戸までついて来るように。
同じ歌を、姉には手順として、妹には遊びとして覚えさせている。
