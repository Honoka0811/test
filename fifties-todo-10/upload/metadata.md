# アップロード用メタデータ(YouTube ショート)

`youtube_metadata.json` が投稿スクリプト `upload_youtube.py` の入力(タイトル・説明文・タグ・設定の正本)です。
手動で投稿する場合は、このファイルの内容をそのまま YouTube Studio に貼り付けてください。

## ファイル

| 用途 | ファイル | 備考 |
|---|---|---|
| 動画本体 | `fifties_todo_10_final.mp4` | 1080×1920(9:16)・30fps・76.9秒・H.264 High / yuv420p・AAC-LC 48kHz ステレオ・-14 LUFS・faststart |
| 字幕 | `subtitles_ja.srt` | 日本語。動画にも焼き込み済みだが、検索性と自動字幕の誤りを避けるためアップロード推奨 |
| サムネイル | `thumbnail.jpg` | 1080×1920。ショートのカスタムサムネイルは YouTube アプリ(スマホ)からのみ設定可。PC の Studio では動画内フレームからの選択になる |
| メタデータ | `youtube_metadata.json` | スクリプト用 |

ショート動画の条件(縦型 9:16、3分以内)を満たしているので、タイトルか説明文に `#Shorts` が入っていればショートとして扱われます。

## 設定

| 項目 | 設定値 |
|---|---|
| カテゴリ | ハウツーとスタイル(categoryId 26) |
| 言語 | 日本語(動画の言語・タイトルと説明の言語とも ja) |
| 視聴者 | 子ども向けではない |
| 公開設定 | まず「限定公開」で再生確認 → 問題なければ「公開」(スクリプトの既定も限定公開) |
| 字幕 | `subtitles_ja.srt` をアップロード |
| 改変・合成コンテンツの開示 | 「いいえ」でよい。合成音声(VOICEVOX)とイラストのみで、実在の人物・場所・出来事を本物らしく見せる表現はないため。気になる場合は「はい」にしても不利益はない |
| コメント | 通常どおり許可(必要なら「不適切な可能性のあるコメントを保留」) |
| 関連動画 / 終了画面 | ショートでは使用不可。説明文のリンクか固定コメントで誘導する |

## 投稿方法

### A. スクリプトで投稿(推奨)

```bash
cd fifties-todo-10/upload
pip install google-api-python-client google-auth-oauthlib
python3 upload_youtube.py                      # 限定公開でアップロード(動画 + 字幕 + サムネイル)
python3 upload_youtube.py --privacy public     # 公開で投稿する場合
python3 upload_youtube.py --dry-run            # 送信内容の確認のみ
```

初回のみ、Google Cloud Console で OAuth クライアント(デスクトップアプリ)を作成し、
`client_secret.json` をこのディレクトリに置く必要があります(手順はスクリプト冒頭のコメント参照)。
ブラウザで Google アカウントの認可を求められ、以後は `token.json` に保存されます。

### B. YouTube Studio から手動で投稿

1. https://studio.youtube.com → 「作成」→「動画をアップロード」→ `fifties_todo_10_final.mp4`
2. タイトル・説明文・タグを上の内容で入力。視聴者は「子ども向けではない」
3. 「字幕」→ 「ファイルをアップロード」→ `subtitles_ja.srt`(タイミング情報あり)
4. 公開設定「限定公開」で保存 → 再生確認 → 「公開」に変更
5. サムネイルを変えたい場合はスマホの YouTube アプリから設定
