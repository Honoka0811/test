## BGM
128BPM・Cメジャー・王道進行(F→G→Em→Am)のフューチャーポップ。キック連動のポンピング、スーパーソウのコード、ベル系のリードフック。
第1位の前でブレイク(ドラム停止+ライザー+加速スネアロール)し、「住所は東京都!!」で再ドロップ。ナレーション中は自動でダッキング。

## 再生成
```bash
./build.sh   # tts.py → audio.py → capture.js → upload/ に書き出し
```
- `tts.py` … 原稿(`SCENES`)をVOICEVOXで合成し、セリフ尺から `output/timeline.json` を作成。原稿を変えると映像の尺も自動で追従
- `audio.py` … BGM・効果音を合成してミックス
- `render.html` … Canvas 2D で `render(t)` がフレームを描画(ブラウザで開くとプレビュー再生。`output/timeline.json` が必要)
- `capture.js` … Playwright で全フレームを撮影し ffmpeg で mp4 化(`--stills 1.0 2.0` で静止画確認)
- 必要: Node.js + playwright, ffmpeg, Python 3 + numpy + scipy + pyopenjtalk + voicevox_core 0.16.1
  - VOICEVOX CORE: `voicevox_core-0.16.1-cp310-abi3-manylinux_2_34_x86_64.whl`、ONNX Runtime `voicevox_onnxruntime-linux-x64-1.17.3`(`VOICEVOX_ORT`)、音声モデル `0.vvm`(四国めたん。`VOICEVOX_VVMS`)

## 事実関係(概数・諸説あり)
- 東京スカイツリー 634m(旧国名「武蔵」にちなむ)
- 渋谷スクランブル交差点: 多いときは1回の青信号で約3,000人が横断するといわれる
- 新宿駅: 1日平均乗降客数 約350万人(コロナ禍前)で「世界一利用者の多い駅」としてギネス世界記録
- 東京タワー: 特別展望台より上の部分などに朝鮮戦争で使われた米軍戦車約90台分のスクラップ鋼材を再利用
- 沖ノ鳥島(日本最南端)・南鳥島(日本最東端)はいずれも東京都小笠原村。沖ノ鳥島は都心から約1,700km
