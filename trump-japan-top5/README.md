# トランプ再登場で日本はここまで変わった — 影響TOP5 ショート動画

トランプ政権2期目(2025年〜)で日本に起きた変化を、影響の大きい順にカウントダウン形式で解説する
縦型ショート動画(1080×1920 / 30fps / 約76秒)です。ナレーションは VOICEVOX:青山龍星、BGM・効果音は自作です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグの `metadata.md`)

## 構成

| シーン | 内容 | 演出 |
|---|---|---|
| フック | 「トランプ再登場で 日本はここまで変わった！」→ TOP5 の伏せカード → 「第1位はあなたの生活に直結」 | 文字の叩きつけ・グリッチ・低音インパクト。1位カードだけ赤く脈打たせて続きを見たくさせる |
| 第5位 | 株と円が乱高下(日経平均 4/7 −2,644円、4/10 +2,894円) | 折れ線が急落する瞬間にカウンター |
| 第4位 | 日本企業がアメリカへ(日本製鉄 × USスチール 約2兆円、黄金株) | 工場が米国へ流れるアニメ、黄金株のスタンプ |
| 第3位 | 防衛費の増額圧力(NATO 5%、日本は2%目標を前倒し) | 横棒グラフ、「2年前倒し」スタンプ |
| 第2位 | 約80兆円の対米投資(5,500億ドル、回収後の利益は9割が米国) | 80兆円カウントアップ、利益配分バーが 50:50 → 90:10 に変化 |
| (溜め) | 「第1位は…」 | BGMを0.7秒止めて暗転、上昇音 |
| 第1位 | 対米輸出に15%関税(自動車 2.5% → 15% の6倍、トヨタ 年1兆円超) | 赤い警報フレーム、巨大な「15%」、「×6」スタンプ |
| まとめ | 5項目の振り返り + 「何位が気になる？コメントで」 | コメント誘導の吹き出し |

共通の演出: 順位スタンプ(拡大→叩きつけ+画面揺れ+白フラッシュ+効果音)、上部の順位トラッカー(5→1)、
最上部の進行バー、キーワードを黄色で強調した焼き込み字幕(無音視聴でも内容が伝わる)。
ナレーションは本文が「ノーマル」、順位コール(「第五位！」など)だけ「熱血」スタイルで抑揚をつけています。

## BGM・効果音(`bgm.py`)

政治・ニュース解説系の緊張感を狙った自作BGM。外部音源を使わず numpy/scipy で合成しているため権利表記は不要です。
Cマイナー・100BPM、脈打つ8分のシンセベース、秒針のようなチック、低弦パッド、鼓動キック、
後半ほど増えるブラス・スタブ。ナレーション中は自動で音量を下げます(ダッキング)。
効果音は順位発表のインパクト(サブベース落下+ブラァム)、場面転換のウーシュ、第1位前の上昇音。

## 再生成の方法

```bash
cd trump-japan-top5
python3 build_audio.py   # ナレーション合成 → シーン尺・字幕・効果音タイミングを output/timeline.js に書き出し、mix.wav を作成
node capture.js          # render.html を1フレームずつ撮影 → output/video_silent.mp4
node capture.js thumb    # output/thumbnail.png
./export.sh              # 映像+音声を合成し -14 LUFS に正規化 → upload/
node capture.js stills 5,20,60   # 確認用の静止画
```

ナレーションの長さから各シーンの尺が決まるため、`build_audio.py` の `SCENES` の原稿を書き換えて
上の手順を再実行すれば、映像・字幕・効果音のタイミングも自動で合います。

### 必要なもの

- Python 3 + `numpy` `scipy` `voicevox_core`、Node.js + `playwright`(Chromium)、`ffmpeg`
- VOICEVOX(`/home/user/vv` 以下に配置。パスは環境変数 `VOICEVOX_ORT` / `VOICEVOX_VVMS` / `VOICEVOX_DICT` で変更可)
  - `voicevox_core-0.17.1-cp310-abi3-manylinux_2_34_x86_64.whl`(VOICEVOX/voicevox_core releases)
  - `voicevox_onnxruntime-linux-x64-1.17.3.tgz`(VOICEVOX/onnxruntime-builder releases)
  - `15.vvm`(青山龍星、VOICEVOX/voicevox_vvm releases 0.17.1)
  - `open_jtalk_dic_utf_8-1.11.tar.gz`(r9y9/open_jtalk releases v1.11.1)
- フォント: Noto Sans JP(Black/Bold/Medium)を `fonts/` に配置(notofonts/noto-cjk releases `Sans2.004/16_NotoSansJP.zip`、SIL OFL)。
  サイズが大きいためリポジトリには含めていません。

VOICEVOX の音声を公開する場合は、利用規約に従い「VOICEVOX:青山龍星」のクレジット表記が必要です(動画内左上と説明文に記載済み)。
