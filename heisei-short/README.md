# 平成あるある 何個わかる? — ショート動画

YouTube ショート用の縦型動画(1080×1920 / 30fps / 約43秒)。ナレーションは **VOICEVOX:四国めたん(ノーマル)**、BGM・効果音・映像はすべてコードで自作(権利フリー)。

**アップロード用一式: `upload/`**(mp4・字幕SRT・サムネイル・タイトル/説明文/タグ/運用メモの `metadata.md`)

## 構成と演出

| 時間 | シーン | 視聴者を引きつける仕掛け |
|---|---|---|
| 0:00 | フック「平成あるある 何個わかる?」 | 1フレーム目から大見出し+BGMが鳴る。「全8問」で最後まで見る理由を作る |
| 0:05–0:19 | 8cmCD / ポケベル(0840=おはよう) / プリ帳 / ルーズソックス | 右上カウンター「n/8」と平成年表バーで進行を可視化、ピコン音で達成感 |
| 0:19–0:25 | 1999年7の月「世界は滅亡…」→「しなかった」 | BGMを抜いて不穏なドローン+画面揺れ → レコードスクラッチで落とすパターン崩し |
| 0:25–0:36 | 二千円札「最近見た?」/ 着メロ16和音 / 赤外線「ピッ」 | 問いかけでコメントを誘発 |
| 0:36–0:43 | 何個わかった?→ 平成マスター → コメント誘導 | 矢印でコメントボタンを指す。最後のグリッチで頭に戻り、ループ再生しやすい |

全編: 約3〜4秒ごとのカット、VHS風スキャンライン/▶PLAY表示、切り替えグリッチ、大きな縁取り字幕(ショートのUIに被らない位置)。

BGM: 126BPM・王道進行(F→G→Em→Am)の平成J-POP/ユーロビート風。4つ打ち+裏打ちベース+シンセのコード+着メロ風ピコピコリード。ナレーション中は自動で音量を下げる(ダッキング)。

## 再生成

```bash
cd heisei-short
python3 narrate.py   # VOICEVOXで音声合成 → output/narration.wav, timeline.js, 字幕SRT
node capture.js      # render.html を1フレームずつ撮影 → output/video_silent.mp4
python3 mix.py       # BGM・効果音をミックスし -14 LUFS で upload/heisei_aruaru_short.mp4 を書き出し
```

- `narrate.py` の `SCENES` を書き換えればセリフ・字幕を変更でき、シーンの長さは音声に合わせて自動で決まります
- `render.html` はブラウザで開くとプレビュー再生できます
- VOICEVOX のセットアップは `../pacific-war-analysis/README.md` と同じ(音声モデルは `0.vvm`、話者ID 2 = 四国めたん ノーマル)
