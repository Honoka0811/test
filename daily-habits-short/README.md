# 毎日の習慣が続く5つのコツ — YouTube ショート

「習慣が続かないのは、意志が弱いからじゃない。」で始まる、縦型ショート動画(1080×1920 / 30fps / 約53秒)です。
ナレーションは VOICEVOX:四国めたん(ノーマル)、BGM と効果音は numpy で自作した権利フリー音源です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグ/チェックリストの `metadata.md`)
- ナレーションのみ: `output/narration.wav` / BGMのみ: `output/bgm.wav` / サムネイル: `output/thumbnail.png`

## 構成

| 時間 | シーン | ナレーション(要旨) | 画面の演出 |
|---|---|---|---|
| 0:00 | フック | 習慣が続かないのは、意志が弱いからじゃない | 三日坊主のカレンダー → 💪に✕と「関係ない」スタンプ |
| 0:04 | 予告 | 続く人がこっそりやってる5つのコツ、全部見せます | 🤫 →「5」がドンと出て5つのアイコンが回る |
| 0:08 | コツ1 | 2分で終わる形にする(腕立て1回・1ページ) | 30回に打ち消し線 → 1回 / ハードルが地面まで下がる |
| 0:18 | コツ2 | 今ある習慣にくっつける | 歯みがき+スクワット、コーヒー+英単語が鎖でつながる |
| 0:27 | コツ3 | 意志より環境を変える | スマホがドアの向こうへ / 本が枕に落ちる / やる気メーターが0%で「負け」 |
| 0:34 | コツ4 | やったらカレンダーにマル | 習慣トラッカーにマルが増え、🔥連続日数がカウントアップ |
| 0:40 | コツ5 | サボるなら1日だけ | 1回休み=セーフ / 2回連続で画面が赤く点滅 |
| 0:46 | CTA | 明日の朝1つだけ試して、結果はコメントで | ルーレットで1つ選ぶ → コメント吹き出し → 保存の呼びかけ |

画面上部には常に「5つのコツ」の進捗(済みは✓)を出し、最後まで見る理由を作っています。
シーン切り替えはカラーワイプ+ズームパンチ+ウーッシュ音、キーワードは字幕マーカー+ポップ音+画面の揺れで強調します。

## 音

- **ナレーション**: VOICEVOX ENGINE で四国めたん(style 2 = ノーマル)、話速 1.12・抑揚 1.3 で元気めに合成
- **BGM**(`bgm.py`): F メジャー / 124BPM、進行 F-C-Dm-B♭。フック中はフィルターのかかったイントロ → 2小節のライザー → コツ1で4つ打ちのドロップ。裏拍ベース・サイドチェインのかかったパッド・16分のプラック・リードのモチーフ。CTA でキックを抜いて落ち着かせる
- **効果音**: 冒頭のインパクト、シーン切り替えのウーッシュ、コツ番号のインパクト、キーワードのポップ音、カレンダーのチェック音、✕のブザー、最後のチャイム。すべて `output/timing.js` のタイミングに同期
- **ミックス**(`mix.py`): ナレーション中は BGM を自動で下げる(ダッキング)。BGM は声より約10dB、効果音は約7dB 小さく、最終的に -14 LUFS に正規化

## 再生成の方法

```bash
cd daily-habits-short
./build.sh              # 全工程(ナレーション → ミックス → 映像撮影 → upload/ 書き出し)
./build.sh --no-video   # 映像の再撮影を省略
```

| ファイル | 役割 |
|---|---|
| `narrate.py` | 原稿(`SCENES`)を VOICEVOX で合成し、モーラ長からテロップごとの表示時刻を計算して `output/timing.js`・`output/narration.wav`・`output/subtitles_ja.srt` を書き出す |
| `render.html` | Canvas 2D で `render(t)` が時刻 t 秒のフレームを決定論的に描画。ブラウザで開くとプレビュー(クリックで音声付き再生、`?t=12.3` で静止) |
| `capture.js` | Playwright(Chromium)で全フレームを撮影し、ffmpeg で mp4 化 |
| `snap.js` | 指定時刻のフレームやサムネイルを PNG で書き出す(確認用) |
| `bgm.py` / `mix.py` | BGM・効果音の合成とミックス |
| `build.sh` | 一括ビルドと -14 LUFS 正規化 |

原稿を変えるときは `narrate.py` の `SCENES` を書き換えて `./build.sh` を実行します。
`【】` で囲んだ語がテロップで強調され、そのタイミングでポップ音と揺れが入ります。
各チャンクは句読点で終えてください(アクセント句の境界でタイミングを分割するため)。

### VOICEVOX ENGINE について

`narrate.py` は `VOICEVOX_URL` → `http://127.0.0.1:50021` → 公開されている VOICEVOX ENGINE の順に接続を試します。
ローカルで動かす場合は公式の Docker イメージ(`voicevox/voicevox_engine:cpu-latest`)か製品版 VOICEVOX を起動してください。
合成結果は `output/cache/` に保存されるため、原稿を変えなければエンジンなしで再ビルドできます。
スタイルは `VOICEVOX_STYLE` で変更できます(2=ノーマル、0=あまあま、6=ツンツン、4=セクシー)。

### 必要なもの

Node.js + `playwright`(Chromium)、`ffmpeg`、Python 3 + `numpy`、絵文字フォント(Noto Color Emoji)。
日本語フォント(Noto Sans JP / Dela Gothic One、いずれも SIL Open Font License)は `fonts/` に同梱しています。
