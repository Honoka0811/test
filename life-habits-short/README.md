# 人生を楽しくする習慣10選 — ショート動画

「人生を楽しくするためにオススメの習慣10選」を、10位→1位のカウントダウン形式で紹介する
縦型ショート動画(1080×1920 / 30fps / 約70秒)です。ナレーションは **VOICEVOX:四国めたん**(ノーマル)。

- **完成動画: `upload/life_habits_10.mp4`**(-14 LUFS 正規化・ステレオAAC)
- サムネイル: `upload/thumbnail.jpg` / 字幕: `upload/subtitles_ja.srt` / 投稿文・タグ: `upload/metadata.md`
- 素材: `output/narration.wav`(ナレーションのみ)、`output/bgm.wav`(BGMのみ)

## 構成

| 時間 | シーン | 演出 |
|---|---|---|
| 0:00–0:03 | フック「毎日なんとなくつまらない…?」 | 灰色の画面・秒針の音・こもったBGMで「退屈」を表現 |
| 0:03–0:07 | 「人生を楽しくする習慣10選!」 | 白フラッシュと同時に **BGMがドロップ**、紙吹雪、特大の「10」。「1位は最後に発表!」で離脱を防ぐ |
| 0:07–0:55 | 第10位 → 第2位 | 斜めワイプ+シュッ音 → 順位がポンと拡大・画面が揺れる → 絵文字が弾んで登場 → タイトルが1文字ずつ → 理由カードのキーワードに黄色マーカー。上部の進捗ドットで「あと何個」かが分かる。5位からリードメロディが加わり盛り上がる |
| 0:55–0:57 | 「そして第1位は…」 | 暗転・スポットライト・BGMが止まり、加速するドラムロールと鼓動する「?」 |
| 0:57–1:04 | 第1位 楽しみな予定を先に入れる | クラッシュ+ファンファーレで **再ドロップ**、金色テーマ・王冠・紙吹雪 |
| 1:04–1:10 | まとめ・CTA | 保存したくなる1〜10位の一覧、「試したいのは何番?コメントで教えてね」「保存して見返そう!」、クレジット |

シーンの長さは固定ではなく、ナレーションの実際の長さから自動で決まります(`narrate.py` → `timeline.js`)。

## ファイル

- `script.py` … 台本(読み上げ文 / 画面表記 / 強調キーワード)。ここを書き換えて `./build.sh` すれば作り直せます
- `narrate.py` … VOICEVOX(四国めたん, style 2。話速 1.3、抑揚強め)で合成し、タイムライン・字幕を作る
- `music.py` … BGM(Cメジャー 124BPM のポップ。C–G–Am–F、キック/クラップ/ハイハット/ベース/シンセ/リード)と効果音を numpy+scipy で合成し、ナレーション中は BGM を自動で下げてミックス。外部音源を使わないので権利フリー
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを描画。ブラウザで開くとプレビュー再生(`#t=12.3` で静止、`#thumb` でサムネイル)
- `capture.js` … Playwright で全フレームを撮影して ffmpeg で mp4 化
- `build.sh` … 上記を順に実行し、-14 LUFS に正規化して `upload/` に書き出す
- `setup.sh` … VOICEVOX CORE・四国めたんの音声モデル・フォント(M PLUS Rounded 1c / Dela Gothic One / Noto Color Emoji, いずれも OFL)を取得

```bash
./setup.sh   # 初回のみ
./build.sh
```

話者を変える場合は `VOICEVOX_STYLE=0 ./build.sh`(0 = 四国めたん あまあま、6 = ツンツン)。
VOICEVOX の利用規約により、公開時は「VOICEVOX:四国めたん」のクレジットが必要です(動画の最後と `metadata.md` の説明文に記載済み)。
