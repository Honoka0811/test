# 午前2時のノック — ホラーショート動画

毎晩午前2時に壁を叩く音。隣の人だと思っていたら、その壁の向こうは「外」だった——。
四国めたん(VOICEVOX)が語るオリジナルの短編ホラーです。縦型 1080×1920 / 30fps / 約70秒。

- **完成動画: `output/gozen2ji_knock.mp4`**(ナレーション・効果音・字幕焼き込み済み)
- サムネイル: `output/thumbnail.jpg`
- 字幕: `output/subtitles_ja.srt`
- タイムライン(各シーン・台詞・効果音の時刻): `output/timeline.json`

> ⚠ 終盤 (約 1:02) に大きな音と顔が出るジャンプスケアがあります。

## 声と音

- ナレーション: **VOICEVOX:四国めたん**
  - 語り = ノーマル(style 2、抑揚を少し抑えて読点の間を長めに)
  - 管理人の台詞 = ノーマルを抑揚 0.55 まで平板にして淡々と
  - 「少しずつ、近づいてきてる」「次は、あなたの部屋かも」 = ヒソヒソ(style 37)
  - 「もう、入ったから」 = ささやき(style 36)を約3半音下げ、逆再生の残響で吸い込むように始まり、右耳のすぐ後ろに定位(イヤホン推奨)
- 効果音・環境音はすべて numpy/scipy で合成した自作音(外部音源なし)。壁・窓ガラス・鉄扉で叩く音を作り分け、低音ドローン、蛍光灯のうなり(映像の明滅と同期)、雷、心音(だんだん速くなる)、暗転直前まで上がり続ける緊張音、スケアの衝撃音
- 音量: 各効果音をナレーションの短期音量に対する相対値(`audio.py` の `SFX_REL`)で配置。スケアだけがナレーションより約 +8dB 大きくなるように調整。全体 約 -16 LUFS / トゥルーピーク -1.5 dBTP 以下

読み誤りの対策として、読み上げ用テキストは一部かなで指定しています(「管理人」→かんりにん、「角部屋」→かどべや)。字幕は漢字表記です。

## 再生成

```bash
cd horror-knock
./setup.sh      # VOICEVOX CORE 0.17.1・ONNX Runtime・音声モデル(0.vvm, 5.vvm)・Noto Serif JP を取得
./build.sh      # 音声 → 映像 → サムネイル → 合成 → output/gozen2ji_knock.mp4
```

- `audio.py` … 台本 `TIMELINE` を合成して時刻を確定し、効果音と環境音を作ってミックス。台詞の差し替えは `TIMELINE` を書き換えて再実行するだけ(尺・シーン切り替え・字幕は自動で追従)
- `render.html` … Canvas 2D で `render(t)` が時刻 t のフレームを決定論的に描く。全シーン・顔・建物などはすべてコードで描画
- `capture.js` … Playwright(Chromium)で全フレームを撮影し ffmpeg で mp4 化。`--stills 1.0,30.5` で確認用の静止画、`--thumb` でサムネイル
- 必要なもの: Python 3 + numpy / scipy / pyopenjtalk / voicevox_core、Node.js + playwright、ffmpeg
