# SR-71 ブラックバード ミリタリー解説ショート

「ミサイル4000発を全部かわした飛行機」SR-71 ブラックバードを、約43秒の縦型ショート(1080×1920 / 30fps)で紹介する動画です。

- **アップロード用一式: `upload/`**(最終mp4・字幕SRT・サムネイルJPG・タイトル/説明文/タグ/投稿のコツが入った `metadata.md`)
- ナレーション: VOICEVOX:四国めたん(ノーマル)
- BGM・効果音: `bgm.py` でプログラム合成(外部音源なし・権利フリー)

## 構成と演出(約43秒)

| 時間 | シーン | 演出 |
|---|---|---|
| 0:00 | フック「撃たれたミサイルは4000発以上 / なのに一発も当たらなかった」 | 1フレーム目から字幕を表示。レーダー画面でミサイルが迫り「MISS」で逸れる。カウンターが 0→4,000+、ロックオン警報、「命中 0」のスタンプ |
| 0:05 | 正体「SR-71 ブラックバード」 | 白フラッシュ+インパクト音。機体がモーションブラー付きで滑り込み、RGBずれのグリッチでタイトル |
| 0:11 | 方法「ミサイルより速く逃げるだけ」 | 追ってくるミサイルとの距離が開いていく(煙の帯・アフターバーナー) |
| 0:14 | 速さ「マッハ3.3 / 東京→大阪7分」 | 針が振り切れるスピードメーター → 東京→大阪のタイマーと、新幹線(約2時間半)との比較バー |
| 0:19 | 高さ「2万6000m / 空が黒く見える」 | 富士山・エベレスト・旅客機を追い越しながら空が青から黒になり、星が出る |
| 0:24 | 熱「表面は300℃以上 / 地上では燃料がダダ漏れ」 | サーマルカメラ風の機体 → パネルの継ぎ目の図解 → 地上で燃料が漏れて水たまりができる |
| 0:30 | 秘密「チタンを敵国ソ連からダミー会社経由で調達」 | 機密書類風の背景、元素記号 Ti のタイル、調達ルートの図、「極秘」スタンプ |
| 0:35 | 締め「32機のうち撃墜された機体は… ゼロ」 | 32機のアイコンと数字のドラムロール → 音と映像を止めて溜める → 「0」と衝撃波 |
| 0:39 | CTA「次に知りたい兵器はコメントで」 | 吹き出しの中で兵器の例が切り替わる(コメントを誘う) |

全体の演出として、カットごとにカメラシェイク・ズームパンチ・白フラッシュを入れ、フィルムグレインとビネットをかけ、画面下に進捗バーを出しています。字幕はキーワードを黄色にしてポップインさせています。

**BGM**(Dマイナー / 128BPM、トレーラー風): 冒頭はドローン+秒針のチック+心拍のようなキックで緊張させ、ライザーを経てリビールで「ブラーム」とインパクト。そこからは16分のベースとストリングスのスタッカートで疾走し、4小節ごとにタムのフィルが入ります。「ゼロ」の直前で全部の音を止めてライザーだけを残し、最大のインパクトを打ちます。効果音はレーダー音、ロックオン警報、ミサイルの発射音、ジェット機の通過音、カット切り替えのウーシュです。ナレーション中は BGM が自動で下がり(ダッキング)、声が背景より約9〜14dB大きくなるようにしています。

## 再生成の方法

前提: Python 3(numpy, scipy, voicevox_core 0.16)、Node.js + Playwright、ffmpeg。
VOICEVOX は `/home/user/vv` に以下を置いた状態を想定しています(パスは環境変数で変更できます)。

- `voicevox_core-0.16.0-cp310-abi3-manylinux_2_34_x86_64.whl`(pip install)
- `ort/voicevox_onnxruntime-linux-x64-1.17.3/`(`VOICEVOX_ORT`)
- `vvms/0.vvm`(四国めたんを含む。`VOICEVOX_VVMS`)
- `open_jtalk_dic_utf_8-1.11/`(`VOICEVOX_DICT`)

```bash
cd sr71-blackbird
npm install                 # フォント(Dela Gothic One / Noto Sans JP)
python3 narrate.py          # 原稿 script.py → output/narration.wav, timeline.json, subtitles_ja.srt
node capture.js             # timeline.json に合わせて映像を描画 → output/video_silent.mp4
python3 mix.py              # BGM・効果音を合成してミックス → upload/sr71_blackbird_short.mp4(-14 LUFS)
node capture.js --thumb     # output/thumbnail.png
node capture.js --stills 1,6,13   # 確認用の静止画 → output/stills/
python3 bgm.py              # BGM・効果音だけを書き出す → output/bgm.wav, output/sfx.wav
```

原稿を変えるときは `script.py` だけを編集します。シーンの長さ・字幕のタイミング・効果音の位置は、すべてナレーションの実際の長さ(`timeline.json`)から自動で決まります。
