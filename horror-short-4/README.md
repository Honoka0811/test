# 近づいてくるアイコン — ホラーショート動画(4本目)

縦型ショート動画(1080×1920 / 30fps / 約55秒)。位置情報共有アプリの地図画面で進むオリジナルの「意味が分かると怖い話」です。

- 完成動画: `output/chikazuku_icon.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、電話の声=あまあま、最後=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(暗いパッド、近づくほど速くなる低音パルスと探知音、バイブ、スマホを探す音、心音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。距離が縮むほど地図が拡大する。分かるのは建物単位まで(誤差円つき)という現実の精度に合わせてある |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

アプリ「いまどこマップ」と登場人物は架空のものです。

## 視聴維持のための仕掛け

- 画面上部の距離が 1km → 「一緒にいます」へ減り続けるカウントダウン構成
- 探知音と低音パルスの間隔が距離に連動して短くなる
- 「一緒にいます」で終わらせず、電話で「スマホをなくした」と分かり、友達が鳴らした「探す」音がベッドの下から聞こえる、という二段目のオチを置く

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py`、距離の推移は `sound.py` の `DK` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
