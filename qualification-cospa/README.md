# 資格のコスパランキング(平均年収 × 難易度)

資格ごとの「平均年収」と「難易度(合格に必要な勉強時間)」から、**勉強1時間あたり年収がいくら上がるか**を計算し、コスパ順に並べました。

## 評価方法

```
年収上乗せ額 = 資格保有者の平均年収 − 日本の平均給与 460万円
コスパ       = 年収上乗せ額 ÷ 必要勉強時間   (円 / 勉強1時間・毎年)
```

- **基準年収 460万円**: 国税庁「民間給与実態統計調査」令和5年分の平均給与。
- **難易度**: 合格率は受験者層によって大きく変わるため、比較しやすい「合格に必要な勉強時間(一般的な目安)」を難易度の指標にしました。★は勉強時間による5段階表示です(〜300h ★1 / 〜700h ★2 / 〜1,500h ★3 / 〜3,500h ★4 / それ以上 ★5)。
- **10年累計**: 上乗せが10年続いた場合に、勉強1時間が何円になるか(コスパ×10)。

## 読み解き

- **最強コスパは「中難易度 × 高年収業界」**。1位の証券アナリスト、2〜3位の情報処理安全確保支援士・応用情報技術者は、勉強500〜600時間で年収上乗せが大きい。金融・IT業界自体の年収水準が高いことが効いています。
- **超難関資格は年収トップでもコスパは中位以下**。弁護士(+540万円)・公認会計士(+440万円)は上乗せ額こそ最大級ですが、3,500〜8,000時間の勉強が必要で、1時間あたりでは薄まります。ただし「10年で約7,000〜13,000円/時間」と、長期で見れば十分な投資です。
- **バランス型の狙い目**は一級建築士・中小企業診断士・技術士・USCPA(勉強1,000〜1,300時間、上乗せ約200万円)。
- **入門資格は「取るだけ」では年収が上がりにくい**。宅建・基本情報は少ない勉強時間で済むためコスパは悪くないものの、FP2級・簿記2級・行政書士・マンション管理士は保有者の平均年収が全体平均とほぼ同じで、単独では年収アップにつながりにくい結果です(実務経験や他資格との組み合わせが前提)。

## 注意点

- 平均年収は、厚生労働省「賃金構造基本統計調査」や求人・資格情報サイト等で公表されている値を参考にした**概算**です。調査により±100万円程度の幅があります。
- 「資格保有者の平均年収」には業界・年齢・経験の影響が含まれており、**資格を取ったことによる効果そのものではありません**(相関であって因果ではない)。
- 勉強時間は一般的な目安で、前提知識によって大きく変わります。弁護士は法科大学院・予備試験ルート、USCPAは受験資格(単位)取得の負担も別途あります。
- 医師・薬剤師・看護師など、大学の専門課程修了が必要な資格は勉強時間で比較できないため対象外にしています。

## ファイル

| ファイル | 内容 |
|---|---|
| `data.csv` | 入力データ(資格・分野・平均年収・勉強時間・合格率) |
| `rank.py` | コスパ計算とランキング出力(`python3 rank.py`) |
| `ranking.csv` / `ranking.md` | 出力されたランキング |

`data.csv` の数値を書き換えて `python3 rank.py` を実行すれば、ランキングを再計算できます。
