# 資格のコスパランキング(年収直結資格限定)

**資格がそのまま年収に結びつく資格**に限定し、平均年収と難易度(勉強時間)から「勉強1時間あたり年収がいくら上がるか」を計算して、コスパ順に並べました。

## 対象の絞り込み:なぜ「年収直結」に限定するか

独占業務のない資格(証券アナリスト・情報処理系・簿記など)は、保有者の平均年収が高くても、**もともと年収の高い業界・職種の人が取っているだけ**の可能性が高いです。この場合、資格を取っても年収は逆転できません。

そこで、次のどちらかに当たる資格だけを対象にしました。

- **業務独占資格**: 資格がないとその仕事ができない(例: 税務代理は税理士だけ)
- **必置資格**: 事業所に置くことが法律で義務づけられている(例: 宅建士、電気主任技術者)

どちらも「資格を持っていること」自体に需要があるため、業界や経歴に関係なく、資格が年収の源泉になります。

## 評価方法

```
年収上乗せ額 = 資格保有者の平均年収 − 日本の平均給与 460万円
コスパ       = 年収上乗せ額 ÷ 必要勉強時間   (円 / 勉強1時間・毎年)
```

- **基準年収 460万円**: 国税庁「民間給与実態統計調査」令和5年分の平均給与
- **難易度**: 合格に必要な勉強時間の一般的な目安。★は勉強時間で5段階(〜300h ★1 / 〜700h ★2 / 〜1,500h ★3 / 〜3,500h ★4 / それ以上 ★5)
- **10年累計**: 上乗せが10年続いた場合に、勉強1時間が何円になるか(コスパ×10)

## 読み解き

- **1位は一級建築士**。勉強時間は約1,200時間と難関士業の1/3程度で、上乗せは約240万円。業務独占資格のなかで最もバランスがよい結果です。
- **公認会計士は上乗せ額が+440万円と大きく**、勉強時間3,500時間でも2位。監査は会計士にしかできないため、資格の効き方がはっきりしています。
- **宅建士は「少ない勉強で確実に効く」タイプ**。上乗せは+40万円と小さいものの、勉強は350時間で済みます。また、不動産会社には一定数の設置義務があるため、資格手当(月1〜3万円程度が一般的)として直接給与に反映されやすい資格です。
- **弁護士・税理士・司法書士は、年収の上乗せは大きいものの勉強時間が長すぎて**、1時間あたりでは中位以下になります。長期的に回収する投資です。
- **行政書士は業務独占資格でもマイナス**。独占業務の単価が低く、開業者の年収差も大きいため、単独で年収アップを狙う資格としてはコスパが悪い結果です。

## 注意点

- 平均年収は、厚生労働省「賃金構造基本統計調査」や求人・資格情報サイト等で公表されている値を参考にした**概算**です。調査により±100万円程度の幅があります。
- 年収直結の資格に絞っても、保有者の年齢や経験の影響は残ります(特に弁護士・会計士は若手と開業者で差が大きい)。
- 勉強時間は一般的な目安で、前提知識によって大きく変わります。弁護士は法科大学院・予備試験ルート、一級建築士は受験資格(学歴・実務経験)の要件も別途あります。
- 医師・薬剤師・看護師など、大学の専門課程修了が必要な資格は勉強時間で比較できないため対象外です。

## ファイル

| ファイル | 内容 |
|---|---|
| `data.csv` | 入力データ(資格・平均年収・勉強時間・合格率・年収直結の判定と根拠) |
| `rank.py` | コスパ計算とランキング出力(`python3 rank.py`)。`年収直結` が ○ の資格だけを順位付け |
| `ranking.csv` / `ranking.md` | 出力されたランキング(除外リスト付き) |

`data.csv` の数値や `年収直結` 列を書き換えて `python3 rank.py` を実行すれば、ランキングを再計算できます。
