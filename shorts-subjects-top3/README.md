# ショート動画「あらゆる仕事で役立つ科目 TOP3」

縦型ショート動画（1080×1920・30fps・約45秒）を生成するスクリプトです。

- 映像・演出・字幕・BGM・効果音はすべて `build.py` がプログラムで生成します（外部素材は使っていないため、著作権の心配はありません）
- ナレーション: VOICEVOX:四国めたん（画面右下にクレジットを表示）

## ナレーションの入れ方
1. VOICEVOX アプリで「四国めたん（ノーマル）」を選ぶ
2. `narration.txt` を読み込む（1行＝1シーン、全8行）
3. 「音声書き出し（一括）」で8つの wav を書き出し、`voice/` に入れる（ファイル名順＝シーン順。例: `01.wav`〜`08.wav`）
4. `python3 build.py` を実行する → `out/short.mp4`

`voice/` が空だと、推定した尺でナレーションなし版を作ります。
音声を入れると、各シーンの尺・字幕・効果音のタイミングが実際の音声の長さに自動で合わせられます。

## 構成と演出
| シーン | 内容 | 演出 |
|---|---|---|
| フック | 「将来ほんとに役立つのはどれ？」 | 集中線、TOP3 がバウンドしながら登場、衝撃音 |
| 意外性 | 数学は「まさかのランク外」 | ×スタンプ、画面の揺れ、ブザー音 |
| 第3位 | 英語 | 科目名が落下してドン、ポイントがスライドイン、チャイム |
| 第2位 | 情報 | 同上 |
| 溜め | 「栄えある第1位は…」 | BGMを止める、ドラムロール、上昇音、脈打つ「？」 |
| 第1位 | 国語 | 金色の集中線、シンバル、紙吹雪、強い揺れ、BGM再開 |
| 次点 | 公民 | 同上（控えめ） |
| CTA | 「コメントで教えてね」 | ランキングのまとめ、跳ねる矢印 |

BGM は 128BPM のアップテンポな EDM 風ループ（Am–F–C–G）で、ナレーション中は自動で音量を下げます。
