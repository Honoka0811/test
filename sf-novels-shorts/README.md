## クレジット・権利

- ナレーション: **VOICEVOX:四国めたん**(公開時はこのクレジット表記が必要。動画の最後のカードに記載済み)
- BGM: `bgm.py` が numpy だけで合成するオリジナル(Aマイナー / 112BPM のシンセウェーブ風)。外部音源は不使用
- 映像: 書影や既存の画像は使わず、アイコンもすべて Canvas で描画
- フォント: Noto Sans JP (SIL Open Font License)

## 作り直す

```bash
./setup.sh   # 初回のみ: フォントと VOICEVOX(四国めたん)を取得
./build.sh   # 音声 → 映像 → 合成
```

- `scenes.json` … 原稿(`say`=読み上げ用、`sub`=字幕用)と各作品のデータ。ここを書き換えて `./build.sh` すれば作り直せます
- `narrate.py` … VOICEVOX で合成し、音声の長さからシーンの尺を決めて `output/timeline.js` に書き出す。BGM は発話中に自動で音量を下げてミックス。`VOICEVOX_STYLE`(0=あまあま 6=ツンツン 4=セクシー)、`VOICEVOX_SPEED` で声色と話速を変更可
- `render.html` … Canvas 2D で時刻 t のフレームを描画(ブラウザで開くとプレビュー再生)
- `capture.js` … Playwright で 1 フレームずつ撮影して ffmpeg で mp4 化
