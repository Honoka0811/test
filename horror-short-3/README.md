# 睡眠アプリの録音 — ホラーショート動画(3本目)

縦型ショート動画(1080×1920 / 30fps / 約55秒)。睡眠アプリの画面形式で進むオリジナルの「意味が分かると怖い話」です。

- 完成動画: `output/sleep_app_recording.mp4`
- サムネイル: `output/thumbnail.jpg` / 字幕: `output/subtitles_ja.srt`
- タイトル・説明文・タグ案: `output/metadata.md`

| 要素 | 内容 |
|---|---|
| ナレーション | VOICEVOX:四国めたん(ナレーション=ノーマル、寝言=あまあま、録音されていた声=ヒソヒソ) |
| BGM・効果音 | `sound.py` で numpy 合成(暗いパッド、子守唄風の旋律、時計、不協和ストリングス、心音、いびき、きしみ、足音)。外部音源なし |
| 映像 | `render.html` の Canvas 描画。波形は実際の音声の音量に連動 |
| フォント | しっぽり明朝(OFL-1.1)、IPAゴシック |

アプリ「ねむりログ」は架空のものです。

## 視聴維持のための仕掛け

- 冒頭の「〜してみた結果」で結末まで見る理由を作る
- 「話し声」で終わらせず、「録音が手動で止められていた」という二段目のオチを置く
- 1件目のいびきの裏に、ドアのきしみと足音を小さく入れてある(見返し・コメント誘導)

## 再生成

```bash
npm install          # フォント
./build.sh           # narrate.py → sound.py → capture.js → 合成
```

必要なものは `../horror-short/README.md` と同じです。台本は `script.py` を編集してください。
公開時は「VOICEVOX:四国めたん」のクレジット表記が必要です(動画末尾と説明文案に記載済み)。
